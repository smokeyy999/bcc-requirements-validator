### Z-002 · Объявление единицы временной метки

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 требует объявления миллисекунд в каждом поле, но не задаёт проверяемого признака объявления. Числовое соответствие одной секунды значению 1000 проверяется отдельно.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать реплику с временной меткой в одну секунду. В поле записано 1000.

**Последствие.** Число можно проверить, а приёмка объявления единицы зависит от того, где и в каком виде оно ожидается.

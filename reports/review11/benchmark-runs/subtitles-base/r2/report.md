### Z-001 · После обязательного отклонения реплики из 81 кодовой точки Unicode должен ли экспорт сохранить допустимую реплику в файле или завершиться без создания файла?

[R-M0015-01](#r-m0015-01) · Subtitle track export / Export limits · [строка 15](../../../../../benchmark/subtitles/baseline.md#L15)

> In the acceptance sample, a cue of 81 Unicode code points is rejected.  

**Сценарий.** Экспортировать по свободному пути дорожку с одной допустимой репликой и одной репликой из 81 кодовой точки Unicode. По ответу проверить, что файл содержит только допустимую реплику либо что файл отсутствует.

**Последствие.** T-7 и T-8 требуют отклонить реплику из 81 кодовой точки Unicode. Для непустой дорожки с допустимой и отклонённой репликами итог экспорта открыт. T-5 задаёт результат только для пустой дорожки.

**Уже установлено.** Экспорт направлен в локальный файл. Реплика из 81 кодовой точки Unicode подлежит отклонению. Правило сохранения состояния назначения относится к пустой дорожке. Основания — [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0015-01](#r-m0015-01), [R-M0010-01](#r-m0010-01).

**Открытое решение.** Определить итог экспорта непустой дорожки после отклонения одной из двух реплик.

**Что различит проверка.** По указанному пути создан файл только с допустимой репликой. / По указанному пути файл отсутствует.

<a id="z-002"></a>

### Z-002 · Где и в каком виде проверка экспорта должна обнаружить объявление миллисекунд для каждого поля временной метки?

**Предполагаемый пробел · Полнота · Существенная.** T-3 требует объявления миллисекунд для каждого поля и задаёт значение 1000 для одной секунды. По числу можно проверить шкалу, а для проверки объявления требуется определить его представление.

Затронутые утверждения — [R-M0008-01](#r-m0008-01).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать дорожку с временной меткой в одну секунду. Проверить значение 1000 и наличие объявления миллисекунд для каждого поля в согласованном месте и представлении.

**Последствие.** T-3 требует объявления миллисекунд для каждого поля и задаёт значение 1000 для одной секунды. По числу можно проверить шкалу, а для проверки объявления требуется определить его представление.

**Уже установлено.** Каждое поле объявляет миллисекунды. Одной секунде соответствует 1000. Правила кодировки и проверки BOM не определяют представление объявления. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

**Открытое решение.** Определить представление объявления миллисекунд, по которому приёмка проверит каждое поле.

**Что различит проверка.** Файл со значением 1000 и объявлением миллисекунд непосредственно в каждом поле проходит проверку, если согласовано такое представление. / Тот же файл не проходит проверку, если согласовано объявление единицы в отдельном описании каждого поля, которого в файле нет.

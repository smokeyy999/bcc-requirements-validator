### Z-001 · Где и в каком виде проверяющий должен увидеть объявление миллисекунд для каждого поля временной метки экспортированной дорожки?

**Предполагаемый пробел · Трассируемость · Существенная.** T-3 требует объявления миллисекунд для каждого поля и задаёт значение 1000 для одной секунды. Числовую шкалу можно проверить, а место и форму объявления ТЗ не определяет.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать дорожку с временной меткой в одну секунду. Проверить значение 1000 и по указанному источнику подтвердить, что для каждого поля временной метки объявлены миллисекунды.

**Последствие.** T-3 требует объявления миллисекунд для каждого поля и задаёт значение 1000 для одной секунды. Числовую шкалу можно проверить, а место и форму объявления ТЗ не определяет.

**Уже установлено.** Дорожка экспортируется в локальный файл. Для каждого поля требуются миллисекунды, одной секунде соответствует 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0003-02](#r-m0003-02).

**Открытое решение.** Указать, где проверяющий находит объявление единицы для каждого поля экспортированной дорожки.

**Что различит проверка.** В том же экспорте значение 1000 подтверждено, объявление миллисекунд проверяется в записи каждого поля. / В том же экспорте значение 1000 подтверждено, объявление миллисекунд для каждого поля проверяется в описании формата.

**Что различит проверка.** Проверяемая станция соответствует ST-1, и замер на ней учитывается при приёмке T-4. / Проверяемая станция не соответствует ST-1, и тот же замер не учитывается при приёмке T-4.

2. Указать, как однозначно опознать ST-1 для замера. ([Z-002](#z-002))

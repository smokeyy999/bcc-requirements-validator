## Проверка набора в целом

Обязательные правила ручной остановки и повторов передачи задают взаимоисключающие исходы. Для аварийной реакции отсутствует конечное положение клапана. Приёмка кнопки «Возобновить» требует согласованного шага и наблюдаемого результата. Для остальных испытаний нужно определить реакцию на корректное показание, критерии некорректности и категории омега, а также источник значения для панели.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. - [Z-004](#z-004) · Команда расписания входит в класс автоматических команд открытия. В ручной остановке W-1 требует игнорировать её, а W-2 требует немедленного открытия. Из-за противоположных исходов ручную остановку в этом сценарии принять нельзя.

### Z-001 · Какое правило определяет, должен ли закрытый клапан открыться при получении корректного показания влажности без ручной остановки и команды расписания?

**Предполагаемый пробел · Полнота · Существенная.** Работа по показаниям датчика заявлена. W-1 и W-2 описывают ручную остановку, а W-4 охватывает некорректные показания. Действие по корректному показанию в обычном режиме остаётся открытым.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/requirements.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** При закрытом клапане, без ручной остановки и команды расписания подать согласованное корректное показание датчика и сверить состояние клапана с правилом для этого показания.

**Последствие.** Работа по показаниям датчика заявлена. W-1 и W-2 описывают ручную остановку, а W-4 охватывает некорректные показания. Действие по корректному показанию в обычном режиме остаётся открытым.

**Уже установлено.** Контроллер использует показания влажности. Для некорректного показания предусмотрен аварийный перевод клапана. Основания — [R-M0003-01](#r-m0003-01), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01), [R-M0009-01](#r-m0009-01).

**Открытое решение.** Какое состояние клапана ожидается по выбранному корректному показанию в обычном режиме.

**Что различит проверка.** Клапан открывается. / Клапан остаётся закрытым.

### Z-002 · По какому критерию следует определять, что показание, полученное контроллером от датчика, некорректно для целей W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 задаёт действие при некорректном показании, но не определяет критерий некорректности. Возможность передачи числового нуля документом не установлена.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/requirements.md#L9)

> W-4. При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение.  

**Сценарий.** Подать одно фактически передаваемое датчиком спорное показание. Сверить применимость W-4 с согласованным критерием и при некорректном показании проверить обязательный аварийный перевод клапана.

**Что нужно уточнить.** Относится ли выбранное фактически передаваемое показание к некорректным по W-4.

**Как ответ изменит приёмку.** Если показание некорректно, аварийный перевод обязателен. Если оно корректно, W-4 для этого входа не срабатывает.

**Уже установлено.** Вход поступает от датчика. При некорректном значении контроллер обязан перевести клапан в аварийное положение. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** По какому признаку полученное показание подпадает под условие W-4.

**Что различит проверка.** Выбранное показание подпадает под W-4, и приёмка требует аварийного перевода. / То же показание находится вне области W-4, и приёмка по этому правилу не требует аварийного перевода.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке затронутых сценариев. Сначала требуется согласовать исход команды расписания при ручной остановке, аварийное положение клапана и число повторов после первого таймаута.

1. Установить единый исход для команды расписания при ручной остановке, задать аварийное положение клапана и согласовать одно число повторов после первого таймаута. ([Z-004](#z-004), [Z-008](#z-008), [Z-009](#z-009))
2. Определить обязательный шаг и наблюдаемый результат испытания кнопки «Возобновить» с учётом W-1. ([Z-005](#z-005))
3. Согласовать реакцию на корректное показание, критерий некорректности, признак категории омега и источник значения, передаваемого панели. ([Z-001](#z-001), [Z-002](#z-002), [Z-007](#z-007), [Z-003](#z-003))

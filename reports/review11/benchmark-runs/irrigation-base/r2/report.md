**Предполагаемый пробел · Полнота · Существенная.** Контроллер работает по показаниям влажности. W-4 задаёт реакцию на некорректное показание, а условия открытия по штатному показанию без команды расписания остаются открытыми.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

**Сценарий.** При выбранной зоне и выключенной ручной остановке подавать по одному согласованному штатному показанию без команды расписания. Перед каждой пробой закрывать клапан и сверять его положение с согласованным результатом.

**Последствие.** Контроллер работает по показаниям влажности. W-4 задаёт реакцию на некорректное показание, а условия открытия по штатному показанию без команды расписания остаются открытыми.

**Уже установлено.** Контроллер учитывает показания датчика, оператор выбирает одну зону, а некорректное показание требует аварийного закрытия. Основания — [R-M0003-01](#r-m0003-01), [R-M0008-01](#r-m0008-01), [R-M0009-01](#r-m0009-01), [R-M0007-01](#r-m0007-01).

**Открытое решение.** Установить, какие штатные показания сами запускают полив в заданных условиях.

**Что различит проверка.** Поданное штатное показание входит в условие запуска, и клапан открывается. / То же показание не входит в условие запуска, и клапан остаётся закрытым.

### Z-002 · Какой источник определяет значение, которое контроллер повторно передаёт панели после первого таймаута, и как получить из него ожидаемое содержимое передачи?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают три повтора. Источники показания и номера зоны описаны, но связь передаваемого значения с конкретным источником не установлена.

Затронутые утверждения — [R-M0013-01](#r-m0013-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Сценарий.** Задать показание датчика и номер зоны так, чтобы возможные значения для проверки различались. Вызвать первый таймаут, проверить ровно три повторные передачи и сверить их содержимое по указанному источнику.

**Последствие.** W-6 и W-7 задают три повтора. Источники показания и номера зоны описаны, но связь передаваемого значения с конкретным источником не установлена.

**Уже установлено.** Контроллер выполняет три повтора после первого таймаута. Показание задаёт датчик, номер зоны выбирает оператор. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Связать содержимое повторной передачи контроллера панели с источником, по которому его можно сверить.

**Что различит проверка.** Если источником назначено показание датчика, содержимое трёх повторов соответствует заданному показанию по согласованному правилу. / Если источником назначен номер зоны, содержимое тех же трёх повторов соответствует выбранному номеру по согласованному правилу.

### Z-003 · По какому критерию полученное от датчика показание следует считать некорректным для W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт результат «Аварийное положение — закрыто.». Открытым остаётся критерий, по которому полученное показание признаётся некорректным.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать одно и то же получаемое от датчика показание, классификация которого уточняется. Если оно некорректно по согласованному критерию, проверить закрытие клапана. В другой ветви исключить этот вход из проверки аварийного закрытия по W-4.

**Что нужно уточнить.** Подпадает ли полученное от датчика спорное показание под признак «некорректное».

**Как ответ изменит приёмку.** Для некорректного показания W-4 требует закрытия. При иной классификации этот вход находится вне области W-4.

**Уже установлено.** Вход поступает от датчика влажности. При получении некорректного значения клапан должен закрыться. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить, какие полученные показания относятся к некорректным.

**Что различит проверка.** Показание признано некорректным. Если клапан остался открыт, испытание по W-4 провалено. / То же показание находится вне области W-4. Открытый клапан в этой пробе не свидетельствует о нарушении W-4.

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Связано с вопросом к автору.** W-4 прямо задаёт результат «Аварийное положение — закрыто.». Открытым остаётся критерий, по которому полученное показание признаётся некорректным.

Связанные замечания — [Z-003](#z-003).

### R-M0013-01 · После первого таймаута контроллер выполняет ровно три повторные передачи значения на панель.

<a id="decision"></a>

## Готовность и порядок исправлений

Можно подготовить проверки выбора зоны, возобновления и числа повторов. Для четырёх уточняемых сценариев критерии приёмки пока неполны.

1. Установить критерий некорректного показания и положение открытого клапана при ручной остановке. ([Z-003](#z-003), [Z-004](#z-004))
2. Определить условия открытия клапана по штатному показанию без команды расписания. ([Z-001](#z-001))
3. Указать источник значения для сверки содержимого повторных передач. ([Z-002](#z-002))

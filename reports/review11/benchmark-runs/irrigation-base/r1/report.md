Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. **Какое положение должен принять закрытый клапан при одном заранее согласованном штатном показании влажности, если зона выбрана, ручная остановка не активна и команды расписания нет?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Подать то же штатное показание при закрытом клапане, выбранной зоне, неактивной ручной остановке и без команды расписания. Сверить положение клапана с согласованным результатом.

**По каким исходным данным и правилу определить значение, которое контроллер должен передать панели в исходной отправке и её трёх повторах?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Задать контрольные исходные данные, зафиксировать значение первой отправки и вызвать её таймаут. Проверить ровно три повтора и сверить значение в каждом с исходной отправкой и ожидаемым значением по согласованному правилу.

**Должен ли открытый клапан закрыться от самого нажатия ручной остановки, если новых команд нет?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Во время полива нажать ручную остановку при открытом клапане и проверить согласованное положение до следующей команды. Затем подать автоматическую команду открытия до нажатия «Возобновить» и проверить, что контроллер её игнорирует.

**По какому критерию контроллер должен распознавать некорректное значение датчика для применения W-4?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — При открытом клапане подать контрольное показание и классифицировать его по согласованному критерию. Если показание некорректно, проверить закрытие клапана по W-4. Если показание корректно, этот вход находится вне области проверки аварийного закрытия.

### Z-001 · Какое положение должен принять закрытый клапан при одном заранее согласованном штатном показании влажности, если зона выбрана, ручная остановка не активна и команды расписания нет?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер работает по показаниям датчика влажности. W-4 задаёт реакцию на некорректное значение, а ожидаемое положение клапана при штатном показании остаётся открытым.

**Сценарий.** Подать то же штатное показание при закрытом клапане, выбранной зоне, неактивной ручной остановке и без команды расписания. Сверить положение клапана с согласованным результатом.

**Последствие.** Контроллер работает по показаниям датчика влажности. W-4 задаёт реакцию на некорректное значение, а ожидаемое положение клапана при штатном показании остаётся открытым.

**Уже установлено.** Источник показания задан. Оператор выбирает зону. Аварийное закрытие предусмотрено для некорректного значения, а ручная остановка блокирует последующие автоматические открытия. ### Z-004 · По какому критерию контроллер должен распознавать некорректное значение датчика для применения W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт результат «Аварийное положение — закрыто». Критерий отнесения показания к некорректным отсутствует.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> W-4. При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать контрольное показание и классифицировать его по согласованному критерию. Если показание некорректно, проверить закрытие клапана по W-4. Если показание корректно, этот вход находится вне области проверки аварийного закрытия.

**Что нужно уточнить.** Относится ли выбранное контрольное показание к некорректным значениям по W-4?

**Как ответ изменит приёмку.** Для некорректного значения W-4 требует закрыть клапан. Для корректного значения W-4 не определяет положение клапана.

**Уже установлено.** Контроллер получает показание датчика. При некорректном значении он обязан закрыть клапан. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Принадлежность конкретного контрольного показания к некорректным значениям.

**Что различит проверка.** На этом показании проверка W-4 требует закрытия клапана. / Это показание находится вне области W-4 и не подходит для проверки аварийного закрытия.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Полные ожидаемые результаты приёмки управления клапаном и передачи значения на панель зависят от уточнений.

1. Определить положение открытого клапана после нажатия ручной остановки. ([Z-003](#z-003))
2. Задать критерий некорректности и отдельно определить ожидаемое положение клапана для согласованного штатного показания. ([Z-004](#z-004), [Z-001](#z-001))
3. Определить исходные данные и правило получения значения для передачи на панель. ([Z-002](#z-002))
4. Оставить W-6 единственным требованием о числе повторов после первого таймаута. ([Z-005](#z-005))

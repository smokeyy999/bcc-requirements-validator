## Проверка набора в целом

Главный пробел — реакция контроллера на корректные показания влажности. Отдельного решения требуют критерий некорректности, состояние клапана при ручной остановке активного полива и источник значения для панели. Число повторных передач определено двумя требованиями.

Открытых предполагаемых пробелов — 3. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Вопросы к автору ТЗ

Вопросы приведены в порядке согласования. Автор ТЗ фиксирует решение, затем QA проверяет указанный сценарий.

### Согласовать до приёмки

**Какое действие должен выполнить контроллер для штатного показания влажности при закрытом клапане и выбранной зоне?**

Блокирует приёмку · [Z-001](#z-001). Зависимый сценарий — Подать согласованное штатное показание и сверить действие контроллера с заданным правилом.

### Уточнить ожидаемое поведение

**Из какого исходного значения контроллер формирует значение, передаваемое на панель по W-6?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Подготовить входные данные, для которых возможные источники дают разные ожидаемые значения. Вызвать первый таймаут передачи на панель и сверить содержимое всех трёх повторных передач со значением из указанного источника.

**Должен ли уже открытый клапан закрыться в результате нажатия кнопки ручной остановки? Последующие автоматические команды открытия в любом случае игнорируются до возобновления.**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Открыть клапан, нажать кнопку ручной остановки и до следующей команды проверить, закрылся ли клапан вследствие нажатия.

**По какому критерию W-4 относит полученное показание к некорректным?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — При открытом клапане подать одно и то же спорное показание и проверить его по заданному критерию. Если клапан остаётся открытым, оценить этот результат по W-4.

### Z-002 · Из какого исходного значения контроллер формирует значение, передаваемое на панель по W-6?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают три повтора передачи на панель. Зависимость управления от показаний датчика сама по себе не устанавливает источник передаваемого значения.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/baseline.md#L14)

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Сценарий.** Подготовить входные данные, для которых возможные источники дают разные ожидаемые значения. Вызвать первый таймаут передачи на панель и сверить содержимое всех трёх повторных передач со значением из указанного источника.

**Последствие.** W-6 и W-7 задают три повтора передачи на панель. Зависимость управления от показаний датчика сама по себе не устанавливает источник передаваемого значения.

**Уже установлено.** Контроллер трижды повторяет передачу на панель после первого таймаута. Показания датчика используются для управления поливом. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Установить связь между значением в передаче на панель и исходными данными контроллера.

**Что различит проверка.** Все три повтора содержат значение, ожидаемое по заданному показанию датчика. / Все три повтора содержат другое значение, ожидаемое по указанному автором источнику при тех же входных данных.

**Что различит проверка.** Клапан закрывается вследствие нажатия. / Клапан остаётся открытым до поступления новой команды в испытании.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке штатного управления поливом до определения реакции на корректные показания.

1. Задать правило управления клапаном по корректным показаниям влажности. ([Z-001](#z-001))
2. Определить критерий некорректности показания для проверки аварийного закрытия. ([Z-004](#z-004))
3. Определить состояние уже открытого клапана сразу после ручной остановки. ([Z-003](#z-003))
4. Указать источник значения для проверки повторных передач на панель. ([Z-002](#z-002))
5. Удалить дублирующее W-7 и сохранить правило в W-6. ([Z-005](#z-005))

## Проверка набора в целом

ТЗ задаёт выбор зоны, аварийное закрытие, блокировку последующих команд, возобновление и число повторов передачи. Для приёмки требуется определить критерий некорректного показания, правило начала полива, положение клапана после ручной остановки и источник значения для панели.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Уточнить ожидаемое поведение

**При каких корректных показаниях влажности контроллер должен начать полив выбранной зоны, если клапан закрыт и ручная остановка снята?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Выбрать зону на панели, закрыть клапан и снять ручную остановку. Подать фиксированное корректное показание и проверить, открывается ли клапан выбранной зоны по согласованному правилу.

**Какую величину контроллер передаёт на панель и по какому источнику определить её ожидаемое значение для сверки повторов?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Подать известное показание датчика и вызвать таймаут первой передачи на панель. Проверить ровно три повтора и сверить содержимое каждого с одним и тем же значением, определённым по согласованному источнику для первой передачи.

**В каком положении должен быть уже открытый клапан после обработки нажатия кнопки ручной остановки, до следующей команды?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Во время полива нажать кнопку ручной остановки и проверить положение клапана после обработки нажатия, до следующей команды. Затем подать команду открытия от расписания и проверить, что она игнорируется до возобновления.

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — При открытом клапане подать фиксированное показание и по согласованному критерию определить, подпадает ли оно под W-4. Для показания, подпадающего под W-4, проверить переход в положение «закрыто».

### Z-004 · По какому критерию контроллер относит показание датчика к некорректным значениям в W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт результат «Аварийное положение — закрыто.» Для выбора входа приёмки нужен критерий некорректности показания.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать фиксированное показание и по согласованному критерию определить, подпадает ли оно под W-4. Для показания, подпадающего под W-4, проверить переход в положение «закрыто».

**Что нужно уточнить.** Относится ли фиксированное показание к некорректным значениям по W-4.

**Как ответ изменит приёмку.** Для некорректного показания закрытие обязательно. При иной классификации этот вход находится вне аварийного сценария W-4.

**Уже установлено.** Показание поступает от датчика влажности. При некорректном значении контроллер обязан закрыть клапан. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Относится ли фиксированное показание к некорректным по критерию W-4.

**Что различит проверка.** Показание подходит для приёмки W-4, ожидаемый результат — закрытие клапана. / То же показание находится вне области W-4, поэтому для приёмки перехода нужен другой вход.

## Готовность и порядок исправлений

Можно подготовить проверки уже заданных исходов. Для полной приёмки автоматики и обмена с панелью нужны уточнения.

1. Определить критерий некорректного показания и положение уже открытого клапана после ручной остановки. ([Z-004](#z-004), [Z-003](#z-003))
2. Задать правило начала полива по корректному показанию. ([Z-001](#z-001))
3. Указать источник ожидаемого значения для сверки передачи на панель. ([Z-002](#z-002))
4. Объединить W-6 и W-7, сохранив ровно три повтора после первого таймаута. ([Z-005](#z-005))

## Проверка набора в целом

Заданы блокировка последующих команд открытия, возобновление, закрытие при некорректном показании и три повтора передачи. Требуется уточнить реакцию на корректную влажность, признак некорректного показания, эффект ручной остановки при открытом клапане и источник значения для панели.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-004 · По какому критерию конкретное показание датчика считается некорректным для применения W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт конечное положение словами «Аварийное положение — закрыто». Для конкретного показания требуется критерий применимости W-4.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать конкретное показание, проверяемое по согласованному критерию. Если оно некорректно, проверить переход в закрытое положение. Если оно корректно, оценивать реакцию по правилу для корректных показаний.

**Что нужно уточнить.** Относится ли конкретное поданное показание к некорректным по W-4.

**Как ответ изменит приёмку.** Для некорректного показания закрытие обязательно. Для корректного положение клапана определяется вне W-4.

**Уже установлено.** Для заведомо некорректного показания W-4 требует закрытого положения клапана. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить, подпадает ли конкретное показание под обозначение «некорректное значение датчика».

**Что различит проверка.** Показание подпадает под W-4, и открытый клапан должен закрыться. / Показание вне области W-4, и приёмка по W-4 для этого входа не требует закрытия.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Возобновление, блокировку следующих команд и число повторов можно проверять по текущему тексту. Для полной приёмки управления клапаном и проверки содержимого обмена нужны ответы автора.

1. Определить положение открытого клапана сразу после обработки ручной остановки. ([Z-003](#z-003))
2. Задать критерий некорректности и отдельно определить реакцию на корректное показание в проверяемом сценарии. ([Z-004](#z-004), [Z-002](#z-002))
3. Связать значение в передаче на панель с его источником и проверить содержимое всех трёх повторов. ([Z-001](#z-001))
4. Оставить правило о трёх повторах после первого таймаута в одном требовании. ([Z-005](#z-005))

## Проверка набора в целом

ТЗ задаёт аварийное закрытие, подавление автоматического открытия до возобновления и три повтора передачи. Для приёмки остаётся определить критерий некорректности, реакцию на корректное показание, положение открытого клапана при ручной остановке и источник значения для панели.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 1.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Уточнить ожидаемое поведение

**По какому правилу определить, откроется ли закрытый клапан выбранной зоны при получении корректного показания, если ручная остановка не активна и команд расписания нет?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Выбрать зону, закрыть клапан, обеспечить отсутствие ручной остановки и команд расписания, подать одно фиксированное корректное показание и сверить состояние клапана с согласованным правилом.

**Из какого источника контроллер берёт значение, которое передаёт панели и повторно отправляет после первого таймаута?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Задать известные различимые значения для проверяемых источников, вызвать таймаут первой передачи и проверить, что контроллер отправил ровно три повтора со значением из согласованного источника.

**По какому критерию полученное значение датчика считается некорректным для W-4?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — При открытом клапане подать одно фиксированное показание. Если оно некорректно по согласованному критерию, проверить закрытие клапана. Если оно корректно, оценивать результат по правилу для корректных показаний.

**Должен ли уже открытый клапан закрыться при нажатии кнопки ручной остановки до поступления следующей команды?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — Во время полива нажать кнопку ручной остановки при открытом клапане и проверить его согласованное положение до следующей команды. Затем подать автоматическую команду открытия от расписания и проверить, что до возобновления она игнорируется.

### Z-001 · По какому правилу определить, откроется ли закрытый клапан выбранной зоны при получении корректного показания, если ручная остановка не активна и команд расписания нет?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер работает по показаниям влажности. W-4 задаёт положение клапана при некорректном показании, а для корректного показания результат остаётся открытым.

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** Выбрать зону, закрыть клапан, обеспечить отсутствие ручной остановки и команд расписания, подать одно фиксированное корректное показание и сверить состояние клапана с согласованным правилом.

**Последствие.** Контроллер работает по показаниям влажности. W-4 задаёт положение клапана при некорректном показании, а для корректного показания результат остаётся открытым.

**Уже установлено.** Полив относится к выбранной зоне. W-4 задаёт закрытие при некорректном показании, а W-5 задаёт исполнение очередной команды открытия после возобновления. Основания — [R-M0003-01](#r-m0003-01), [R-M0007-01](#r-m0007-01), [R-M0008-01](#r-m0008-01), [R-M0009-01](#r-m0009-01), [R-M0010-01](#r-m0010-01).

**Открытое решение.** Определить состояние клапана для фиксированного корректного показания в заданном сценарии.

**Что различит проверка.** После получения показания клапан открывается. / После получения того же показания клапан остаётся закрытым.

**Последствие.** W-6 и W-7 задают ровно три повтора передачи значения панели. Связь содержимого передачи с конкретным источником данных отсутствует.

**Уже установлено.** Контроллер использует показание датчика влажности, оператор выбирает номер зоны на панели, а после первого таймаута контроллер повторяет передачу значения ровно три раза. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0008-01](#r-m0008-01).

**Что различит проверка.** Если источником назначено показание датчика, во всех трёх повторах передано заданное показание. / Если источником назначен номер выбранной зоны, во всех трёх повторах передан заданный номер зоны.

### Z-003 · По какому критерию полученное значение датчика считается некорректным для W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт результат: «Аварийное положение — закрыто.» Для конкретного показания остаётся определить, подпадает ли оно под условие закрытия.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать одно фиксированное показание. Если оно некорректно по согласованному критерию, проверить закрытие клапана. Если оно корректно, оценивать результат по правилу для корректных показаний.

**Что нужно уточнить.** Подпадает ли фиксированное показание датчика под критерий некорректности W-4.

**Как ответ изменит приёмку.** Для некорректного показания приёмка по W-4 требует закрытия клапана. Для корректного показания проверка W-4 неприменима.

**Уже установлено.** Получение некорректного значения датчика обязывает контроллер закрыть клапан. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить, какие полученные значения датчика относятся к некорректным.

**Что различит проверка.** Для фиксированного показания, признанного некорректным, открытый клапан должен закрыться. / Для того же показания, признанного корректным, проверка закрытия по W-4 неприменима.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Для приёмки указанных сценариев нужны четыре уточнения.

1. Определить критерий некорректности показаний и правило управления клапаном по корректным показаниям. ([Z-003](#z-003), [Z-001](#z-001))
2. Зафиксировать положение открытого клапана после нажатия ручной остановки. ([Z-004](#z-004))
3. Указать источник значения для панели и проверить содержимое всех трёх повторов. ([Z-002](#z-002))
4. Оставить одну формулировку правила о трёх повторах после первого таймаута. ([Z-005](#z-005))

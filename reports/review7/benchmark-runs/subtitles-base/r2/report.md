### Z-002 · Объявление единицы временной метки

**Неоднозначность · Однозначность · Существенная.** T-3 задаёт миллисекунды и число 1000 для одной секунды. Оборот «Each timestamp field declares milliseconds» допускает объявление единицы в самом поле файла или в описании поля формата. От этого зависит приёмка числового поля.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать метку в одну секунду и проверить число 1000. По согласованному правилу определить, проходит ли проверку поле, для которого миллисекунды объявлены только в описании формата.

**Последствие.** Один проверяющий примет числовое поле, другой потребует объявить единицу в файле.

**Уже установлено.** Единица каждого поля временной метки — миллисекунды. Одна секунда представляется числом 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Определить, где достаточно объявить единицу каждого поля временной метки.

**Что различит проверка.** Поле с числом 1000 не проходит проверку, поскольку в файле нет объявления единицы для этого поля. / Поле с числом 1000 проходит проверку, поскольку миллисекунды объявлены в описании поля формата.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Достаточно ли объявить миллисекунды в описании каждого поля формата или объявление единицы должно присутствовать в экспортированном файле для каждого поля временной метки?

1. **Вариант 1.** Для каждого поля временной метки единица объявляется в экспортированном файле.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Поле с числом 1000 без объявления единицы в файле не проходит проверку.

2. **Вариант 2.** Миллисекунды объявляются в описании каждого поля формата, а в файле достаточно числового значения.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Поле с числом 1000 проходит проверку единицы и значения для метки в одну секунду.

**Черновик приёмочного теста.** Экспортировать метку в одну секунду и проверить число 1000. По согласованному правилу определить, проходит ли проверку поле, для которого миллисекунды объявлены только в описании формата.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Для двух сценариев ожидаемые результаты приёмки требуют уточнения.

1. Указать, где объявляются миллисекунды для каждого поля временной метки. ([Z-002](#z-002))
2. Задать состояние существующего файла при экспорте дорожки с допустимой и отклонённой репликами. ([Z-001](#z-001))

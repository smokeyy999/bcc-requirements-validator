### Z-002 · Объявление единицы времени в экспорте

**Неоднозначность · Однозначность · Существенная.** T-3 фиксирует значение 1000 для одной секунды. Фраза о единице поля допускает объявление в описании формата или в самом файле, поэтому приёмка поля с одним числом зависит от прочтения.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second  

**Сценарий.** Экспортировать отметку в одну секунду. Поле в файле содержит число 1000 без явного обозначения единицы.

**Последствие.** Один и тот же файл проходит или не проходит проверку T-3 в зависимости от трактовки объявления единицы.

**Уже установлено.** Для каждого поля задана единица в миллисекундах. Одна секунда представляется числом 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Достаточно ли объявления миллисекунд в описании формата или оно должно присутствовать в экспортированном файле для каждого поля.

**Что различит проверка.** Поле с числом 1000 без обозначения единицы проходит проверку T-3. / То же поле не проходит проверку T-3 из-за отсутствия объявления единицы в файле.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Должен ли файл с числом 1000 без явного объявления единицы проходить проверку T-3? Если объявление обязательно, по какому признаку его проверять для каждого поля?

1. **Вариант 1.** Единица каждого поля задана спецификацией. В экспортированном поле достаточно числа в миллисекундах.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Поле с числом 1000 проходит проверку.

2. **Вариант 2.** Единица каждого поля должна быть явно объявлена в экспортированном файле.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Поле с числом 1000 без объявления единицы не проходит проверку.

**Черновик приёмочного теста.** Проверить число 1000 для отметки в одну секунду и применить выбранный критерий объявления единицы к каждому полю времени.

### Z-003 · Какая рабочая станция обозначена как ST-1 в T-4?

**Предполагаемый пробел · Ясность · Существенная.** T-4 задаёт измеряемый предел, начало и конец замера и число реплик. Для выбора применимого замера требуется идентифицировать ST-1.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Subtitle track export / Format · [строка 9](../../../../../benchmark/subtitles/baseline.md#L9)

> For a track with 100 cues on workstation ST-1, show the completion dialog no later than 2 seconds after the export command.  

**Сценарий.** На станции, идентифицированной как ST-1, экспортировать дорожку из 100 допустимых реплик. Измерить время от команды экспорта до появления диалога завершения и проверить предел в 2 секунды.

**Что нужно уточнить.** Неизвестно, какая из использованных для замера рабочих станций соответствует обозначению ST-1.

**Как ответ изменит приёмку.** Если ST-1 дала результат до 2 секунд включительно, сценарий проходит проверку. Если результат ST-1 превышает 2 секунды, сценарий её проваливает.

**Уже установлено.** Критерий T-4 применяется на ST-1 к дорожке из 100 реплик. Диалог завершения должен появиться не позднее 2 секунд после команды экспорта. Основания — [R-M0009-01](#r-m0009-01).

**Открытое решение.** Какую рабочую станцию считать ST-1.

**Что различит проверка.** К T-4 относится замер на станции, где диалог появился в пределах 2 секунд. Проверка проходит. / К T-4 относится замер на станции, где диалог появился позже 2 секунд. Проверка проваливается.

> Reject a cue when its text exceeds 80 Unicode code points.

## Готовность и порядок исправлений

Разработку однозначно описанных сценариев можно начать. Критерии приёмки по трём открытым вопросам требуют уточнения.

1. Задать итог экспорта при отклонении части и всех реплик исходно непустой дорожки. ([Z-001](#z-001))
2. Уточнить, где объявляются миллисекунды для полей времени. ([Z-002](#z-002))
3. Идентифицировать ST-1 для замера времени экспорта. ([Z-003](#z-003))

Проверить отклонение длинной реплики, появление диалога не позднее чем через 2 секунды после команды и согласованный итог по пути назначения.

**По какому признаку в экспортированном файле проверяющий должен установить, что для каждого поля объявлены миллисекунды?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Проверить значение 1000 для метки в одну секунду и проверить объявление миллисекунд по согласованному признаку.

### Z-002 · Объявление единицы временной метки

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 требует объявления миллисекунд для каждого поля. Пример со значением 1000 проверяет числовое представление одной секунды, а критерий проверки объявления единицы в файле отсутствует.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать дорожку с временной меткой в одну секунду и проверить соответствующее поле со значением 1000.

**Последствие.** Проверяющий может подтвердить числовое значение, но не может определить, выполнено ли требование об объявлении единицы.

**Уже установлено.** Каждое поле объявляет миллисекунды, а метка в одну секунду имеет числовое значение 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Определить, какой признак в файле подтверждает объявление миллисекунд для каждого поля.

**Что различит проверка.** Файл со значением 1000 и текстовым обозначением миллисекунд при каждом поле проходит проверку, если такого обозначения достаточно. / Тот же файл не проходит проверку, если для объявления миллисекунд требуется отдельный атрибут поля.

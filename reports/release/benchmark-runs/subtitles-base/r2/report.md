## Готовность и порядок исправлений

Основные правила экспорта готовы к разработке. Ожидаемые результаты двух приёмочных проверок требуют уточнения.

1. Определить ожидаемое состояние файла назначения при экспорте смешанной дорожки. ([Z-002](#z-002))
2. Указать, по какому элементу формата проверяется объявление миллисекунд для каждого поля. ([Z-001](#z-001))

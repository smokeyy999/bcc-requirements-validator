### Уточнить ожидаемое поведение

**При экспорте по новому пути дорожки с репликами длиной 80 и 81 кодовая точка Unicode должен ли появиться файл с 80-точечной репликой или файл не создаётся?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — В примере T-8 проверить, что реплика из 81 кодовой точки Unicode отсутствует в результате экспорта. Отдельно экспортировать по новому пути дорожку с двумя различимыми репликами из 80 и 81 кодовой точки Unicode. По согласованному правилу проверить, что файл либо содержит только реплику из 80 кодовых точек, либо отсутствует.

## Проверка набора в целом

ТЗ задаёт выбор зоны, блокировку автоматических открытий, возобновление, аварийное положение и число повторов. Для приёмки нужно определить штатную реакцию на показания, критерий аварийного срабатывания, действие остановки при открытом клапане и значение для панели. Критерий числа повторов продублирован.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Вопросы к автору ТЗ

### Уточнить ожидаемое поведение

**При каких корректных показаниях влажности контроллер должен начать полив выбранной зоны в штатном режиме?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — При закрытом клапане выбрать зону по номеру на панели, вывести контроллер из ручной остановки и подать конкретное корректное показание. По согласованному правилу проверить, начинается ли полив выбранной зоны.

**Какое значение контроллер должен передавать панели и по каким исходным данным его определить для проверки?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Задать различающиеся показание влажности и номер выбранной зоны. Определить ожидаемое значение по согласованному источнику, сверить с ним исходную передачу и проверить, что после первого таймаута контроллер трижды передаёт то же значение.

**В каком положении должен быть уже открытый клапан после нажатия ручной остановки и до следующей команды?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Во время полива нажать ручную остановку и сверить положение клапана до следующей команды с ответом. Затем проверить, что до нажатия «Возобновить» автоматические команды открытия игнорируются.

**По какому критерию контроллер должен считать показание датчика некорректным?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — При открытом клапане подать конкретное показание, классификация которого зависит от ответа. По согласованному критерию определить применимость W-4 и, если показание некорректно, проверить закрытие клапана.

Принадлежность расписания к автоматическим источникам не меняет этот исход и нужна лишь для установления того, требуется ли полное игнорирование команды также по W-1.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Уже заданные сценарии можно реализовывать и проверять. Для полной приёмки нужны ответы по открытым сценариям управления и обмена.

1. Определить критерий некорректного показания и правило начала полива при корректных показаниях. ([Z-004](#z-004), [Z-001](#z-001))
2. Задать положение открытого клапана сразу после ручной остановки. ([Z-003](#z-003))
3. Определить значение для панели и источник ожидаемого значения в проверке обмена. ([Z-002](#z-002))
4. Объединить W-6 и W-7 и привязать к единому требованию проверку трёх повторов. ([Z-005](#z-005))

## Проверка набора в целом

В ТЗ заданы несовместимые исходы отправки черновика и ведомости из 25 строк. Для срока хранения при значении 7 указаны два масштаба, для показа «Передано» отсутствует предел задержки. Ссылка S-97 не имеет адресата. Текст сообщения при отказе и состояние ведомости заданы в S-7.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-001](#z-001) · S-1 запрещает отправку черновика, а S-2 требует передачи при той же попытке. Для проверки доставки перевозчику заданы взаимоисключающие исходы.
- [Z-002](#z-002) · S-3 ограничивает состав ведомости 24 строками, а S-4 прямо разрешает отправку загруженной ведомости из 25 строк. Выполнение требования к состоянию сохраняет оба предписания для одной ведомости.

## Вопросы к автору ТЗ

### Согласовать до приёмки

**При попытке отправки черновика перевозчик должен получить ведомость или передача должна быть запрещена?**

Блокирует приёмку · [Z-001](#z-001). Зависимый сценарий — Попытаться отправить черновик и проверить наличие передачи на стороне перевозчика.

**Разрешать ли отправку загруженной ведомости из 25 строк, если условие «Готова» выполнено, или для неё действует предел в 24 строки?**

Блокирует приёмку · [Z-002](#z-002). Зависимый сценарий — Загрузить файл из 25 строк и проверить, допускает ли терминал его к отправке при выполненном условии состояния.

Требует уточнения · [Z-005](#z-005). Зависимый сценарий — Задать значение 7, сохранить подтверждение и проверить, истёк ли срок хранения через сутки.

> При попытке отправить ведомость в состоянии «Черновик» терминал сразу передаёт её перевозчику.

**Последствие.** Нельзя принять реализацию отправки черновика по единому ожидаемому результату.

**Общее условие.** Оператор пытается отправить сохранённую ведомость в состоянии «Черновик» при исправных сети и авторизации. Основания — [R-M0006-01](#r-m0006-01) «Оператор может отправить ведомость только в состоянии «Готова».», [R-M0007-02](#r-m0007-02) «При попытке отправить ведомость в состоянии «Черновик» терминал сразу передаёт её перевозчику.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** При попытке отправки черновика перевозчик должен получить ведомость или передача должна быть запрещена?

1. **Вариант 1.** Оператор может отправить ведомость только в состоянии «Готова».

   **Основание.** [R-M0006-01](#r-m0006-01) «Оператор может отправить ведомость только в состоянии «Готова».».

   **Ожидаемый результат.** Перевозчик не получает черновик.

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

2. **Вариант 2.** При попытке отправить ведомость в состоянии «Черновик» терминал сразу передаёт её перевозчику.

   **Основание.** [R-M0007-02](#r-m0007-02) «При попытке отправить ведомость в состоянии «Черновик» терминал сразу передаёт её перевозчику.».

   При выборе этого варианта привести в соответствие [R-M0006-01](#r-m0006-01).

   **Ожидаемый результат.** Отправка ведомости из 25 строк доступна.

   При выборе этого варианта привести в соответствие [R-M0010-01](#r-m0010-01).

## Готовность и порядок исправлений

ТЗ не готово к разработке отправки. Сначала нужно согласовать обязательные исходы для черновика и ведомости из 25 строк.

1. Согласовать, получает ли перевозчик черновик при попытке отправки. ([Z-001](#z-001))
2. Согласовать предел числа строк с допуском ведомости из 25 строк к отправке в состоянии «Готова». ([Z-002](#z-002))
3. Установить единый срок локального хранения подтверждения для значения 7. ([Z-005](#z-005))
4. Задать максимальный интервал от получения подтверждения перевозчика до показа «Передано». ([Z-004](#z-004))
5. Исправить внутреннюю ссылку S-97. ([Z-006](#z-006))

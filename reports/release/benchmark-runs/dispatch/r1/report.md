Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. ### R-M0006-01 · Отправка разрешена только для ведомости в состоянии «Готова».

## Готовность и порядок исправлений

ТЗ не готово к передаче в разработку. Для трёх обязательных сценариев нужно установить однозначные ожидаемые исходы.

1. Согласовать единый исход попытки отправки черновика. ([Z-001](#z-001))
2. Согласовать допустимость отправки ведомости из 25 строк и проверять разрешение на отправку отдельно от приёма файла. ([Z-003](#z-003))
3. Согласовать объявленную единицу хранения с расшифровкой значения 7. ([Z-005](#z-005))
4. Задать событие начала отсчёта и допустимый интервал до показа «Передано». ([Z-004](#z-004))
5. Исправить внутреннюю ссылку S-97. ([Z-006](#z-006))

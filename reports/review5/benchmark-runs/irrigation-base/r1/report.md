## Проверка набора в целом

ТЗ задаёт аварийное закрытие, блокировку последующих открытий при ручной остановке, возобновление, выбор зоны и число повторов. Для полной приёмки нужно уточнить классификацию показаний, реакцию на корректное показание, эффект остановки при открытом клапане и источник значения для панели. Число повторов описано дважды.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Готовность и порядок исправлений

ТЗ готово к частичной разработке и проверке явно заданных правил. Полная приёмка автоматики и содержимого обмена с панелью требует уточнений.

1. Определить критерий применения аварийного закрытия и положение открытого клапана после ручной остановки. ([Z-003](#z-003), [Z-004](#z-004))
2. Задать реакцию автоматики на корректные показания влажности. ([Z-001](#z-001))
3. Указать, из каких данных определяется значение, передаваемое панели. ([Z-002](#z-002))
4. Оставить одно требование о трёх повторах после первого таймаута. ([Z-005](#z-005))

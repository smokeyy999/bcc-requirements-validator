## Проверка набора в целом

Для штатного полива требуется правило управления клапаном по корректным показаниям. Для аварийного закрытия требуется определить, какие показания считаются некорректными. Отдельно нужно определить положение открытого клапана при ручной остановке и источник значения, передаваемого панели.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Задать различимые значения для входов и состояний, включая показание датчика и номер выбранной зоны. Вызвать первый таймаут передачи на панель и проверить, что во всех трёх повторах передано значение, определённое по указанному источнику.

**Какое положение должен занять уже открытый клапан после нажатия кнопки ручной остановки, если других команд нет и блокировка последующих автоматических команд открытия действует до возобновления?**

**Какие показания датчика относятся к некорректным по W-4?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — При открытом клапане подать фиксированное пограничное показание. По согласованному критерию определить применимость W-4. Если правило применимо, проверить закрытие клапана.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

**Последствие.** Работа по показаниям датчика заявлена. W-3 задаёт выбор зоны, W-4 задаёт аварийное закрытие. Без правила для корректных показаний невозможно принять штатное управление поливом по датчику.

**Что различит проверка.** При одном и том же корректном показании исходно закрытый клапан открывается. / При том же показании исходно закрытый клапан остаётся закрытым.

### Z-002 · Из какого входа или состояния контроллер определяет значение, которое передаёт панели и повторяет ровно три раза после первого таймаута?

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Сценарий.** Задать различимые значения для входов и состояний, включая показание датчика и номер выбранной зоны. Вызвать первый таймаут передачи на панель и проверить, что во всех трёх повторах передано значение, определённое по указанному источнику.

**Последствие.** W-6 и W-7 задают три повтора передачи на панель. Источник значения в передаче не указан, поэтому ожидаемое содержимое повторов нельзя вывести из заданных входов.

**Уже установлено.** Контроллер передаёт значение панели и повторяет передачу трижды после первого таймаута. Показание влажности приходит от датчика, номер зоны задаёт оператор. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0008-01](#r-m0008-01).

**Открытое решение.** Установить связь между источником значения у контроллера и содержимым передачи на панель.

**Что различит проверка.** Если источником выбрано показание датчика, каждый повтор содержит значение, определённое по этому показанию. / Если источником выбрана зона, каждый повтор содержит значение, определённое по номеру выбранной зоны.

### Z-004 · Какие показания датчика относятся к некорректным по W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 однозначно предписывает закрыть клапан при некорректном показании. Критерий принадлежности показания к этой категории отсутствует.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать фиксированное пограничное показание. По согласованному критерию определить применимость W-4. Если правило применимо, проверить закрытие клапана.

**Что нужно уточнить.** Входит ли проверяемое граничное показание датчика в категорию некорректных по W-4?

**Как ответ изменит приёмку.** Если показание некорректно, W-4 требует закрытия клапана. Если показание корректно, W-4 к нему неприменимо.

**Уже установлено.** W-4 требует закрыть клапан при некорректном показании датчика. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить, какие показания подпадают под обозначение «некорректное значение датчика» в W-4.

**Что различит проверка.** Если вход отнесён к некорректным и клапан остался открытым, проверка W-4 провалена. / Если тот же вход отнесён к корректным и клапан остался открытым, проверка W-4 к этому входу неприменима.

### R-M0013-01 · После первого таймаута контроллер выполняет ровно три повторные передачи значения на панель.

Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Связано с вопросом к автору.** W-6 и W-7 задают три повтора передачи на панель. Источник значения в передаче не указан, поэтому ожидаемое содержимое повторов нельзя вывести из заданных входов. Фразы «ровно три раза после первого таймаута» и «равно трём» задают точное число повторов после срабатывания триггера. По этим формулировкам даже при успехе первого повтора выполняются ещё два.

## Готовность и порядок исправлений

ТЗ требует уточнений до разработки штатного управления по датчику. Для приёмки нужно определить применимость аварийного закрытия к проверяемым показаниям, положение открытого клапана после ручной остановки и содержимое повторных передач на панель.

1. Задать критерий корректности показаний и ожидаемое положение клапана для корректных входов. ([Z-001](#z-001), [Z-004](#z-004))
2. Определить положение уже открытого клапана при ручной остановке. ([Z-003](#z-003))
3. Указать источник значения для передачи на панель и проверки содержимого трёх повторов. ([Z-002](#z-002))

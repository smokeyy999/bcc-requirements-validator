### Z-001 · Каков результат экспорта на новый локальный путь, если в дорожке один допустимый субтитр и один отклоняемый субтитр из 81 кодовой точки Unicode?

**Предполагаемый пробел · Полнота · Существенная.** T-7 и T-8 требуют отклонить субтитр из 81 кодовой точки Unicode. T-5 задаёт состояние назначения только для пустой дорожки. Результат экспорта смешанной дорожки остаётся открытым.

[R-M0015-01](#r-m0015-01) · Subtitle track export / Export limits · [строка 15](../../../../../benchmark/subtitles/baseline.md#L15)

> In the acceptance sample, a cue of 81 Unicode code points is rejected.  

**Сценарий.** Экспортировать такую дорожку на новый локальный путь. Проверить наличие файла по согласованному результату. Если файл создан, сверить его состав и убедиться, что отклонённый субтитр отсутствует.

**Последствие.** T-7 и T-8 требуют отклонить субтитр из 81 кодовой точки Unicode. T-5 задаёт состояние назначения только для пустой дорожки. Результат экспорта смешанной дорожки остаётся открытым.

**Уже установлено.** Субтитр из 81 кодовой точки Unicode отклоняется. Сохранение состояния назначения предписано для пустой дорожки. Основания — [R-M0014-01](#r-m0014-01), [R-M0003-02](#r-m0003-02), [R-M0010-02](#r-m0010-02), [R-M0015-01](#r-m0015-01).

**Открытое решение.** Результат команды экспорта смешанной дорожки после отклонения субтитра.

**Что различит проверка.** По новому пути создан файл только с допустимым субтитром. / По новому пути файл не создан.

### Z-002 · Как в экспортированном файле представлено объявление миллисекунд для каждого поля временной метки?

**Предполагаемый пробел · Полнота · Существенная.** T-3 требует объявления миллисекунд для каждого поля и задаёт значение 1000 для одной секунды. Представление объявления в файле остаётся открытым.

Затронутые утверждения — [R-M0008-01](#r-m0008-01).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

**Сценарий.** Экспортировать дорожку с меткой в одну секунду. Сверить числовое значение 1000 для этой метки и проверить объявление миллисекунд для каждого поля по согласованному представлению.

**Последствие.** T-3 требует объявления миллисекунд для каждого поля и задаёт значение 1000 для одной секунды. Представление объявления в файле остаётся открытым.

**Уже установлено.** Файл записывается в UTF-8 без BOM. Каждое поле объявляет миллисекунды, одна секунда представлена числом 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0006-01](#r-m0006-01).

**Открытое решение.** Представление объявления единицы для каждого поля временной метки в файле.

**Что различит проверка.** Миллисекунды объявлены в имени каждого поля, метка в одну секунду имеет значение 1000. / Миллисекунды объявлены отдельным атрибутом каждого поля, метка в одну секунду имеет значение 1000.

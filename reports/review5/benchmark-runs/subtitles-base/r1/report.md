### Z-001 · Каким должен быть существующий файл назначения после экспорта дорожки с одной допустимой репликой и одной отклонённой репликой из 81 кодовой точки Unicode?

**Сценарий.** Экспортировать такую дорожку в файл с заранее известным содержимым, отличным от экспорта допустимой реплики. Сверить итоговое содержимое с ответом автора и проверить, что отклонённая реплика не записана.

### Z-002 · Где и по какой записи проверяющий должен подтверждать объявление миллисекунд для каждого поля временной метки?

**Предполагаемый пробел · Трассируемость · Низкая.** T-3 задаёт миллисекунды для каждого поля и значение 1000 для одной секунды. Для проверки объявления единицы остаётся определить, где и в каком виде его искать.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать непустую дорожку с меткой в одну секунду. Проверить значение 1000 и для каждого поля найти применимое к нему объявление миллисекунд в согласованном месте и виде.

**Последствие.** T-3 задаёт миллисекунды для каждого поля и значение 1000 для одной секунды. Для проверки объявления единицы остаётся определить, где и в каком виде его искать.

**Уже установлено.** Каждое поле объявляет миллисекунды. Одной секунде соответствует числовое значение 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Указать, где проверяющий находит запись об единице для каждого экспортированного поля.

**Что различит проверка.** Образец со значением 1000 и объявлениями только рядом с полями проходит проверку, если объявление ожидается рядом с каждым полем. / Тот же образец со значением 1000 не проходит проверку объявления, если для каждого поля требуется запись в описании формата.

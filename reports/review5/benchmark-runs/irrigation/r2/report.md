## Проверка набора в целом

Правила ручной остановки и повторной передачи задают несовместимые исходы. Для аварийного перехода и обязательной проверки возобновления отсутствуют данные для приёмки. Категория зоны и происхождение значения для панели требуют уточнения.

Открытых предполагаемых пробелов — 2. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-001](#z-001) · W-4 требует аварийного перехода клапана. Критерий некорректности показания отсутствует. Даже для заведомо некорректного показания конечное положение не задано, поэтому аварийный переход нельзя принять.
- [Z-003](#z-003) · Команда расписания входит в число автоматических команд открытия. До нажатия «Возобновить» W-1 требует её игнорировать, а W-2 требует немедленно открыть клапан. Для ручной остановки заданы взаимоисключающие исходы.
- [Z-004](#z-004) · W-5 требует проверить кнопку. W-1 задаёт окончание блокировки при нажатии, а W-2 описывает команду расписания в режиме остановки. Действие для проверки после нажатия и его ожидаемый эффект не заданы, поэтому обязательное испытание возобновления нельзя завершить.
- [Z-007](#z-007) · W-6 требует ровно три повторные передачи после первого таймаута, W-7 требует пять. Оба числа относятся к повторам одной передачи при одном условии, поэтому сценарий восстановления обмена нельзя принять.

### Z-002 · По какому источнику и правилу QA должен определить ожидаемое значение, передаваемое контроллером на панель?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают передачу значения контроллером на панель. Описание датчика устанавливает источник показаний для контроллера, а происхождение передаваемого значения остаётся открытым.

**Последствие.** W-6 и W-7 задают передачу значения контроллером на панель. Описание датчика устанавливает источник показаний для контроллера, а происхождение передаваемого значения остаётся открытым.

**Уже установлено.** Показание влажности поступает от датчика контроллеру. Значение на панель передаёт контроллер. Основания — [R-M0013-01](#r-m0013-01), [R-M0003-01](#r-m0003-01), [R-M0014-01](#r-m0014-01).

**Что различит проверка.** Панель получает заданное показание влажности без изменения. / При том же показании панель получает отличающееся значение по указанному источнику и правилу.

**Открытое решение.** Определить, по каким признакам конкретная зона относится к категории омега.

**Что различит проверка.** Единственная включённая зона входит в категорию омега, проверка проходит. / Та же единственная включённая зона не входит в категорию омега, проверка не проходит.

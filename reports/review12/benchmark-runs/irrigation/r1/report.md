## Проверка набора в целом

ТЗ задаёт несовместимые исходы для команды расписания при ручной остановке и для повторов передачи после первого таймаута. Для обязательного аварийного перехода отсутствует конечное положение клапана, а для кнопки «Возобновить» отложено содержание приёмочного испытания.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-004](#z-004) · До нажатия «Возобновить» W-1 требует игнорировать все автоматические команды открытия. Для той же автоматической команды от расписания W-2 требует немедленно открыть клапан. Приёмка ручной остановки даёт взаимоисключающие исходы.
- [Z-007](#z-007) · W-4 требует перевести клапан в аварийное положение при заведомо некорректном показании. Конечное положение отсутствует, поэтому обязательный аварийный переход нельзя принять.
- [Z-008](#z-008) · W-6 и W-7 считают повторные передачи одного значения на панель после одного и того же первого таймаута. Три и пять повторов дают взаимоисключающие результаты обязательной проверки.

### Z-007 · Аварийное положение клапана

**Дефект · Полнота · Критичная.** W-4 требует перевести клапан в аварийное положение при заведомо некорректном показании. Конечное положение отсутствует, поэтому обязательный аварийный переход нельзя принять.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/requirements.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение.  

**Сценарий.** Клапан открыт. На вход подано показание из согласованного набора заведомо некорректных значений.

**Последствие.** По одному испытанию можно наблюдать закрытие клапана или сохранение открытого положения, но ТЗ не позволяет установить, какое положение соответствует аварийному.

**Уже установлено.** При получении заведомо некорректного показания контроллер обязан выполнить аварийное действие с клапаном. Основания — [R-M0009-01](#r-m0009-01).

**Открытое решение.** Какое конкретное положение является целью аварийного действия для этого входа.

**Что различит проверка.** После аварийной установки клапан закрыт, если автор задаёт закрытое положение. / После аварийной установки клапан открыт, если автор задаёт открытое положение.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** В каком конкретном положении должен оказаться клапан при этом заведомо некорректном показании?

Внести ответ на этот вопрос в [R-M0009-01](#r-m0009-01) для сценария «Клапан открыт. На вход подано показание из согласованного набора заведомо некорректных значений.».

<a id="z-001"></a>

### Z-001 · Какое изменение состояния полива, если оно требуется, должно вызвать выбранное корректное показание при выключенном поливе, без ручной остановки и команды расписания?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер работает по показаниям влажности. W-4 задаёт действие при некорректном входе, а W-3 задаёт число зон при поливе. Ожидаемая реакция на корректное показание остаётся открытой.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/requirements.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** При выключенном поливе, без ручной остановки и команды расписания подать согласованное корректное показание и сверить состояние полива с заданным исходом. Если полив начался, проверить включение одной зоны категории омега.

**Последствие.** Контроллер работает по показаниям влажности. W-4 задаёт действие при некорректном входе, а W-3 задаёт число зон при поливе. Ожидаемая реакция на корректное показание остаётся открытой.

**Уже установлено.** Входом служит показание датчика влажности. При поливе включается одна зона категории омега. Основания — [R-M0003-01](#r-m0003-01), [R-M0009-01](#r-m0009-01), [R-M0008-01](#r-m0008-01).

**Открытое решение.** Должно ли выбранное корректное показание запустить полив в заданном исходном состоянии.

**Что различит проверка.** Полив начинается с включением одной зоны категории омега. / Полив остаётся выключенным.

### Z-002 · По какому критерию показание датчика влажности относится к некорректным для W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 предписывает аварийный переход для некорректного показания. Критерий применимости этого правила к конкретному показанию отсутствует.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/requirements.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение.  

**Сценарий.** Подать одно согласованное показание, классификация которого требует критерия. По ответу определить, требуется ли для этого входа аварийный переход. Для некорректного показания проверить предписанный переход по отдельно заданному целевому положению.

**Что нужно уточнить.** Принадлежит ли выбранное показание к некорректным по критерию W-4.

**Как ответ изменит приёмку.** Для некорректного показания аварийный переход обязателен. Для корректного показания W-4 не задаёт исход.

**Уже установлено.** Показание поступает от датчика влажности. Для некорректного показания обязателен аварийный переход. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** По какому признаку отнести одно и то же показание к области действия W-4.

**Что различит проверка.** На выбранном входе испытание должно подтвердить аварийный переход. / Выбранный вход не подпадает под W-4, поэтому аварийный переход по этому правилу не оценивается.

**Открытое решение.** Связать содержимое передачи панели с данными, по которым проверяющий может вычислить ожидаемое значение.

**Что различит проверка.** В исходной отправке и повторах наблюдается заданное показание влажности, если автор связывает передачу с ним напрямую. / В тех же отправках наблюдается иное значение, определённое указанным автором источником или правилом.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке ручной остановки, аварийного перехода и повторной передачи на панель. Для подготовки остальных проверок нужно уточнить реакцию на корректное показание, критерии некорректности и категории омега, а также источник значения для панели.

1. Согласовать единый исход команды расписания при ручной остановке и единое число повторов после первого таймаута. ([Z-004](#z-004), [Z-008](#z-008))
2. Задать конечное аварийное положение для заведомо некорректного показания. ([Z-007](#z-007))
3. Дополнить обязательное испытание кнопки «Возобновить» контрольным шагом и наблюдаемым критерием успеха. ([Z-005](#z-005))
4. Уточнить реакцию на корректное показание, критерии некорректности и принадлежности к категории омега, а также происхождение передаваемого панели значения. ([Z-001](#z-001), [Z-002](#z-002), [Z-006](#z-006), [Z-003](#z-003))

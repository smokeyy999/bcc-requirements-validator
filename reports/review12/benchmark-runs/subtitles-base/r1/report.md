**Где и по какому признаку проверяющий должен увидеть, что для каждого поля временной метки объявлены миллисекунды?**

### Z-001 · Каков ожидаемый результат экспорта дорожки с репликами длиной 80 и 81 кодовую точку Unicode в новый файл после обязательного отклонения второй реплики?

[R-M0003-01](#r-m0003-01) · Subtitle track export · [строка 3](../../../../../benchmark/subtitles/baseline.md#L3)

**Сценарий.** Экспортировать дорожку с репликами длиной 80 и 81 кодовую точку Unicode по пути, где файла нет. Проверить согласованный исход. Если файл должен появиться, проверить, что в нём только реплика длиной 80 кодовых точек.

**Что нужно уточнить.** Применяется ли правило записи файла к остатку дорожки после отклонения одной реплики.

**Как ответ изменит приёмку.** Если экспорт продолжается, создаётся файл с репликой длиной 80 кодовых точек. Если операция прекращается, файл не создаётся.

**Уже установлено.** Реплика в 81 кодовую точку отклоняется. Правило о неизменности назначения задано для пустой дорожки. Основания — [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0015-01](#r-m0015-01), [R-M0010-02](#r-m0010-02).

**Открытое решение.** Определить ожидаемый результат экспорта после отклонения реплики, когда в дорожке остаётся допустимая реплика.

**Что различит проверка.** Создан файл только с репликой длиной 80 кодовых точек. / Файл по пути назначения отсутствует.

<a id="z-002"></a>

### Z-002 · Признак объявления единицы времени

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 требует объявления миллисекунд для каждого поля временной метки. Значение 1000 для одной секунды проверяет числовую шкалу. Критерий проверки самого объявления не задан.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds;  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать дорожку с временной меткой в одну секунду и получить в соответствующем поле значение 1000.

**Последствие.** Значение 1000 подтверждает шкалу, но по нему нельзя определить, выполнено ли требование об объявлении миллисекунд.

**Уже установлено.** Для каждого поля требуется объявить миллисекунды. Метка в одну секунду имеет значение 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Определить, какое наблюдение подтверждает объявление миллисекунд для каждого поля.

**Что различит проверка.** Файл со значением 1000 проходит проверку, если объявление для каждого поля явно задано в описании формата. / Тот же файл не проходит проверку, если объявление для каждого поля требуется в самом файле.

1. Задать ожидаемый исход экспорта при отклонении одной реплики из смешанной дорожки. ([Z-001](#z-001))

## Реестр замечаний

<a id="z-002"></a>

### Z-002 · Место объявления миллисекунд

**Неоднозначность · Однозначность · Существенная.** T-3 задаёт единицу для каждого поля и значение 1000 для одной секунды. Оборот «Each timestamp field declares milliseconds» допускает объявление в определении поля либо в самом файле. От этого зависит приёмка файла с одними числами.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second.  

**Сценарий.** Во всех определениях полей временных отметок указаны миллисекунды. В экспортированном файле есть только числовые значения, включая 1000 для отметки в одну секунду.

**Последствие.** Разработчик и проверяющий могут по-разному оценить соответствие файла T-3.

**Уже установлено.** Каждое поле объявляет миллисекунды. Одной секунде соответствует число 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Определить, достаточно ли объявления единицы в определении поля или оно требуется в экспортированном файле.

**Что различит проверка.** Файл с числом 1000 для одной секунды проходит проверку, если миллисекунды объявлены в определении поля. / Тот же файл с числом 1000 для одной секунды проваливает проверку из-за отсутствия объявления в файле.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Достаточно ли объявления миллисекунд в определении каждого поля или оно должно присутствовать в самом файле?

1. **Вариант 1.** Объявляйте миллисекунды в определении каждого поля временной отметки.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл проходит проверку объявления единицы.

2. **Вариант 2.** Записывайте объявление миллисекунд для каждого поля временной отметки в экспортируемом файле.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл не проходит проверку объявления единицы.

**Черновик приёмочного теста.** Экспортировать отметку в одну секунду, сверить значение 1000 и проверить объявление миллисекунд в выбранном месте.

**Что различит проверка.** Файл содержит только допустимую реплику из экспортируемой дорожки. / Файл сохраняет исходное содержимое.

## Готовность и порядок исправлений

ТЗ позволяет начать разработку. Для завершения приёмки нужно согласовать место объявления единицы и состояние файла при отклонении одной из реплик.

1. Указать место объявления миллисекунд для каждого поля и закрепить его в проверке формата. ([Z-002](#z-002))
2. Определить состояние существующего файла после экспорта дорожки с допустимой и отклонённой репликами. ([Z-001](#z-001))

**Сценарий.** Выполнить экспорт для примера T-8 и отдельно для дорожки с репликой из 81 кодовой точки Unicode и допустимой по длине репликой. **Что различит проверка.** В обоих случаях экспорт прекращается и файл не записывается. Допустимая реплика смешанной дорожки не экспортируется. / В обоих случаях записывается файл без отклонённой реплики. В файле смешанной дорожки присутствует допустимая реплика.

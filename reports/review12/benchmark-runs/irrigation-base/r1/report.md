Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

**Открытое решение.** Связать значение в повторной передаче на панель с конкретным исходным значением.

### Z-003 · По какому признаку определяется, что выбранное для аварийного испытания показание датчика некорректно?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт исход словами «Аварийное положение — закрыто». Для испытания нужен признак, по которому выбранное показание признаётся некорректным.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

**Сценарий.** Подать выбранное показание при открытом клапане. Если оно подпадает под заданный признак некорректности, проверить закрытие клапана. Иначе выбрать вход, который запускает аварийный переход.

**Что нужно уточнить.** Неизвестно, относится ли выбранное испытательное показание к некорректным.

**Как ответ изменит приёмку.** При некорректном показании клапан должен закрыться. При допустимом показании этот прогон не проверяет W-4.

**Уже установлено.** Некорректное показание обязывает контроллер закрыть клапан. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить, подпадает ли выбранное показание под обозначение «некорректное значение датчика».

**Что различит проверка.** Оставшийся открытым клапан означает провал проверки W-4. / Оставшийся открытым клапан не оценивается по W-4, поскольку вход не запускает аварийный переход.

**Последствие.** Ровно три повторные передачи удовлетворяют обеим нормам. Раздельные записи создают две точки сопровождения одного условия приёмки.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

Показание влажности и номер зоны имеют известные источники, но связь передаваемого значения с его источником не указана. W-6 и W-7 требуют ровно три повторные передачи значения на панель после одного и того же первого таймаута. W-6 полностью задаёт проверяемое поведение, поэтому отдельная запись W-7 дублирует его.

Связанные замечания — [Z-002](#z-002), [Z-004](#z-004).

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Приёмку управления по влажности и содержимого передачи можно завершить после уточнений.

1. Задать ожидаемое положение клапана для допустимого испытательного показания и отдельно определить критерий некорректности для проверки аварийного закрытия. ([Z-001](#z-001), [Z-003](#z-003))
2. Указать источник значения, которое контроллер повторно передаёт панели. ([Z-002](#z-002))
3. Сохранить условие о трёх повторах в W-6 и удалить дублирующую запись W-7. ([Z-004](#z-004))

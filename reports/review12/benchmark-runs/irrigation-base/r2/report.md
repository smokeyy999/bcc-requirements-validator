## Проверка набора в целом

Заданы аварийное положение клапана, блокировка автоматического открытия до возобновления и число повторов передачи. Требуют уточнения реакция на допустимое показание, граница некорректности, положение клапана после ручной остановки и источник передаваемого значения.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Какое конечное положение должен занять изначально закрытый клапан при конкретном допустимом показании влажности, если зона выбрана, ручная остановка не активна и других команд открытия нет?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер работает по показаниям влажности. W-3 определяет выбор зоны, а W-4 задаёт закрытие при некорректном показании. Действие клапана при допустимом показании не задано.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

**Последствие.** Контроллер работает по показаниям влажности. W-3 определяет выбор зоны, а W-4 задаёт закрытие при некорректном показании. Действие клапана при допустимом показании не задано.

**Уже установлено.** Источник показания — датчик влажности. W-2 задаёт блокировку команды расписания при ручной остановке, W-3 определяет выбор зоны, W-4 задаёт аварийное закрытие. **Открытое решение.** Ожидаемое положение изначально закрытого клапана после подачи выбранного допустимого показания.

**Что различит проверка.** Показание признано некорректным. Если клапан остался открытым, проверка W-4 провалена. / Показание признано допустимым. Если клапан остался открытым, это не нарушает W-4.

## Готовность и порядок исправлений

Можно подготовить проверки возобновления и числа повторов. Для завершения приёмочных сценариев полива, ручной остановки и проверки содержимого передачи нужны уточнения.

1. Задать критерий некорректного показания и положение открытого клапана после нажатия ручной остановки. ([Z-003](#z-003), [Z-004](#z-004))
2. Определить ожидаемое положение клапана при допустимом показании в штатном режиме. ([Z-001](#z-001))
3. Указать источник значения для сверки содержимого передачи на панель. ([Z-002](#z-002))
4. Сохранить правило трёх повторов в W-6 и удалить дублирующий W-7. ([Z-005](#z-005))

## Проверка набора в целом

Основная функция полива по влажности не имеет ожидаемого результата для штатного показания. Для отдельных проверок нужно определить эффект ручной остановки на открытый клапан, критерий некорректного показания и источник значения для панели. Норма о трёх повторах записана дважды.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-004 · По какому критерию W-4 относит показание датчика к некорректным?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт конечное положение словами «Аварийное положение — закрыто». Для испытания нужно определить, какие значения датчика считаются некорректными.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать заранее фиксированное показание и зафиксировать итоговое положение клапана. Если показание подпадает под согласованный критерий W-4, ожидаемый результат — закрытие.

**Что нужно уточнить.** Подпадает ли конкретное испытательное показание под обозначение «некорректного значения датчика».

**Как ответ изменит приёмку.** Если показание некорректно, W-4 требует закрытия. Если оно не подпадает под критерий, этот вход не проверяет аварийное закрытие.

**Уже установлено.** При некорректном показании датчика клапан должен закрыться. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить критерий, по которому фиксированное показание подпадает под условие W-4.

**Что различит проверка.** Показание подпадает под W-4. Если клапан остался открытым, требование нарушено. / То же показание находится вне области W-4. Открытый клапан в этом испытании не свидетельствует о нарушении W-4.

### Z-005 · Повтор нормы о числе передач

**Дефект · Дублирование · Низкая.** W-6 и W-7 задают ровно три повторные передачи значения на панель после одного и того же первого таймаута. Одной записи достаточно для той же приёмочной проверки.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/baseline.md#L14)

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Сценарий.** Первая передача значения на панель завершается таймаутом. По обеим нормам проверяющий считает три последующие передачи.

**Последствие.** Две записи поддерживают одно приёмочное ожидание.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

Проект правки по [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01) — Объединить требования в одну норму о числе повторных передач значения на панель после первого таймаута.

**Черновик приёмочного теста.** Открыть исправленные пункты [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01) и проверить выполнение предложенной правки «Объединить требования в одну норму о числе повторных передач значения на панель после первого таймаута.».

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке штатного управления поливом. Сначала требуется определить реакцию клапана на штатные показания.

1. Задать ожидаемое положение клапана для штатных показаний в условиях работы автоматики. ([Z-002](#z-002))
2. Определить непосредственный эффект ручной остановки на открытый клапан. ([Z-003](#z-003))
3. Определить критерий некорректности показания для проверки аварийного закрытия. ([Z-004](#z-004))
4. Указать источник значения, передаваемого панели при повторах. ([Z-001](#z-001))
5. Объединить W-6 и W-7 с сохранением условия первого таймаута и ровно трёх повторов. ([Z-005](#z-005))

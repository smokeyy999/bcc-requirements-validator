Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

**Каким должно стать состояние закрытого клапана при получении конкретного корректного показания в обычном режиме без команды расписания?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Задать исходные данные с различимыми значениями для проверяемых источников, вызвать первый таймаут и сверить содержимое каждой из трёх повторных передач на границе с панелью со значением из указанного источника.

**Должен ли уже открытый клапан закрыться при нажатии кнопки ручной остановки до поступления новых команд открытия?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Во время полива нажать кнопку ручной остановки при открытом клапане и сверить его состояние до поступления новых команд. Затем подать автоматическую команду открытия до нажатия «Возобновить» и проверить, что команда игнорируется.

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — Подать одно и то же проверяемое показание при открытом клапане. Если критерий относит его к некорректным, проверить закрытие по W-4. Иначе ожидаемое состояние клапана по W-4 для этого входа не оценивается.

### Z-002 · Из какого источника определяется значение, которое контроллер передаёт панели при повторах после первого таймаута?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают три повтора после первого таймаута. Упоминание датчика не связывает его показание с содержимым передачи на панель.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Сценарий.** Задать исходные данные с различимыми значениями для проверяемых источников, вызвать первый таймаут и сверить содержимое каждой из трёх повторных передач на границе с панелью со значением из указанного источника.

**Последствие.** W-6 и W-7 задают три повтора после первого таймаута. Упоминание датчика не связывает его показание с содержимым передачи на панель.

**Уже установлено.** Датчик поставляет показания контроллеру. После первого таймаута контроллер трижды повторяет передачу значения панели. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Связь между значением в повторной передаче на панель и исходными данными, из которых оно определяется.

**Что различит проверка.** Во всех трёх повторах панель получает заданное показание датчика. / Во всех трёх повторах панель получает отличающееся значение из другого указанного источника.

### Z-004 · По какому критерию определяется, что конкретное полученное показание датчика некорректно по W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт конечное положение «закрыто». Для проверки срабатывания нужен критерий некорректности показания.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** Подать одно и то же проверяемое показание при открытом клапане. Если критерий относит его к некорректным, проверить закрытие по W-4. Иначе ожидаемое состояние клапана по W-4 для этого входа не оценивается.

**Что нужно уточнить.** Относится ли проверяемое показание к некорректным по критерию W-4.

**Как ответ изменит приёмку.** Если показание некорректно, клапан должен закрыться. В противном случае W-4 к этому входу не применяется.

**Уже установлено.** Конечное положение при срабатывании задано прямо. «Аварийное положение — закрыто.» Основания — [R-M0009-01](#r-m0009-01).

**Открытое решение.** Применимость W-4 к выбранному показанию по критерию некорректности.

**Что различит проверка.** Для выбранного показания закрытие клапана обязательно по W-4. / Выбранное показание вне области W-4, поэтому закрытие по этому правилу не проверяется.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

## Готовность и порядок исправлений

ТЗ частично готово к разработке и приёмке. Для сценариев с открытыми вопросами нужны ожидаемые результаты и входные данные испытаний.

1. Уточнить состояние уже открытого клапана при ручной остановке и критерий срабатывания аварийного закрытия. ([Z-003](#z-003), [Z-004](#z-004))
2. Задать реакцию клапана на корректное показание в обычном режиме без команды расписания. ([Z-001](#z-001))
3. Указать источник значения для проверки содержимого повторных передач панели. ([Z-002](#z-002))
4. Сохранить W-6 и удалить дублирующее W-7. ([Z-005](#z-005))

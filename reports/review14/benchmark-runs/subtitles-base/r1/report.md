### Z-001 · Место объявления единицы временных меток

**Неоднозначность · Однозначность · Существенная.** T-3 задаёт число 1000 для одной секунды. Слова «Each timestamp field declares milliseconds» допускают объявление единицы в определении поля формата или в самом записанном поле. От этого зависит приёмка файла с числом 1000.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать метку в одну секунду. В файле записано 1000, а миллисекунды объявлены для каждого поля только в описании формата.

**Последствие.** Ожидаемое представление единицы измерения в экспортируемом файле нельзя определить однозначно.

**Уже установлено.** Единица каждого поля — миллисекунды. Одной секунде соответствует число 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Достаточно ли объявить единицу для каждого поля в описании формата?

**Что различит проверка.** Файл с числом 1000 и объявлением единицы только в описании формата проваливает проверку. / Тот же файл проходит проверку.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Должен ли файл из сценария пройти приёмку или объявление миллисекунд обязательно в самом файле?

1. **Вариант 1.** Миллисекунды должны быть объявлены для каждого поля временной метки в самом файле.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл с числом 1000 проваливает проверку объявления единицы.

2. **Вариант 2.** Достаточно объявить миллисекунды для каждого поля в описании формата. В файле допускается числовое значение без объявления единицы.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл с числом 1000 проходит проверку объявления единицы.

**Черновик приёмочного теста.** Проверить число 1000 для метки в одну секунду и оценить файл без объявления единицы по выбранному правилу.

**Предполагаемый пробел · Полнота · Существенная.** T-7 и T-8 требуют отклонить реплику из 81 кодовой точки. Оба описания относятся к реплике. Ожидаемое состояние файла после её отклонения остаётся открытым.

Затронутые утверждения — [R-M0014-01](#r-m0014-01), [R-M0015-01](#r-m0015-01).

> In the acceptance sample, a cue of 81 Unicode code points is rejected.  

**Сценарий.** На ST-1 экспортировать по новому пути дорожку из 100 реплик, из которых 99 содержат по 80 кодовых точек Unicode, а одна — 81. Проверить отклонение реплики из 81 кодовой точки и сверить наличие файла и его состав с ожидаемым результатом. Проверить появление диалога не позднее двух секунд после команды.

**Последствие.** T-7 и T-8 требуют отклонить реплику из 81 кодовой точки. Оба описания относятся к реплике. Ожидаемое состояние файла после её отклонения остаётся открытым.

**Уже установлено.** Реплика из 81 кодовой точки подлежит отклонению. Правило сохранения назначения относится к пустой дорожке. Для 100 реплик на ST-1 задан двухсекундный предел появления диалога. Основания — [R-M0014-01](#r-m0014-01), [R-M0015-01](#r-m0015-01), [R-M0010-02](#r-m0010-02), [R-M0009-01](#r-m0009-01).

**Открытое решение.** Какое состояние назначения ожидается после отклонения длинной реплики в смешанной дорожке?

**Что различит проверка.** По новому пути появляется файл с 99 репликами, реплика из 81 кодовой точки отклонена. / По новому пути файл не появляется, реплика из 81 кодовой точки отклонена.

## Готовность и порядок исправлений

Основной экспорт можно разрабатывать. Ожидаемые результаты двух приёмочных проверок требуют уточнения.

1. Указать, где объявляются миллисекунды для каждого поля временной метки. ([Z-001](#z-001))
2. Задать наличие и состав файла после обязательного отклонения длинной реплики в смешанной дорожке. ([Z-002](#z-002))

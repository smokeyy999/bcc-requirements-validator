## Проверка набора в целом

Правила допуска к отправке расходятся для черновика и для готовой ведомости с 25 строками. Для настройки хранения 7 указаны разные длительности, а для показа «Передано» отсутствует измеримый предел. В S-6 требуется редакторское исправление ссылки S-97. Текст и состояние при отказе уже заданы в S-7.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-001](#z-001) · S-1 разрешает отправку только из состояния «Готова». S-2 требует сразу передать «Черновик» по той же попытке оператора. Без согласования нельзя принять правило допуска к отправке.
- [Z-002](#z-002) · S-3 ограничивает состав одной ведомости 24 строками. S-4 принимает файл ведомости из 25 строк и разрешает её отправку. Оба правила относятся к одной ведомости, а изменение её состава между загрузкой и отправкой не задано.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке правил допуска к отправке. Для приёмки хранения и своевременности показа статуса требуется согласовать срок и допустимую задержку.

1. Согласовать результат попытки отправить черновик. ([Z-001](#z-001))
2. Согласовать предел числа строк и допуск готовой ведомости с 25 строками. ([Z-002](#z-002))
3. Согласовать единицу хранения и срок для настройки 7. ([Z-003](#z-003))
4. Задать допустимую задержку показа «Передано» после подтверждения перевозчика. ([Z-005](#z-005))
5. Исправить внутреннюю ссылку S-97 в S-6. ([Z-006](#z-006))

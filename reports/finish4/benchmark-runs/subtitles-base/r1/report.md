### Z-001 · Каким должен быть результат экспорта в существующий файл, если дорожка содержит реплики из 80 и 81 кодовой точки Unicode и длинная реплика отклоняется?

**Предполагаемый пробел · Полнота · Существенная.** T-7 и T-8 требуют отклонить реплику из 81 кодовой точки. Состояние файла для смешанной дорожки не задано. Условие T-5 о неизменности файла относится к пустой дорожке.

[R-M0015-01](#r-m0015-01) · Subtitle track export / Export limits · [строка 15](../../../../../benchmark/subtitles/baseline.md#L15)

> In the acceptance sample, a cue of 81 Unicode code points is rejected.  

**Сценарий.** Экспортировать такую дорожку в существующий файл, который изначально не содержит этих реплик. Проверить отклонение реплики из 81 кодовой точки и сверить состояние файла и наличие в нём реплики из 80 кодовых точек с согласованным результатом.

**Последствие.** T-7 и T-8 требуют отклонить реплику из 81 кодовой точки. Состояние файла для смешанной дорожки не задано. Условие T-5 о неизменности файла относится к пустой дорожке.

**Уже установлено.** Реплика из 81 кодовой точки отклоняется. Реплика из 80 кодовых точек не подпадает под ограничение длины. Основания — [R-M0014-01](#r-m0014-01), [R-M0003-02](#r-m0003-02), [R-M0010-02](#r-m0010-02), [R-M0015-01](#r-m0015-01).

**Открытое решение.** Какое состояние файла ожидается после отклонения длинной реплики при экспорте смешанной дорожки.

**Что различит проверка.** Файл обновлён и содержит реплику из 80 кодовых точек без длинной реплики. / Экспорт прекращён, существующий файл остался без изменений.

<a id="z-002"></a>

### Z-002 · Где и в каком виде в экспортированном файле проверяющий должен прочитать объявление миллисекунд для каждого поля временной метки?

**Предполагаемый пробел · Трассируемость · Существенная.** T-3 задаёт объявление миллисекунд для каждого поля и числовую шкалу. В экспортированном файле не указан элемент, по которому проверяющий может прочитать объявление для конкретного поля.

Затронутые утверждения — [R-M0008-01](#r-m0008-01).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

**Сценарий.** Экспортировать дорожку с меткой в одну секунду. Для каждого поля временной метки проверить объявление миллисекунд в согласованном месте и виде, а для метки в одну секунду проверить числовое значение 1000.

**Последствие.** T-3 задаёт объявление миллисекунд для каждого поля и числовую шкалу. В экспортированном файле не указан элемент, по которому проверяющий может прочитать объявление для конкретного поля.

**Уже установлено.** Каждое поле объявляет миллисекунды. Число 1000 соответствует одной секунде. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0003-02](#r-m0003-02).

**Открытое решение.** По какому элементу экспортированного файла проверяющий связывает конкретное поле временной метки с объявлением его единицы.

**Что различит проверка.** У каждого поля миллисекунды указаны в его имени, а числовое значение метки в одну секунду равно 1000. / У каждого поля миллисекунды указаны в отдельном атрибуте единицы, а числовое значение метки в одну секунду равно 1000.

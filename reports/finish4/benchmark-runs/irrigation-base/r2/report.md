### Z-001 · Какие исходные данные определяют значение, которое контроллер передаёт панели по W-6?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают три повтора после первого таймаута. W-6 называет контроллер отправителем, но документ не связывает передаваемое значение с конкретными исходными данными.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/baseline.md#L14)

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Сценарий.** Задать исходные данные с различимыми значениями, вызвать первый таймаут и проверить, что контроллер трижды передаёт панели значение, ожидаемое по указанному источнику.

**Последствие.** W-6 и W-7 задают три повтора после первого таймаута. W-6 называет контроллер отправителем, но документ не связывает передаваемое значение с конкретными исходными данными.

**Уже установлено.** Контроллер повторяет передачу значения панели три раза после первого таймаута. Показание поступает от датчика, номер зоны выбирает оператор на панели. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0008-01](#r-m0008-01).

**Открытое решение.** Установить связь значения, передаваемого панели по W-6, с данными, по которым его можно независимо определить в тесте.

**Что различит проверка.** Если источником служит показание датчика, во всех трёх повторах наблюдается заданное показание. / Если источником служит выбранный номер зоны, во всех трёх повторах наблюдается заданный номер зоны.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

**Сценарий.** При активной автоматике, закрытом клапане и отсутствии команды расписания подать допустимое показание влажности. Проверить состояние клапана по согласованному правилу для этого показания и заданных условий.

**Последствие.** Контроллер работает по показаниям влажности. W-4 задаёт закрытие для некорректного значения. Для допустимого показания при активной автоматике реакция клапана не определена.

**Уже установлено.** Автоматика использует показания датчика. Для некорректного показания задано аварийное закрытие. При ручной остановке автоматические команды открытия игнорируются. Основания — [R-M0003-01](#r-m0003-01), [R-M0009-01](#r-m0009-01), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

**Открытое решение.** Определить, открывает ли контроллер клапан при данном допустимом показании и фиксированных условиях.

**Что различит проверка.** После подачи показания клапан открывается. / После подачи того же показания клапан остаётся закрытым.

**Открытое решение.** Определить, закрывает ли само нажатие кнопки ручной остановки уже открытый клапан.

**Что различит проверка.** Клапан закрывается при нажатии кнопки, последующая команда расписания игнорируется. / Нажатие оставляет клапан открытым, последующая команда расписания игнорируется.

### Z-004 · По какому критерию полученное показание датчика считается некорректным для срабатывания W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо требует закрыть клапан при некорректном показании. Открыт критерий, по которому конкретное значение датчика подпадает под это правило.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать конкретное показание датчика. Определить по согласованному критерию, подпадает ли оно под W-4. Для показания, признанного некорректным, проверить закрытие клапана.

**Что нужно уточнить.** Подпадает ли конкретное испытательное значение датчика под обозначение «некорректного значения».

**Как ответ изменит приёмку.** Если значение признано некорректным, W-4 требует закрытия. Иначе этот вход находится вне области применения W-4.

**Уже установлено.** Источник показания задан. При получении некорректного значения клапан должен закрыться. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить критерий принадлежности конкретного показания к некорректным.

**Что различит проверка.** Показание подпадает под W-4. Если клапан остаётся открытым, испытание W-4 не пройдено. / То же показание вне области W-4. Открытое положение клапана не даёт основания считать W-4 нарушенным.

### R-M0013-01 · После первого таймаута контроллер выполняет ровно три повтора передачи значения на панель.

Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Связано с вопросом к автору.** W-6 и W-7 задают три повтора после первого таймаута. W-6 называет контроллер отправителем, но документ не связывает передаваемое значение с конкретными исходными данными. Фраза «ровно три раза после первого таймаута» задаёт три повтора. Успех одного из первых повторов не указан как основание для сокращения их числа. Обоснование выбранного числа для проверки не требуется.

Связанные замечания — [Z-001](#z-001).

Основания для снятия замечания — [R-M0014-01](#r-m0014-01).

## Готовность и порядок исправлений

ТЗ частично готово к разработке и приёмке. Уже можно проверить возобновление, подавление команд открытия при ручной остановке, выбор зоны и число повторов. Для оставшихся сценариев нужны уточнения.

1. Задать критерий аварийного входа и положение открытого клапана после ручной остановки. ([Z-004](#z-004), [Z-003](#z-003))
2. Определить правило открытия клапана по допустимому показанию влажности. ([Z-002](#z-002))
3. Связать значение для панели с исходными данными для проверки содержимого повторов. ([Z-001](#z-001))

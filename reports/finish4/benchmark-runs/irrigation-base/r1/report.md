## Проверка набора в целом

Документ задаёт закрытие клапана при некорректном показании, подавление последующих команд открытия при ручной остановке и три повтора передачи. Для приёмки остаётся определить критерий некорректности, реакцию на корректное показание, положение открытого клапана после ручной остановки и источник данных для панели.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Для затронутых сценариев сначала нужно согласовать входы и ожидаемые результаты приёмки.

1. Определить критерий некорректности и задать реакцию клапана на корректные показания. ([Z-003](#z-003), [Z-002](#z-002))
2. Задать положение открытого клапана после нажатия ручной остановки. ([Z-004](#z-004))
3. Указать, из какого источника берётся значение, получаемое панелью при повторной передаче. ([Z-001](#z-001))
4. Оставить одну запись о трёх повторах после первого таймаута. ([Z-005](#z-005))

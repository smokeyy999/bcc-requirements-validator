Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Экспортировать такую дорожку по свободному пути. Проверить отклонение реплики из 81 кодовой точки и согласованный результат по пути, включая содержимое файла при его создании.

<a id="z-001"></a>

### Z-001 · Обозначение миллисекунд в поле

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 требует объявлять миллисекунды в каждом поле отметки времени, но не задаёт проверяемого признака такого объявления. Числовую шкалу можно проверить отдельно по значению 1000 для одной секунды.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать дорожку с отметкой времени в одну секунду и проверить соответствующее поле.

**Последствие.** Тест может сверить числовое значение 1000, но не может принять обозначение единицы в поле.

[R-M0015-01](#r-m0015-01) · Subtitle track export / Export limits · [строка 15](../../../../../benchmark/subtitles/baseline.md#L15)

> In the acceptance sample, a cue of 81 Unicode code points is rejected.  

**Сценарий.** Экспортировать такую дорожку по свободному пути. Проверить отклонение реплики из 81 кодовой точки и согласованный результат по пути, включая содержимое файла при его создании.

## Готовность и порядок исправлений

Разработку определённых сценариев можно начать. Полная приёмка потребует критерия объявления единицы и ожидаемого результата для файла при отклонении одной реплики.

1. Согласовать проверяемый признак объявления миллисекунд в каждом поле и добавить его в приёмочный тест. ([Z-001](#z-001))
2. Уточнить ожидаемый результат по пути для смешанной дорожки и зафиксировать его в тесте вместе с отклонением длинной реплики. ([Z-002](#z-002))

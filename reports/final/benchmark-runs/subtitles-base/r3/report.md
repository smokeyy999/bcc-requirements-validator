### Уточнить ожидаемое поведение

**Как подтвердить обязательное отклонение длинной реплики в смешанной дорожке и каким должен быть результат для файла назначения и допустимой реплики?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Экспортировать дорожку с одной допустимой репликой и одной репликой из 81 кодовой точки. Подтвердить отклонение длинной реплики согласованным способом, проверить состояние назначения и судьбу допустимой реплики.

**Где и в каком виде проверяющий должен увидеть обязательное объявление миллисекунд для каждого поля?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Проверить значение 1000 для метки в одну секунду и сверить объявление единицы каждого поля в указанном месте и виде.

**Как при приёмке определить, какая рабочая станция обозначена ST-1?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — На идентифицированной ST-1 экспортировать дорожку со 100 допустимыми репликами и проверить появление диалога не позднее чем через 2 секунды после команды.

### Z-002 · Объявление единицы временной метки

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 требует объявления миллисекунд для каждого поля. Соответствие одной секунды числу 1000 проверяет шкалу. Для самого объявления ТЗ не задаёт наблюдаемого признака.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать дорожку с временной меткой в одну секунду и проверить полученное поле.

**Последствие.** Число 1000 подтверждает шкалу, а приёмка объявления единицы остаётся неопределённой.

### Z-003 · Как при приёмке определить, какая рабочая станция обозначена ST-1?

**Предполагаемый пробел · Полнота · Существенная.** T-4 задаёт предел в две секунды и обе границы замера. Для применения этого предела нужно установить, какая рабочая станция обозначена ST-1.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Subtitle track export / Format · [строка 9](../../../../../benchmark/subtitles/baseline.md#L9)

> For a track with 100 cues on workstation ST-1, show the completion dialog no later than 2 seconds after the export command.  

**Сценарий.** На идентифицированной ST-1 экспортировать дорожку со 100 допустимыми репликами и проверить появление диалога не позднее чем через 2 секунды после команды.

**Что нужно уточнить.** Какая рабочая станция для приёмочного замера соответствует обозначению ST-1?

**Как ответ изменит приёмку.** На подтверждённой ST-1 замер проверяет предел T-4. Замер на другой станции не даёт результата приёмки по T-4.

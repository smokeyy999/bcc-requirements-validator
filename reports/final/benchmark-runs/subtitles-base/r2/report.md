### Уточнить ожидаемое поведение

**По какому наблюдаемому признаку проверять отклонение реплики из 81 кодовой точки в примере T-8? Каким должно быть состояние файла назначения при отклонении такой реплики на смешанной дорожке и должна ли допустимая реплика попасть в файл, если он записывается?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Выполнить экспорт для примера T-8 и для дорожки с репликой из 81 кодовой точки и допустимой репликой. В обоих случаях подтвердить отклонение по согласованному признаку. Для смешанной дорожки проверить ожидаемое состояние файла назначения и, если файл записывается, ожидаемое наличие или отсутствие допустимой реплики.

**Миллисекунды должны быть объявлены для каждого поля. По какому элементу экспортированного файла приёмщик должен это проверить?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Проверить значение 1000 для метки в одну секунду и отдельно сверить согласованный элемент объявления единицы для каждого поля временной метки.

### Z-002 · Объявление миллисекунд в файле

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 требует объявить миллисекунды в каждом поле временной метки. Для проверки числовой шкалы задано соответствие 1000 одной секунде. Критерий проверки объявления единицы отсутствует.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

**Сценарий.** Экспортировать дорожку с временной меткой в одну секунду и проверить соответствующее поле файла.

**Последствие.** Значение 1000 подтверждает шкалу, но не позволяет вынести вердикт по требованию об объявлении единицы.

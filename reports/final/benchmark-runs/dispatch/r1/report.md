## Проверка набора в целом

Два противоречия блокируют согласование приёмки отправки. Для обработки ответа перевозчика нужно задать критерий задержки надписи и разрешить ссылку на правило отказа. Критерий немедленной передачи нужен, если её сохранят для черновика.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-001](#z-001) · Для одной попытки отправки черновика S-1 исключает передачу, а S-2 требует её. Ожидаемый результат проверки отправки определить невозможно.
- [Z-004](#z-004) · S-3 исключает ведомость из 25 строк из допустимого диапазона, а S-4 требует принять её и разрешить отправку. Состояние «Готова» устраняет ограничение по состоянию, но конфликт по числу строк сохраняется.

## Готовность и порядок исправлений

ТЗ не готово к разработке отправки до выбора исходов для черновика и ведомости из 25 строк.

1. Согласовать, передаётся ли черновик при попытке отправки. ([Z-001](#z-001))
2. Согласовать допустимое число строк и разрешение на отправку ведомости из 25 строк. ([Z-004](#z-004))
3. Если передача черновика сохраняется, задать наблюдаемое событие и допустимую задержку. ([Z-003](#z-003))
4. Установить начало отсчёта и допустимую задержку появления «Передано». ([Z-005](#z-005))
5. Указать правило, на которое ссылается S-6, и согласовать его с обязательной надписью из S-7. ([Z-006](#z-006))

## Проверка набора в целом

ТЗ задаёт закрытое аварийное положение, блокировку автоматического открытия до возобновления и число повторных передач. Для испытаний нужно определить критерий некорректного показания, реакцию на корректную влажность, состояние открытого клапана при ручной остановке и содержимое передачи на панель.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 2.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Критерий некорректного показания

**Предполагаемый пробел · Проверяемость · Существенная.** W-4 задаёт закрытие клапана при некорректном показании. Без критерия некорректности проверяющий не может выбрать вход для испытания. Ожидаемое положение клапана задано.

Затронутые утверждения — [R-M0003-01](#r-m0003-01), [R-M0009-01](#r-m0009-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/baseline.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане контроллер получает показание, которое нужно классифицировать как корректное или некорректное.

**Последствие.** Проверяющий не может определить, применимо ли обязательное аварийное закрытие к выбранному входу.

**Предполагаемый пробел · Полнота · Существенная.** Описание связывает работу контроллера с показаниями влажности. W-4 задаёт реакцию на некорректные значения, а правило для корректных показаний остаётся открытым.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** Подать согласованные корректные показания в заданных начальных состояниях и проверить действие контроллера или сохранение состояния по согласованному правилу.

**Что нужно уточнить.** Какие корректные показания влияют на полив и при каких условиях.

**Как ответ изменит приёмку.** Ответ определит, при каких показаниях испытание должно ожидать действия контроллера, а при каких — сохранения состояния.

**Рекомендация · Дублирование · Низкая.** W-6 и W-7 задают ровно три повторные передачи после первого таймаута. Единая формулировка позволит менять число повторов в одном месте.

## Готовность и порядок исправлений

Сценарии с заданным результатом готовы к разработке. Для полной приёмки контроллера требуется согласовать открытые условия и результаты испытаний.

1. Задать критерий некорректного показания для проверки аварийного закрытия. ([Z-001](#z-001))
2. Определить состояние открытого клапана при ручной остановке и реакцию автоматики на корректные показания. ([Z-004](#z-004), [Z-002](#z-002))
3. Определить значение для панели и его источник для проверки повторной передачи. ([Z-003](#z-003))
4. Оформить команду расписания как сценарий приёмки ручной остановки и свести правило о трёх повторах к одной формулировке. ([Z-005](#z-005), [Z-006](#z-006))

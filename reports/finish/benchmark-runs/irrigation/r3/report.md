## Проверка набора в целом

Ручная остановка и повторы после первого таймаута имеют взаимоисключающие исходы. Для аварийного перехода отсутствует целевое положение клапана. Обязательное испытание «Возобновить» требует ожидаемого результата. Для остальных проверок нужны штатная реакция на влажность, критерий некорректности, определение категории омега и источник значения для панели.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-004](#z-004) · До возобновления W-1 требует игнорировать все автоматические команды открытия, а W-2 требует открыть клапан по команде расписания в том же режиме. Приоритет не задан, поэтому реакцию клапана при ручной остановке принять нельзя.

- [Z-008](#z-008) · W-6 и W-7 считают повторные передачи одного значения на панель после первого таймаута. Требования трёх и пяти повторов исключают друг друга, поэтому принять обработку таймаута невозможно.

### Z-004 · Открытие по расписанию при ручной остановке

**Дефект · Противоречивость · Критичная.** До возобновления W-1 требует игнорировать все автоматические команды открытия, а W-2 требует открыть клапан по команде расписания в том же режиме. Приоритет не задан, поэтому реакцию клапана при ручной остановке принять нельзя.

Затронутые утверждения — [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

[R-M0006-01](#r-m0006-01) · Управление поливом теплицы / Автоматика · [строка 6](../../../../../benchmark/irrigation/requirements.md#L6)

> При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».  

[R-M0007-01](#r-m0007-01) · Управление поливом теплицы / Автоматика · [строка 7](../../../../../benchmark/irrigation/requirements.md#L7)

> В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.  

**Сценарий.** Клапан закрыт, ручная остановка активна, «Возобновить» не нажата. Расписание автоматически выдаёт команду открытия.

**Последствие.** По W-1 команда игнорируется и клапан остаётся закрытым. По W-2 клапан немедленно открывается. Исключение для команд расписания не задано.

**Общее условие.** При активной ручной остановке до нажатия «Возобновить» расписание выдаёт автоматическую команду открытия. Основания — [R-M0006-01](#r-m0006-01) «При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».», [R-M0007-01](#r-m0007-01) «В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой исход выбрать для команды расписания до нажатия «Возобновить»?

1. **Вариант 1.** До нажатия «Возобновить» игнорируются все автоматические команды открытия, включая команды расписания.

   **Основание.** [R-M0006-01](#r-m0006-01) «При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».».

   **Ожидаемый результат.** Клапан остаётся закрытым.

   При выборе этого варианта привести в соответствие [R-M0007-01](#r-m0007-01).

2. **Вариант 2.** В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.

   **Основание.** [R-M0007-01](#r-m0007-01) «В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.».

   **Ожидаемый результат.** Клапан немедленно открывается.

   При выборе этого варианта привести в соответствие [R-M0006-01](#r-m0006-01).

**Черновик приёмочного теста.** В описанном состоянии подать команду расписания и проверить, остался ли клапан закрытым или открылся.

### Z-001 · Какое состояние клапана ожидается при согласованном изменении корректного показания влажности без ручной остановки и команды расписания?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер работает по показаниям влажности. W-4 задаёт аварийную реакцию, а штатная реакция клапана на изменение корректного показания не определена.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/requirements.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** При закрытом клапане, без ручной остановки и команды расписания подать согласованную последовательность корректных показаний и проверить ожидаемое состояние клапана.

**Последствие.** Контроллер работает по показаниям влажности. W-4 задаёт аварийную реакцию, а штатная реакция клапана на изменение корректного показания не определена.

**Уже установлено.** Контроллер использует показания влажности. W-4 предписывает переход при некорректном входе. Основания — [R-M0003-01](#r-m0003-01), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01), [R-M0009-01](#r-m0009-01).

**Открытое решение.** Определить штатную реакцию клапана на согласованное изменение корректного показания.

**Что различит проверка.** При заданном изменении клапан открывается. / При том же изменении клапан остаётся закрытым.

### Z-002 · По какому критерию значение датчика влажности считается некорректным для W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 связывает аварийный переход с некорректным значением, но критерий его распознавания отсутствует.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/requirements.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение.  

**Сценарий.** Подать согласованные показания, проверить их классификацию по заданному критерию и подтвердить обязательный переход в заданное аварийное положение для некорректного входа.

**Последствие.** W-4 связывает аварийный переход с некорректным значением, но критерий его распознавания отсутствует.

**Уже установлено.** Показание поступает от датчика влажности. Некорректное показание требует аварийного перехода. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Задать критерий отнесения показания к некорректным.

**Что различит проверка.** Спорное показание признано некорректным, и аварийный переход обязателен. / То же показание признано корректным, и отсутствие аварийного перехода допустимо по W-4.

**Что различит проверка.** При заданных входных данных панель получает само показание влажности, если источником служит показание. / При тех же входных данных панель получает отличающееся значение, если автор укажет другой источник.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке в полном объёме. Сначала нужно определить исход команды расписания при ручной остановке, аварийное положение клапана и число повторов передачи.

1. Согласовать обработку команды расписания при остановке, аварийное положение клапана и число повторов после первого таймаута. ([Z-004](#z-004), [Z-007](#z-007), [Z-008](#z-008))
2. Завершить обязательное испытание «Возобновить» и определить критерий некорректного показания для проверки аварийного перехода. ([Z-005](#z-005), [Z-002](#z-002))
3. Задать штатную реакцию клапана, состав категории омега и источник значения для панели. ([Z-001](#z-001), [Z-006](#z-006), [Z-003](#z-003))

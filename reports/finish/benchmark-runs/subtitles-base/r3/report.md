## Реестр замечаний

<a id="z-001"></a>

### Z-001 · Место объявления единицы временной метки

**Неоднозначность · Однозначность · Существенная.** T-3 задаёт миллисекунды и значение 1000 для одной секунды. Фраза об объявлении единицы допускает два места проверки, поэтому один и тот же файл может пройти или не пройти проверку формата.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать временную метку в одну секунду. Описание формата объявляет миллисекунды для поля, а файл содержит число 1000 без обозначения единицы.

**Последствие.** Один проверяющий примет файл, другой потребует объявление единицы в самом файле.

**Уже установлено.** Единица каждого поля — миллисекунды. Число 1000 обозначает одну секунду. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0006-01](#r-m0006-01).

**Открытое решение.** Достаточно ли объявить единицу поля в описании формата или объявление должно присутствовать в экспортированном файле?

**Что различит проверка.** Файл со значением 1000 и объявлением единицы только в описании формата проходит проверку. / Тот же файл не проходит проверку, поскольку в самом файле нет объявления единицы.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Должен ли пройти приёмку файл, в котором число 1000 обозначает одну секунду, если миллисекунды объявлены для поля только в описании формата?

1. **Вариант 1.** Единица каждого поля временной метки объявляется в описании формата.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл с числом 1000 проходит проверку объявления единицы.

2. **Вариант 2.** Единица каждого поля временной метки объявляется в самом экспортированном файле.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл с числом 1000 без объявления единицы не проходит эту проверку.

**Черновик приёмочного теста.** Проверить один и тот же файл и описание формата на наличие объявления единицы, применив выбранное автором правило.

## Готовность и порядок исправлений

ТЗ готово к разработке определённой части экспорта. Приёмочные критерии для двух сценариев требуют уточнения.

1. Указать, где должно находиться объявление миллисекунд, и закрепить критерий проверки файла со значением 1000. ([Z-001](#z-001))
2. Определить, создаётся ли файл с допустимой репликой после отклонения реплики из 81 кодовой точки Unicode. ([Z-002](#z-002))

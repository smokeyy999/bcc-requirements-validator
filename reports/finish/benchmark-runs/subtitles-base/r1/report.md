**Сценарий.** Экспортировать дорожку с временной меткой в одну секунду. Проверить значение 1000 и по согласованному признаку подтвердить объявление миллисекунд в каждом поле временной метки.

**Последствие.** T-3 требует объявления миллисекунд в каждом поле. Значение 1000 подтверждает шкалу, а наблюдаемый признак объявления единицы не задан.

**Уже установлено.** Каждое поле объявляет миллисекунды. Одной секунде соответствует значение 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Выбрать наблюдаемое представление объявления миллисекунд в каждом поле.

**Что различит проверка.** В каждом поле миллисекунды указаны в имени поля. / В каждом поле миллисекунды указаны отдельным атрибутом единицы.

**Открытое решение.** Определить результат экспорта для файла и допустимой реплики при отклонении длинной реплики из той же дорожки.

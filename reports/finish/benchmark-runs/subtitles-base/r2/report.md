**По какому правилу проверяющий должен найти поле временной метки и прочитать его объявление миллисекунд в экспортированном файле?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Экспортировать допустимую непустую дорожку с временной меткой в одну секунду. В файле UTF-8 без BOM по согласованному правилу найти поле и проверить объявление миллисекунд и числовое значение 1000.

### Z-001 · Каков ожидаемый результат экспорта в новый файл при отклонении одной реплики, если в дорожке есть и допустимая реплика?

**Сценарий.** Экспортировать в новый локальный файл дорожку с одной допустимой репликой и одной репликой из 81 кодовой точки Unicode. Проверить отклонение длинной реплики по согласованному состоянию файла и его содержимому, если он создан.

**Уже установлено.** Реплика из 81 кодовой точки подлежит отклонению. Сохранение назначения прямо задано для пустой дорожки. Основания — [R-M0014-01](#r-m0014-01), [R-M0003-02](#r-m0003-02), [R-M0015-01](#r-m0015-01), [R-M0010-02](#r-m0010-02).

**Открытое решение.** Определить состояние нового файла после отклонения реплики в смешанной дорожке.

**Что различит проверка.** Создан файл только с допустимой репликой. / Файл отсутствует.

### Z-002 · По какому правилу проверяющий должен найти поле временной метки и прочитать его объявление миллисекунд в экспортированном файле?

**Предполагаемый пробел · Трассируемость · Существенная.** T-1 задаёт кодировку, а T-3 задаёт единицу и числовую шкалу. Для проверки объявления единицы требуется правило чтения поля временной метки в файле.

Затронутые утверждения — [R-M0006-02](#r-m0006-02), [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0006-02](#r-m0006-02) · Subtitle track export / Format · [строка 6](../../../../../benchmark/subtitles/baseline.md#L6)

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second  

**Сценарий.** Экспортировать допустимую непустую дорожку с временной меткой в одну секунду. В файле UTF-8 без BOM по согласованному правилу найти поле и проверить объявление миллисекунд и числовое значение 1000.

**Последствие.** T-1 задаёт кодировку, а T-3 задаёт единицу и числовую шкалу. Для проверки объявления единицы требуется правило чтения поля временной метки в файле.

**Уже установлено.** Файл записывается в UTF-8 без BOM. Каждое поле временной метки объявляет миллисекунды, а значение 1000 соответствует одной секунде. Основания — [R-M0008-01](#r-m0008-01), [R-M0006-02](#r-m0006-02), [R-M0007-01](#r-m0007-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Установить, по какому правилу чтения файла проверяющий связывает поле временной метки с объявлением его единицы.

**Что различит проверка.** Поле со значением 1000 проходит проверку, если согласованный формат объявляет миллисекунды в имени поля. / То же поле без отдельного атрибута единицы не проходит проверку, если согласованный формат требует объявление в таком атрибуте.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Subtitle track export / Format · [строка 9](../../../../../benchmark/subtitles/baseline.md#L9)

> T-4. For a track with 100 cues on workstation ST-1, show the completion dialog no later than 2 seconds after the export command.  

**Сценарий.** На рабочей станции, идентифицированной как ST-1, экспортировать допустимую дорожку со 100 репликами. Проверить, что диалог завершения появляется не позднее чем через 2 секунды после команды экспорта.

**Последствие.** T-4 задаёт число реплик, события начала и конца замера и предел в 2 секунды. Обозначение ST-1 не позволяет идентифицировать станцию, а специальный образец дорожки T-4 не предписывает.

**Уже установлено.** Для дорожки со 100 репликами на ST-1 от команды экспорта до появления диалога должно пройти не более 2 секунд. Основания — [R-M0009-01](#r-m0009-01).

**Открытое решение.** Идентифицировать рабочую станцию ST-1.

**Что различит проверка.** Замер на проверяемой станции засчитывается для приёмки T-4, если это ST-1. / Замер на той же станции не засчитывается для приёмки T-4, если ST-1 обозначает другую станцию.

## Готовность и порядок исправлений

ТЗ пригодно для начала разработки по заданным правилам. Полная приёмка требует трёх уточнений.

1. Задать состояние файла после отклонения длинной реплики в смешанной дорожке. ([Z-001](#z-001))
2. Определить правило чтения поля временной метки и объявления его единицы. ([Z-002](#z-002))
3. Идентифицировать ST-1 для приёмочного замера. ([Z-003](#z-003))

## Проверка набора в целом

ТЗ определяет ручную остановку и возобновление, выбор зоны, аварийное положение клапана и число повторов передачи. Открыты правило открытия по корректному показанию, критерий некорректности и источник значения для панели.

Открытых предполагаемых пробелов — 3. Неоднозначностей — 0. Рекомендаций — 1.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · По какому правилу контроллер открывает закрытый клапан по корректному показанию влажности, когда зона выбрана и ручная остановка не активна?

**Сценарий.** При выбранной зоне, закрытом клапане и неактивной ручной остановке подать корректные показания из согласованных случаев и сверить положение клапана с правилом открытия.

**Последствие.** Контроллер работает по показаниям влажности. W-3 задаёт выбор зоны, а W-4 задаёт положение клапана для некорректного показания. Для корректного показания правило открытия отсутствует.

**Уже установлено.** Контроллер использует показания датчика, оператор выбирает зону, а при некорректном показании клапан закрывается. Основания — [R-M0003-01](#r-m0003-01), [R-M0008-02](#r-m0008-02), [R-M0009-01](#r-m0009-01).

**Открытое решение.** Определить условие открытия клапана по корректному показанию.

**Что различит проверка.** При данном корректном показании клапан открывается. / При том же корректном показании клапан остаётся закрытым.

### Z-002 · Из какого источника берётся значение, которое контроллер передаёт на панель и повторно отправляет после таймаута?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают три повтора передачи. Показание влажности и номер зоны имеют известные источники, но источник передаваемого на панель значения не указан.

Затронутые утверждения — [R-M0013-01](#r-m0013-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Сценарий.** Задать различимые исходные данные по согласованному источнику, вызвать таймаут первой передачи и проверить, что все три повтора содержат то же ожидаемое значение.

**Последствие.** W-6 и W-7 задают три повтора передачи. Показание влажности и номер зоны имеют известные источники, но источник передаваемого на панель значения не указан.

**Уже установлено.** Контроллер повторяет передачу значения на панель ровно три раза. Показание поступает от датчика, номер зоны выбирает оператор. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Установить связь между значением в передаче по W-6 и его источником.

**Что различит проверка.** Если источником служит датчик, три повтора содержат заданное показание влажности. / Если источником служит выбор оператора, три повтора содержат заданный номер зоны.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Для полной приёмки управления по влажности и проверки содержимого передач нужны уточнения.

1. Задать правило открытия клапана по корректным показаниям влажности. ([Z-001](#z-001))
2. Определить критерий некорректного показания для испытания аварийного закрытия. ([Z-003](#z-003))
3. Указать источник значения, передаваемого контроллером на панель. ([Z-002](#z-002))
4. Оставить правило о трёх повторах в W-6 и убрать дублирующую формулировку W-7. ([Z-004](#z-004))

ТЗ задаёт выбор зоны, блокировку последующих открытий, проверку возобновления, аварийное положение и число повторов передачи. Для приёмки нужны критерий некорректности, реакция на корректное показание, состояние клапана при ручной остановке и источник значения для панели. Число повторов продублировано.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

**Открытое решение.** Какое действие с клапаном соответствует каждому корректному показанию в заданном режиме.

**Что различит проверка.** Для одного и того же корректного показания клапан открывается для полива выбранной зоны. / Для того же показания клапан остаётся закрытым.

### Z-003 · По какому критерию показание датчика считается некорректным для обязательного закрытия по W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо требует аварийного закрытия. Для выбора входа, который должен вызвать это действие, нужен критерий некорректности.

**Сценарий.** При открытом клапане подать контрольное показание, проверить его пригодность для испытания по заданному критерию и, если оно некорректно, проверить закрытие клапана.

**Что нужно уточнить.** Относит ли критерий W-4 контрольное показание к некорректным?

**Как ответ изменит приёмку.** Некорректное показание требует закрытия по W-4. Корректное показание не запускает проверку аварийного закрытия.

**Уже установлено.** При некорректном показании клапан должен закрыться. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Как распознать некорректное показание.

**Что различит проверка.** Контрольное показание подходит для проверки W-4, и наблюдаемое закрытие подтверждает требование. / То же показание признано корректным, и наблюдаемое закрытие не засчитывается как проверка W-4.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Полная приёмка автоматики и данных панели требует уточнений.

1. Указать критерий некорректности, реакцию на корректное показание и состояние клапана сразу после ручной остановки. ([Z-003](#z-003), [Z-001](#z-001), [Z-004](#z-004))
2. Указать источник значения для проверки данных на панели при повторе. ([Z-002](#z-002))
3. Сохранить правило о трёх повторах в W-6 и удалить повторяющую его формулировку W-7. ([Z-005](#z-005))

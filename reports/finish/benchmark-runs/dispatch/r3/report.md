## Проверка набора в целом

ТЗ задаёт сообщения при подтверждении и отказе. Допуск к отправке черновика и ведомости из 25 строк, а также срок хранения при значении 7 заданы противоречиво. Для показа «Передано» отсутствует измеримый предел задержки.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Отправка черновика

**Дефект · Противоречивость · Критичная.** S-1 разрешает отправку только из состояния «Готова», а S-2 требует сразу передать черновик при попытке отправки. Проверку допуска к передаче принять невозможно.

Затронутые утверждения — [R-M0006-01](#r-m0006-01), [R-M0007-02](#r-m0007-02).

[R-M0007-02](#r-m0007-02) · Отправка грузовых ведомостей / Отправка · [строка 7](../../../../../benchmark/dispatch/requirements.md#L7)

> При попытке отправить ведомость в состоянии «Черновик» терминал сразу передаёт её перевозчику.  

**Сценарий.** Оператор пытается отправить сохранённую ведомость в состоянии «Черновик». Сеть и авторизация исправны.

**Последствие.** Нельзя определить, должна ли ведомость поступить перевозчику.

**Общее условие.** Оператор пытается отправить сохранённую ведомость в состоянии «Черновик». Основания — [R-M0006-01](#r-m0006-01) «Оператор может отправить ведомость только в состоянии «Готова».», [R-M0007-02](#r-m0007-02) «При попытке отправить ведомость в состоянии «Черновик» терминал сразу передаёт её перевозчику.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** При попытке отправки черновика терминал должен передать ведомость перевозчику или заблокировать передачу?

1. **Вариант 1.** Отправка разрешена только из состояния «Готова».

   **Основание.** [R-M0006-01](#r-m0006-01) «Оператор может отправить ведомость только в состоянии «Готова».».

   **Ожидаемый результат.** Терминал не передаёт черновик перевозчику.

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

2. **Вариант 2.** При попытке отправки из состояния «Черновик» терминал сразу передаёт ведомость перевозчику.

   **Основание.** [R-M0007-02](#r-m0007-02) «При попытке отправить ведомость в состоянии «Черновик» терминал сразу передаёт её перевозчику.».

   **Ожидаемый результат.** Терминал сразу передаёт черновик перевозчику.

**Последствие.** Проверка верхней границы даёт противоположные результаты. Сам по себе приём файла совместим с последующим запретом отправки.

**Общее условие.** Загружается ведомость из 25 строк. Разрешение на отправку проверяется при выполнении условия «Готова». Основания — [R-M0010-02](#r-m0010-02) «Одна ведомость содержит от 1 до 24 строк груза включительно.», [R-M0011-01](#r-m0011-01) «При загрузке ведомости из 25 строк терминал принимает файл и разрешает отправку.», [R-M0006-01](#r-m0006-01) «Оператор может отправить ведомость только в состоянии «Готова».».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

1. **Вариант 1.** Для отправляемой ведомости действует предел в 24 строки включительно.

   **Основание.** [R-M0010-02](#r-m0010-02) «Одна ведомость содержит от 1 до 24 строк груза включительно.».

   **Ожидаемый результат.** Отправка ведомости с 25 строками недоступна.

   При выборе этого варианта привести в соответствие [R-M0011-01](#r-m0011-01).

2. **Вариант 2.** При загрузке ведомости из 25 строк терминал принимает файл и разрешает отправку при выполненном условии «Готова».

   **Основание.** [R-M0011-01](#r-m0011-01) «При загрузке ведомости из 25 строк терминал принимает файл и разрешает отправку.».

   **Ожидаемый результат.** Терминал разрешает отправку ведомости с 25 строками.

   При выборе этого варианта привести в соответствие [R-M0010-02](#r-m0010-02).

**Черновик приёмочного теста.** Загрузить ведомость с 25 строками и проверить доступность отправки при выполненном условии «Готова». Приём файла зафиксировать отдельно.

Затронутые утверждения — [R-M0015-01](#r-m0015-01), [R-M0015-02](#r-m0015-02).

> Срок локального хранения подтверждения задаётся в сутках; значение 7 означает семь часов.  

**Сценарий.** Для локального хранения подтверждения задано значение 7. Обе длительности отсчитываются от начала хранения того же подтверждения.

**Последствие.** Длительность хранения составляет либо 604800000 мс, либо 25200000 мс. Приёмка срока даёт разные результаты.

**Общее условие.** Для срока локального хранения подтверждения задано значение 7. Основания — [R-M0015-01](#r-m0015-01) «Срок локального хранения подтверждения задаётся в сутках», [R-M0015-02](#r-m0015-02) «Срок локального хранения подтверждения задаётся в сутках; значение 7 означает семь часов.».

1. **Вариант 1.** Числовое значение срока локального хранения задаётся в сутках.

   **Ожидаемый результат.** При значении 7 срок составляет семь суток.

   **Основание.** [R-M0015-02](#r-m0015-02) «Срок локального хранения подтверждения задаётся в сутках; значение 7 означает семь часов.».

### R-M0006-01 · Отправка доступна только для ведомости в состоянии «Готова».

Отправка грузовых ведомостей / Отправка · [строка 6](../../../../../benchmark/dispatch/requirements.md#L6)

**Связано с нарушением в спецификации.** S-1 разрешает отправку только из состояния «Готова», а S-2 требует сразу передать черновик при попытке отправки. Проверку допуска к передаче принять невозможно. S-3 ограничивает ведомость 24 строками, а S-4 явно разрешает отправку ведомости из 25 строк. ## Готовность и порядок исправлений

ТЗ требует согласования перед разработкой и приёмкой затронутых сценариев. После согласования поведения и критерия задержки редакционно исправить ссылку S-97. Текст сообщения при отказе уже задан в S-7.

1. Согласовать исход попытки отправки черновика. ([Z-001](#z-001))
2. Согласовать верхнюю границу числа строк и разрешение отправки при загрузке ведомости из 25 строк. ([Z-002](#z-002))
3. Согласовать единицу настройки и срок локального хранения при значении 7. ([Z-003](#z-003))
4. Задать максимальную задержку показа «Передано» после получения подтверждения. ([Z-005](#z-005))

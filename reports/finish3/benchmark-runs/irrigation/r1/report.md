## Проверка набора в целом

При ручной остановке команда расписания получает два несовместимых исхода. После первого таймаута панель должна получить два разных числа повторов. Для аварийного перевода не задано целевое положение, а обязательное испытание возобновления описано только как предстоящее.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-004](#z-004) · W-1 охватывает «все следующие автоматические команды открытия», включая команду расписания. При активной ручной остановке W-1 требует её игнорировать, а W-2 требует немедленно открыть клапан. Приёмка этого сценария заблокирована.
- [Z-007](#z-007) · W-4 требует перевода клапана при некорректном показании. Даже для заведомо некорректного входа целевое положение отсутствует, поэтому аварийную реакцию нельзя принять.
- [Z-008](#z-008) · W-6 и W-7 считают одни и те же повторные передачи значения на панель после первого таймаута. Приёмка обмена заблокирована двумя точными числами повторов.

### Z-004 · Команда расписания при ручной остановке

**Дефект · Противоречивость · Критичная.** W-1 охватывает «все следующие автоматические команды открытия», включая команду расписания. При активной ручной остановке W-1 требует её игнорировать, а W-2 требует немедленно открыть клапан. Приёмка этого сценария заблокирована.

Затронутые утверждения — [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

[R-M0006-01](#r-m0006-01) · Управление поливом теплицы / Автоматика · [строка 6](../../../../../benchmark/irrigation/requirements.md#L6)

> При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».  

[R-M0007-01](#r-m0007-01) · Управление поливом теплицы / Автоматика · [строка 7](../../../../../benchmark/irrigation/requirements.md#L7)

> В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.  

**Сценарий.** Клапан закрыт, режим ручной остановки активен, «Возобновить» не нажимали. Расписание выдаёт автоматическую команду открытия.

**Последствие.** Один и тот же результат испытания проходит по одному правилу и нарушает другое.

**Общее условие.** Ручная остановка активна, «Возобновить» ещё не нажали, расписание выдаёт автоматическую команду открытия. Основания — [R-M0006-01](#r-m0006-01) «При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».», [R-M0007-01](#r-m0007-01) «В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой исход выбрать для команды расписания до возобновления: клапан остаётся закрытым или немедленно открывается?

1. **Вариант 1.** До нажатия «Возобновить» игнорируются все автоматические команды открытия, включая команды расписания.

   **Основание.** [R-M0006-01](#r-m0006-01) «При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».».

   **Ожидаемый результат.** Команда игнорируется, клапан остаётся закрытым.

   При выборе этого варианта привести в соответствие [R-M0007-01](#r-m0007-01).

2. **Вариант 2.** Во время ручной остановки команда открытия от расписания немедленно открывает клапан.

   **Основание.** [R-M0007-01](#r-m0007-01) «В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.».

   **Ожидаемый результат.** Клапан немедленно открывается.

   При выборе этого варианта привести в соответствие [R-M0006-01](#r-m0006-01).

**Черновик приёмочного теста.** В активном режиме ручной остановки подать команду расписания при закрытом клапане и проверить выбранный исход.

### Z-001 · Какое состояние полива ожидается для каждого диапазона корректных показаний с учётом исходного состояния в обычном режиме?

**Сценарий.** В обычном режиме подать корректные показания из согласованных диапазонов при заданных исходных состояниях и сверить состояние полива после каждого показания.

**Уже установлено.** Вход управления поступает с датчика влажности. Для некорректного значения предусмотрен аварийный перевод клапана. Основания — [R-M0003-01](#r-m0003-01), [R-M0009-01](#r-m0009-01).

**Открытое решение.** Какое состояние полива должно следовать из корректного показания при заданном исходном состоянии.

**Что различит проверка.** При заданном показании полив запускается из выключенного состояния. / При том же показании полив остаётся выключенным.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке контроллера. Сначала нужны однозначные исходы команды расписания, повторов передачи и аварийного перевода.

1. Согласовать один исход команды расписания при ручной остановке и одно число повторов после первого таймаута. ([Z-004](#z-004), [Z-008](#z-008))
2. Задать целевое аварийное положение клапана для некорректного показания. ([Z-007](#z-007))
3. Определить реакцию на корректные показания, состояние клапана после ручной остановки и принадлежность зон к категории омега. ([Z-001](#z-001), [Z-003](#z-003), [Z-006](#z-006))
4. Задать контрольный шаг и критерий приёмки кнопки «Возобновить», а также источник значения для проверки повторной передачи панели. ([Z-005](#z-005), [Z-002](#z-002))

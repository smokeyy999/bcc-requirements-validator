### Уточнить ожидаемое поведение

**Каким должно быть состояние файла назначения после экспорта дорожки с одной допустимой репликой и одной отклонённой репликой из 81 кодовой точки Unicode?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Экспортировать такую дорожку в существующий файл с известным содержимым и по пути без файла. В обоих запусках проверить отклонение длинной реплики, наличие файла и его содержимое по согласованному результату.

**Значение 1000 означает одну секунду. По какому признаку в файле проверять, что поле объявляет миллисекунды?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Проверить значение 1000 для отметки в одну секунду и применить согласованный критерий объявления единицы к каждому полю временной метки.

**Как проверяющий идентифицирует рабочую станцию ST-1 для замера с пределом 2 секунды?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — На указанной станции замерить время от команды экспорта дорожки со 100 допустимыми репликами до появления диалога. Принять результат при времени не более 2 секунд.

**Сценарий.** Экспортировать такую дорожку в существующий файл с известным содержимым и по пути без файла. В обоих запусках проверить отклонение длинной реплики, наличие файла и его содержимое по согласованному результату.

**Открытое решение.** Состояние файла назначения после команды экспорта смешанной дорожки.

**Что различит проверка.** Файл создаётся или заменяется и содержит только допустимую реплику. / Существующий файл сохраняется без изменений, отсутствующий файл не создаётся.

<a id="z-002"></a>

### Z-002 · Объявление единицы временной метки

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 требует объявления миллисекунд в каждом поле. Соответствие числа 1000 одной секунде позволяет проверить масштаб. Критерий проверки самого объявления отсутствует.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать дорожку с отметкой в одну секунду и прочитать поле со значением 1000.

**Последствие.** Можно проверить числовое значение, но нельзя принять требование об объявлении миллисекунд.

**Уже установлено.** Каждое поле объявляет миллисекунды. Число 1000 соответствует одной секунде. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Какой наблюдаемый признак в файле подтверждает объявление миллисекунд для поля.

**Что различит проверка.** Поле со значением 1000 и указанием миллисекунд в имени проходит проверку, если имя считается объявлением единицы. / То же поле не проходит проверку, если для объявления требуется отдельный указатель единицы.

### Z-003 · Идентификация ST-1

**Предполагаемый пробел · Ясность · Существенная.** T-4 задаёт число реплик, начало замера, событие завершения и предел в 2 секунды. По документу нельзя определить, какая станция обозначена ST-1.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Subtitle track export / Format · [строка 9](../../../../../benchmark/subtitles/baseline.md#L9)

> For a track with 100 cues on workstation ST-1, show the completion dialog no later than 2 seconds after the export command.  

**Сценарий.** Два проверяющих запускают экспорт одной дорожки со 100 допустимыми репликами и выбирают разные рабочие станции для проверки T-4.

**Последствие.** При разных результатах замера по документу нельзя определить, какой из них относится к ST-1.

**Уже установлено.** На ST-1 диалог должен появиться не позднее 2 секунд после команды экспорта дорожки со 100 репликами. Основания — [R-M0009-01](#r-m0009-01).

**Открытое решение.** Какая рабочая станция соответствует обозначению ST-1.

**Что различит проверка.** Если ST-1 — станция, на которой диалог появился в пределах 2 секунд, проверка проходит. / Если ST-1 — станция, на которой диалог появился позже 2 секунд, проверка не проходит.

## Готовность и порядок исправлений

Базовые сценарии готовы к разработке. Приёмка смешанной дорожки, объявления единиц и времени экспорта требует уточнений.

1. Определить состояние файла назначения при отклонении длинной реплики в смешанной дорожке. ([Z-001](#z-001))
2. Указать проверяемый признак объявления миллисекунд для каждого поля временной метки. ([Z-002](#z-002))
3. Указать, как проверяющий идентифицирует станцию ST-1. ([Z-003](#z-003))

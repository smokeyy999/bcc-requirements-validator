### Z-002 · Объявление единицы временной метки

**Неоднозначность · Однозначность · Существенная.** В T-3 оборот «Each timestamp field declares milliseconds» допускает объявление единицы в экспортированном поле или в его описании. Числовое значение 1000 для одной секунды задано однозначно.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second.  

**Сценарий.** Метка в одну секунду экспортирована как 1000. В файле единица явно не обозначена, а в описании поля она задана в миллисекундах.

**Последствие.** Один и тот же файл может пройти или не пройти проверку T-3.

**Уже установлено.** Единица — миллисекунды. Метке в одну секунду соответствует значение 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0006-02](#r-m0006-02).

**Открытое решение.** Где обязательно объявлять миллисекунды — в самом файле или в описании поля.

**Что различит проверка.** Файл со значением 1000 и объявлением единицы только в описании поля не проходит T-3. / Тот же файл проходит T-3.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Должен ли файл из сценария пройти T-3 или объявление миллисекунд обязательно в самом файле?

1. **Вариант 1.** Каждое поле временной метки должно явно объявлять миллисекунды в экспортированном файле.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл не проходит проверку T-3, поскольку в нём нет объявления единицы.

2. **Вариант 2.** Миллисекунды объявляются в описании каждого поля временной метки, а в файле достаточно числового значения.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл проходит проверку T-3, поскольку 1000 соответствует одной секунде.

**Черновик приёмочного теста.** Экспортировать дорожку с меткой в одну секунду, сверить число 1000 и проверить объявление единицы там, где его требует выбранное правило.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Для однозначной приёмки нужны решения по объявлению единицы в T-3 и результату экспорта при отклонении реплики.

1. Указать, где объявляются миллисекунды, и зафиксировать критерий приёмки файла со значением 1000. ([Z-002](#z-002))
2. Уточнить наличие и содержимое файла при экспорте дорожки с допустимой и отклонённой репликами. ([Z-001](#z-001))

Для попытки отправки черновика и допуска ведомости из 25 строк заданы несовместимые исходы. Для срока хранения со значением 7 заданы две длительности. Показ слова «Передано» определён, но его скорость нельзя оценить без порога. Ссылка S-97 требует редакторской правки. Поведение при отказе перевозчика задано в S-7.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. <a id="r-m0006-01"></a>

### R-M0006-01 · Состояние «Готова» обязательно для отправки ведомости.

Отправка грузовых ведомостей / Отправка · [строка 6](../../../../../benchmark/dispatch/requirements.md#L6)

> Оператор может отправить ведомость только в состоянии «Готова».  

**Связано с нарушением в спецификации.** При одной попытке отправки черновика S-1 запрещает передачу, а S-2 требует её. Приёмка отправки из этого состояния заблокирована. S-3 ограничивает состав ведомости 24 строками, а S-4 разрешает отправку загруженной ведомости из 25 строк. Условие «Готова» не устраняет расхождение, поэтому сценарий загрузки и отправки нельзя принять.

Связанные замечания — [Z-002](#z-002), [Z-003](#z-003).

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке сценариев отправки с противоречивыми исходами. Приёмка срока хранения требует согласованной длительности, а проверка скорости показа подтверждения — измеримого предела.

1. Согласовать исход попытки отправки черновика и допуск к отправке ведомости из 25 строк. ([Z-002](#z-002), [Z-003](#z-003))
2. Согласовать единицу срока локального хранения и длительность для значения 7. ([Z-005](#z-005))
3. Задать максимальную задержку от подтверждения перевозчика до появления слова «Передано». ([Z-004](#z-004))
4. Исправить ссылку S-97 и проверить её адрес по полному тексту ТЗ. ([Z-006](#z-006))

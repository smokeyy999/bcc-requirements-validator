## Проверка набора в целом

ТЗ задаёт выбор зоны, блокировку команд открытия, результат проверки возобновления, закрытие при некорректном показании и число повторов передачи. Для остальных проверок нужны критерий некорректности, штатная реакция на показание, состояние открытого клапана при ручной остановке и ожидаемое значение на панели.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 1.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Уточнить ожидаемое поведение

**Как корректное показание влажности определяет, открыть ли закрытый клапан выбранной зоны, если ручная остановка снята и команды расписания нет?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — При снятой ручной остановке, выбранной зоне и закрытом клапане подать согласованное корректное показание без команды расписания. Сверить состояние клапана с утверждённым правилом для этого показания.

**По какому критерию полученное показание датчика считается некорректным для применения W-4?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — При открытом клапане подать показание датчика, для которого уточняется допустимость. Если критерий относит его к некорректным, проверить закрытие по W-4. Если показание допустимо, оценить состояние клапана по штатному правилу.

**Должен ли уже открытый клапан закрыться вследствие нажатия кнопки ручной остановки до поступления новой команды или показания?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Во время полива нажать кнопку ручной остановки при открытом клапане и проверить его состояние до новой команды или показания. Затем подать автоматическую команду открытия и убедиться, что она игнорируется до нажатия «Возобновить».

**Какое исходное значение контроллер передаёт на панель и по каким данным приёмка определяет его ожидаемую величину?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — Задать согласованные исходные данные, зафиксировать первый таймаут и проверить ровно три повторные передачи. В принятом панелью повторе сверить значение с ожидаемым для исходной передачи.

### Z-002 · По какому критерию полученное показание датчика считается некорректным для применения W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 требует закрыть клапан при некорректном показании. Критерий отнесения показания к некорректным не указан.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать показание датчика, для которого уточняется допустимость. Если критерий относит его к некорректным, проверить закрытие по W-4. Если показание допустимо, оценить состояние клапана по штатному правилу.

**Что нужно уточнить.** Подпадает ли проверяемое показание датчика под обозначение «некорректное значение» в W-4?

**Как ответ изменит приёмку.** Для некорректного показания обязательно закрытие по W-4. Для допустимого показания ожидаемое состояние определяет штатное правило.

**Уже установлено.** На некорректном показании датчика W-4 требует закрыть клапан. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Установить критерий, по которому проверяемое показание подпадает под W-4.

**Что различит проверка.** Закрытие на этом входе обязательно для прохождения аварийной проверки. / Этот вход оценивается по штатному правилу, и отсутствие аварийного закрытия само по себе не нарушает W-4.

## Готовность и порядок исправлений

Частично готово к разработке и приёмке. Описанные сценарии можно реализовать и проверить в пределах заданных условий. Для полной приёмки нужны четыре уточнения.

1. Определить критерий аварийного закрытия и отдельно согласовать состояние открытого клапана при ручной остановке. ([Z-002](#z-002), [Z-003](#z-003))
2. Задать штатную реакцию клапана на корректное показание без команды расписания. ([Z-001](#z-001))
3. Задать передаваемое значение и данные для вычисления ожидаемого результата на панели. ([Z-004](#z-004))
4. Свести W-6 и W-7 в одно требование с тем же числом повторов. ([Z-005](#z-005))

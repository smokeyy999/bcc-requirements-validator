### Z-001 · Какое состояние клапана требуется при каждом условии по корректным показаниям влажности, когда ручная остановка снята и зона выбрана?

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** Снять ручную остановку, выбрать зону и подать корректное показание при заданном исходном состоянии клапана. Сверить действие или сохранение состояния с согласованным правилом для этого показания.

**Последствие.** Фраза «работает по показаниям датчика влажности» задаёт управление по датчику. Выбор зоны и аварийное закрытие определены, а штатная реакция на корректное показание не задана.

**Уже установлено.** Контроллер работает по датчику, оператор выбирает одну зону, некорректное показание требует закрытия, а после возобновления очередная команда открытия исполняется. Основания — [R-M0003-01](#r-m0003-01), [R-M0006-01](#r-m0006-01), [R-M0008-01](#r-m0008-01), [R-M0009-01](#r-m0009-01), [R-M0010-01](#r-m0010-01).

**Открытое решение.** Определить реакцию клапана на корректное показание в штатном режиме.

**Что различит проверка.** При проверяемом корректном показании исходно закрытый клапан открывается. / При том же показании исходно закрытый клапан остаётся закрытым.

<a id="z-002"></a>

### Z-002 · По каким признакам полученное показание влажности считается некорректным для применения W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт исход «Аварийное положение — закрыто». Для приёмки требуется критерий, по которому показание относится к некорректным.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать проверяемое показание и классифицировать его по согласованному критерию. Для некорректного показания проверить закрытие клапана. Для корректного показания исключить W-4 из ожидаемых оснований закрытия.

**Последствие.** W-4 прямо задаёт исход «Аварийное положение — закрыто». Для приёмки требуется критерий, по которому показание относится к некорректным.

**Уже установлено.** Показание приходит от датчика влажности. При получении некорректного значения клапан обязательно закрывается. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Установить, какие показания подпадают под обозначение «некорректного значения датчика».

**Что различит проверка.** Проверяемое показание подпадает под W-4, и приёмка требует закрытия клапана. / То же показание находится вне области W-4, и приёмка обработки этого показания не требует аварийного закрытия по W-4.

<a id="z-003"></a>

### Z-003 · Из какого входа или состояния контроллера берётся значение для передачи на панель по W-6?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 обещает, что контроллер «повторяет передачу значения на панель ровно три раза». Источник значения для панели не указан. Упоминание датчика относится к работе контроллера.

Затронутые утверждения — [R-M0013-01](#r-m0013-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Сценарий.** Задать известное значение в согласованном источнике и вызвать таймаут первой передачи на панель. Проверить три повторные попытки и сверить передаваемое в каждой из них значение с ожидаемым для этого источника.

**Последствие.** W-6 обещает, что контроллер «повторяет передачу значения на панель ровно три раза». Источник значения для панели не указан. Упоминание датчика относится к работе контроллера.

**Уже установлено.** Датчик даёт контроллеру показание влажности. После первого таймаута контроллер трижды повторяет передачу значения на панель. Основания — [R-M0013-01](#r-m0013-01), [R-M0003-01](#r-m0003-01), [R-M0014-01](#r-m0014-01).

**Открытое решение.** Связать значение в передаче на панель с конкретным входом или состоянием контроллера.

**Что различит проверка.** В трёх повторах передаётся заданное показание датчика, если оно указано как источник. / В тех же трёх повторах передаётся отличающееся значение из другого входа или состояния, если источником указан он.

### R-M0013-01 · После первого таймаута контроллер трижды повторяет передачу значения на панель.

Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Связано с нарушением в спецификации.** W-6 обещает, что контроллер «повторяет передачу значения на панель ровно три раза». Источник значения для панели не указан. Упоминание датчика относится к работе контроллера. Фразы «ровно три раза после первого таймаута» и «после первого таймаута равно трём» задают одно число повторов. W-6 также задаёт действие контроллера, поэтому его достаточно для проверки. Фраза «ровно три раза после первого таймаута» задаёт точное число повторов после срабатывания условия. При успешной доставке на первом повторе ожидаемое суммарное число повторов по тексту по-прежнему равно трём.

Связанные замечания — [Z-003](#z-003), [Z-005](#z-005).

## Готовность и порядок исправлений

ТЗ частично готово к разработке и приёмке. Уже заданные сценарии можно реализовывать и проверять. Для остальных нужны согласованные ожидаемые результаты.

1. Задать критерий некорректности показаний и правило управления клапаном по корректным показаниям. ([Z-001](#z-001), [Z-002](#z-002))
2. Уточнить состояние уже открытого клапана после нажатия ручной остановки. ([Z-004](#z-004))
3. Указать источник значения, передаваемого на панель по W-6. ([Z-003](#z-003))
4. Сохранить W-6 как правило действия и числа повторов, удалить дублирующее W-7. ([Z-005](#z-005))

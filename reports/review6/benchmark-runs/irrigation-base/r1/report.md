### Уточнить ожидаемое поведение

**При каких допустимых показаниях клапан должен открыться, если ручная остановка снята, зона выбрана и клапан закрыт?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — При снятой ручной остановке и выбранной зоне подать согласованное допустимое показание на контроллер с закрытым клапаном. Без команды расписания проверить положение клапана по согласованному правилу.

**По какому критерию контроллер должен распознать некорректное показание датчика?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Подать одно заранее зафиксированное показание датчика при открытом клапане. По согласованному критерию определить применимость W-4. Если показание некорректно, проверить закрытие клапана.

**Какое значение контроллер должен передавать панели и из какого источника оно поступает?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Зафиксировать показание датчика и ожидаемое передаваемое значение по указанному источнику. Вызвать первый таймаут и проверить, что контроллер выполнил ровно три повторные передачи панели и каждая содержит ожидаемое значение.

**В какое положение должен перейти открытый клапан при нажатии кнопки ручной остановки?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — Нажать кнопку во время полива при открытом клапане и проверить его положение при отсутствии новых команд и показаний. Для обоих исходов сохранить проверку игнорирования последующих автоматических команд открытия до нажатия «Возобновить».

**Последствие.** «Контроллер одной секции работает по показаниям датчика влажности.» W-4 задаёт аварийное закрытие. Для допустимого показания исход при закрытом клапане не задан.

### Z-002 · По какому критерию контроллер должен распознать некорректное показание датчика?

**Предполагаемый пробел · Ясность · Существенная.** W-4 однозначно задаёт конечное положение словами «Аварийное положение — закрыто.» Для применения правила к фактическому показанию нужен критерий его некорректности.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

**Сценарий.** Подать одно заранее зафиксированное показание датчика при открытом клапане. По согласованному критерию определить применимость W-4. Если показание некорректно, проверить закрытие клапана.

**Что нужно уточнить.** Подпадает ли зафиксированное показание датчика под критерий некорректности W-4?

**Как ответ изменит приёмку.** Для некорректного показания закрытие обязательно. Для допустимого показания проверка аварийного закрытия по W-4 не применяется.

**Уже установлено.** Вход поступает от датчика влажности. При некорректном показании аварийное положение клапана — закрыто. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить, какие показания относятся к некорректным.

**Что различит проверка.** Если клапан остался открыт при некорректном показании, испытание W-4 провалено. / Если то же показание допустимо, открытое положение клапана не нарушает W-4.

### Z-003 · Какое значение контроллер должен передавать панели и из какого источника оно поступает?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают получателя и три повтора. Описание работы по показаниям датчика не связывает их со значением, которое контроллер передаёт панели.

Затронутые утверждения — [R-M0013-01](#r-m0013-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Сценарий.** Зафиксировать показание датчика и ожидаемое передаваемое значение по указанному источнику. Вызвать первый таймаут и проверить, что контроллер выполнил ровно три повторные передачи панели и каждая содержит ожидаемое значение.

**Последствие.** W-6 и W-7 задают получателя и три повтора. Описание работы по показаниям датчика не связывает их со значением, которое контроллер передаёт панели.

**Уже установлено.** Контроллер передаёт значение панели и повторяет передачу ровно три раза после первого таймаута. Основания — [R-M0013-01](#r-m0013-01), [R-M0003-01](#r-m0003-01), [R-M0014-01](#r-m0014-01).

**Открытое решение.** Связать значение в передаче контроллера панели с источником, по которому QA определит ожидаемое содержимое.

**Что различит проверка.** Все три повтора содержат зафиксированное показание датчика, если оно определено как передаваемое значение. / Все три повтора содержат отличающееся от показания значение, если его для того же испытания определяет указанный источник.

### Z-004 · В какое положение должен перейти открытый клапан при нажатии кнопки ручной остановки?

> У оператора есть кнопка ручной остановки.  

[R-M0006-01](#r-m0006-01) · Управление поливом теплицы / Автоматика · [строка 6](../../../../../benchmark/irrigation/baseline.md#L6)

> При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».

**Что нужно уточнить.** Какое положение должен занять уже открытый клапан после нажатия ручной остановки при отсутствии новых команд и показаний?

**Как ответ изменит приёмку.** В зависимости от ответа клапан закрывается при нажатии или остаётся открытым. В обоих случаях последующие автоматические команды открытия игнорируются до возобновления.

**Уже установлено.** После ручной остановки автоматические команды открытия игнорируются до возобновления. Закрытие прямо задано для некорректного показания. Основания — [R-M0003-02](#r-m0003-02), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01), [R-M0009-01](#r-m0009-01), [R-M0010-01](#r-m0010-01).

**Открытое решение.** Определить положение уже открытого клапана после нажатия ручной остановки.

**Что различит проверка.** Клапан закрывается вследствие нажатия. / Клапан остаётся открытым после нажатия при отсутствии других воздействий.

## Готовность и порядок исправлений

Частично готово к разработке и приёмке. Сценарии с заданными исходами можно проверять по текущему ТЗ. Для остальных сценариев ожидаемые результаты зависят от уточнений.

1. Задать критерий некорректного показания и отдельно определить положение открытого клапана при ручной остановке. ([Z-002](#z-002), [Z-004](#z-004))
2. Задать правило открытия клапана по допустимому показанию. ([Z-001](#z-001))
3. Указать источник передаваемого панели значения для проверки содержимого повторов. ([Z-003](#z-003))

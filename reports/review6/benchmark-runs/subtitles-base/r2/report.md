### Z-003 · По какому элементу формата экспорта проверять, что поле временной метки объявляет миллисекунды?

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 требует, чтобы каждое поле объявляло миллисекунды, и задаёт шкалу. Значение 1000 за одну секунду проверяет шкалу, а признак объявления единицы в формате не указан.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать дорожку с меткой в одну секунду. Проверить значение 1000 и отдельно сверить объявление миллисекунд для этого поля по согласованному признаку.

**Последствие.** T-3 требует, чтобы каждое поле объявляло миллисекунды, и задаёт шкалу. Значение 1000 за одну секунду проверяет шкалу, а признак объявления единицы в формате не указан.

**Уже установлено.** Каждое поле объявляет миллисекунды. Одна секунда представлена числом 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0006-01](#r-m0006-01).

**Открытое решение.** Указать наблюдаемый признак объявления миллисекунд для поля временной метки.

**Что различит проверка.** Поле содержит значение 1000, а единица указана в его имени. / Поле содержит значение 1000, а единица указана в отдельном атрибуте этого поля.

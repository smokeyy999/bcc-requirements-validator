## Проверка набора в целом

Правила допуска к отправке расходятся по состоянию и числу строк. Для настройки хранения 7 заданы разные сроки, а для показа «Передано» отсутствует измеримый предел. Ссылка S-97 требует редакторского исправления. Текст и состояние при отказе уже определены в S-7.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

- [Z-001](#z-001) · S-1 разрешает отправку только из состояния «Готова», а S-2 требует сразу передать «Черновик» при той же попытке отправки. Приёмка отправки по состоянию заблокирована.

## Готовность и порядок исправлений

ТЗ не готово к разработке в текущем виде. Сначала требуется согласовать исходы обязательных сценариев отправки и срок хранения для значения 7.

1. Согласовать исход попытки отправки черновика и допуск готовой ведомости из 25 строк. ([Z-001](#z-001), [Z-002](#z-002))
2. Согласовать единицу срока хранения с длительностью для значения 7. ([Z-003](#z-003))
3. Задать максимальную задержку показа «Передано» после подтверждения перевозчика. ([Z-005](#z-005))
4. Исправить ссылку S-97 редакционно с учётом уже заданного поведения при отказе. ([Z-006](#z-006))

## Проверка набора в целом

Правила отправки расходятся для черновика и ведомости из 25 строк. Для хранения подтверждения заданы два разных срока при значении 7, для сообщения «Передано» отсутствует предел задержки. Ссылка S-97 требует редакторской правки. Сообщение об отказе и состояние ведомости уже заданы в S-7.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Готовность и порядок исправлений

ТЗ требует согласования до разработки допуска к отправке. Для полной приёмки также нужны единый срок хранения при значении 7, предел задержки сообщения и исправленная ссылка.

1. Согласовать исход попытки отправить черновик и допустимость отправки готовой ведомости из 25 строк. ([Z-001](#z-001), [Z-002](#z-002))
2. Согласовать единицу хранения со значением 7 и задать максимальную задержку появления слова «Передано». ([Z-005](#z-005), [Z-004](#z-004))
3. Исправить ссылку S-97 с учётом уже заданного поведения при отказе перевозчика. ([Z-006](#z-006))

## Проверка набора в целом

Правила отправки расходятся для черновика и готовой ведомости из 25 строк. Для значения 7 заданы несовместимые сроки хранения. Проверке задержек мешают неопределённые пределы, а проверке S-6 мешает отсутствующее правило S-97.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-001](#z-001) · S-1 разрешает отправку только в состоянии «Готова», а S-2 требует передать «Черновик» при попытке отправки. Для одного действия заданы взаимоисключающие исходы, поэтому правило отправки по состоянию нельзя принять.
- [Z-002](#z-002) · S-3 ограничивает ведомость 24 строками, а S-4 прямо разрешает отправку ведомости из 25 строк. Для загруженной ведомости в состоянии «Готова» нельзя принять правило отправки по размеру. Приём файла по S-4 проверяется отдельно.

## Готовность и порядок исправлений

ТЗ не готово к разработке целиком. Сначала нужно согласовать исходы отправки по состоянию и числу строк.

1. Определить исход попытки отправки черновика и допустимость отправки готовой ведомости из 25 строк. Проверять приём файла отдельно. (Z-001, Z-002)
2. Согласовать единицу срока хранения и длительность для значения 7. (Z-003)
3. Задать предел задержки появления слова «Передано» и, если передачу черновика сохранят, отдельный предел задержки этой передачи. (Z-004)
4. Уточнить ссылку в S-6 и проверить её согласованность с сообщением по S-7. (Z-005)

W-1 и W-2 задают разные состояния клапана при одной команде расписания, а W-6 и W-7 задают разное число повторов при одном условии. W-4 оставляет аварийный сценарий без проверяемого входа и результата. Для приёмки штатного полива требуется правило реакции на корректные показания.

## Критичные дефекты

- [Z-004](#z-004) · До нажатия «Возобновить» W-1 требует игнорировать автоматическую команду расписания, а W-2 требует немедленно открыть по ней клапан. При закрытом клапане исходы взаимоисключающие, поэтому принять ручную остановку в этом сценарии нельзя.
- [Z-007](#z-007) · W-4 требует аварийного перехода клапана, но в ТЗ отсутствуют критерий некорректности показания и целевое положение клапана. Для приёмки аварийного сценария нельзя определить ни вход, ни ожидаемый результат.
- [Z-008](#z-008) · При таймауте каждой попытки W-6 требует ровно три повтора, а W-7 требует пять. Противоречие исключает единый ожидаемый результат приёмки повторной передачи.

### Z-004 · Команда расписания при ручной остановке

**Дефект · Противоречивость · Критичная.** До нажатия «Возобновить» W-1 требует игнорировать автоматическую команду расписания, а W-2 требует немедленно открыть по ней клапан. При закрытом клапане исходы взаимоисключающие, поэтому принять ручную остановку в этом сценарии нельзя.

Затронутые утверждения — [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

[R-M0006-01](#r-m0006-01) · Управление поливом теплицы / Автоматика · [строка 6](../../../../benchmark/irrigation/requirements.md#L6)

> При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».  

[R-M0007-01](#r-m0007-01) · Управление поливом теплицы / Автоматика · [строка 7](../../../../benchmark/irrigation/requirements.md#L7)

> В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.  

**Сценарий.** Клапан закрыт, ручная остановка активна, «Возобновить» не нажата. Расписание выдаёт автоматическую команду открытия.

**Последствие.** По W-1 клапан останется закрытым, по W-2 сразу откроется. Приёмочный тест не может выбрать ожидаемое состояние.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

Согласовать [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01). Черновик для заполнения автором — «При [условиях данного сценария] ожидается [один согласованный исход]».

**Черновик приёмочного теста.** Подать команду расписания до нажатия «Возобновить» и проверить согласованное состояние клапана.

**Последствие.** Нельзя выбрать вход испытания по ТЗ и определить ожидаемое положение клапана.

### R-M0003-01 · Контроллер секции использует показания датчика влажности для управления поливом.

Управление поливом теплицы · [строка 3](../../../../benchmark/irrigation/requirements.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

**Недостаточно данных.** Во вводном описании контроллер работает по показаниям влажности. W-4 охватывает некорректный вход. Для штатного управления по корректным показаниям ожидаемое действие неизвестно, поэтому принять эту функцию нельзя. W-6 и W-7 предусматривают передачу значения панели. <a id="decision"></a>

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке в полном объёме. Сначала нужно согласовать поведение при ручной остановке, аварийный переход, число повторов и правило штатного полива.

1. Согласовать исход команды расписания при ручной остановке, критерий некорректного показания и аварийное положение клапана. (Z-004, Z-007)
2. Установить единое число повторов после первого таймаута. (Z-008)
3. Задать правило управления клапаном по корректным показаниям влажности. (Z-001)
4. Уточнить состояние открытого клапана при остановке, признак категории зоны, источник и содержимое значения для панели и критерий проверки кнопки «Возобновить». (Z-003, Z-006, Z-002, Z-005)
5. Если открытие по расписанию при ручной остановке сохранится, согласовать критерий времени реакции. (Z-009)

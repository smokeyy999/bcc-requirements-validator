Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. ### Z-001 · Должен ли экспорт дорожки с допустимой и отклонённой по T-7 репликами завершиться записью допустимой реплики или прерваться без готового файла?

**Предполагаемый пробел · Полнота · Существенная.** T-7 требует отклонить реплику длиннее 80 кодовых точек Unicode. T-8 подтверждает отклонение при длине 81. Обе фразы описывают судьбу реплики. Исход экспорта дорожки с допустимой и отклонённой репликами остаётся открытым.

**Сценарий.** Экспортировать в новый локальный файл дорожку с двумя репликами, одна из которых содержит 81 кодовую точку Unicode, а другая укладывается в лимит. Проверить отклонение длинной реплики и согласованный исход экспорта.

**Последствие.** T-7 требует отклонить реплику длиннее 80 кодовых точек Unicode. T-8 подтверждает отклонение при длине 81. Обе фразы описывают судьбу реплики. Исход экспорта дорожки с допустимой и отклонённой репликами остаётся открытым.

**Уже установлено.** Реплика длиной 81 кодовую точку отклоняется. T-5 задаёт состояние файла назначения для пустой дорожки. Основания — [R-M0014-01](#r-m0014-01), [R-M0003-02](#r-m0003-02), [R-M0015-01](#r-m0015-01), [R-M0010-02](#r-m0010-02).

**Открытое решение.** Исход экспорта дорожки, в которой вместе с отклонённой репликой есть допустимая.

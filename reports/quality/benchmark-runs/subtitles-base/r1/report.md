## Вопросы к автору ТЗ

### Согласовать до приёмки

**Субтитр из 81 кодовой точки подлежит отклонению. Какой наблюдаемый результат подтверждает это в T-8 и что происходит с допустимыми субтитрами в той же дорожке?**

Блокирует приёмку · [Z-001](#z-001). Зависимый сценарий — Выполнить оба экспорта и сверить результат с уточнением. При отклонении всего экспорта проверить состояние назначения, при экспорте допустимых субтитров проверить содержимое файла.

### Уточнить ожидаемое поведение

**Для каждого поля должны быть объявлены миллисекунды. Где и в каком виде проверяющий должен увидеть это объявление?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Проверить числовое значение 1000 и отдельно подтвердить, что в указанном месте и виде миллисекунды объявлены для каждого поля временной метки.

<a id="z-001"></a>

### Z-001 · Результат отклонения субтитра

**Предполагаемый пробел · Полнота · Существенная.** T-7 и T-8 требуют отклонить субтитр из 81 кодовой точки. В приёмочном примере не задано состояние файла после отклонения, а T-5 определяет его только для пустой дорожки.

Затронутые утверждения — [R-M0014-01](#r-m0014-01), [R-M0015-01](#r-m0015-01).

[R-M0014-01](#r-m0014-01) · Subtitle track export / Export limits · [строка 14](../../../../../benchmark/subtitles/baseline.md#L14)

> T-7. Reject a cue when its text exceeds 80 Unicode code points.  

[R-M0015-01](#r-m0015-01) · Subtitle track export / Export limits · [строка 15](../../../../../benchmark/subtitles/baseline.md#L15)

> T-8. In the acceptance sample, a cue of 81 Unicode code points is rejected.  

**Сценарий.** Выполнить экспорт с субтитром из 81 кодовой точки, как в T-8. Отдельно повторить на дорожке, где есть и допустимый субтитр.

**Последствие.** Проверяющий не может определить, должен ли появиться файл и должны ли в него попасть допустимые субтитры.

**Уже установлено.** Субтитр из 81 кодовой точки подлежит отклонению. Основания — [R-M0015-01](#r-m0015-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0010-01](#r-m0010-01).

**Открытое решение.** Какой результат экспорта ожидается после отклонения субтитра, в том числе при наличии допустимого субтитра?

**Что различит проверка.** При экспорте смешанной дорожки допустимый субтитр записан в файл, а отклонённый отсутствует. / При экспорте той же дорожки новое содержимое не записано.

<a id="z-002"></a>

### Z-002 · Объявление единицы временной метки

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 задаёт масштаб и требует объявления миллисекунд для каждого поля. Значение 1000 подтверждает масштаб, а критерий проверки объявления единицы отсутствует.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать временную метку в одну секунду и получить числовое значение 1000.

**Последствие.** По числу 1000 можно подтвердить масштаб, но нельзя установить, объявлена ли единица для каждого поля.

**Уже установлено.** Каждое поле объявляет миллисекунды, а значение 1000 соответствует одной секунде. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

**Открытое решение.** Какое наблюдаемое представление подтверждает объявление миллисекунд для каждого поля временной метки?

**Что различит проверка.** Файл со значением 1000 проходит проверку, если описание формата в файле явно задаёт миллисекунды для каждого поля. / Тот же файл не проходит проверку, если объявление требуется непосредственно в каждом поле.

1. Указать ожидаемый результат экспорта для примера T-8 и для дорожки с допустимым и отклонённым субтитрами. ([Z-001](#z-001))

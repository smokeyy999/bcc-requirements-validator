Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. ## Критичные дефекты

- [Z-001](#z-001) · S-1 разрешает отправку только из состояния «Готова», а S-2 требует передать ведомость при попытке отправки из состояния «Черновик». Для одной попытки правила дают противоположные результаты, поэтому сценарий отправки по состоянию нельзя принять.
- [Z-002](#z-002) · S-3 ограничивает ведомость 24 строками, а S-4 прямо разрешает отправку ведомости из 25 строк. Даже при выполненном условии «Готова» эти правила не дают единого критерия приёмки допуска к отправке.

### R-M0006-01 · Состояние «Готова» обязательно для отправки.

Отправка грузовых ведомостей / Отправка · [строка 6](../../../../../benchmark/dispatch/requirements.md#L6)

> Оператор может отправить ведомость только в состоянии «Готова».  

**Связано с нарушением в спецификации.** S-1 разрешает отправку только из состояния «Готова», а S-2 требует передать ведомость при попытке отправки из состояния «Черновик». Для одной попытки правила дают противоположные результаты, поэтому сценарий отправки по состоянию нельзя принять. S-3 ограничивает ведомость 24 строками, а S-4 прямо разрешает отправку ведомости из 25 строк. Даже при выполненном условии «Готова» эти правила не дают единого критерия приёмки допуска к отправке.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке в полном объёме. Сначала нужно согласовать ожидаемые исходы двух обязательных сценариев допуска к отправке.

1. Согласовать, поступает ли черновик перевозчику при попытке отправки. ([Z-001](#z-001))
2. Согласовать допуск ведомости из 25 строк в состоянии «Готова». Проверять приём файла и разрешение отправки отдельно. ([Z-002](#z-002))
3. Согласовать единицу настройки и длительность локального хранения при значении 7. ([Z-005](#z-005))
4. Задать максимальную задержку от получения подтверждения перевозчика до показа «Передано». ([Z-003](#z-003))
5. Восстановить трассировку требования S-6 к действующему правилу текста отказа. ([Z-004](#z-004))

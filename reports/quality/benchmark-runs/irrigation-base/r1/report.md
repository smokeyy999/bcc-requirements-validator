**Сценарий.** При открытом клапане и без иных оснований для закрытия подать одно пограничное показание. Если по согласованному критерию оно некорректно, проверить обязательное аварийное закрытие. Если оно корректно, проверить отсутствие аварийного закрытия по W-4.

**Последствие.** W-4 предписывает закрыть клапан при некорректном показании. Для проверки с конкретным входом нужен критерий, по которому это показание признаётся некорректным.

**Уже установлено.** Контроллер работает по показаниям датчика влажности. При некорректном значении клапан должен перейти в закрытое положение. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Как классифицировать показание для аварийного правила.

**Что различит проверка.** Пограничное показание признано некорректным, и клапан аварийно закрывается. / То же показание признано корректным, и аварийного закрытия по W-4 нет.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Для перечисленных проверок требуется уточнить ожидаемые результаты.

1. Определить критерий некорректного показания для проверки аварийного закрытия. ([Z-002](#z-002))
2. Уточнить положение открытого клапана после нажатия ручной остановки. ([Z-004](#z-004))
3. Определить влияние корректного показания на открытие клапана. ([Z-003](#z-003))
4. Установить передаваемое значение и эталон для проверки содержимого повторов. ([Z-001](#z-001))

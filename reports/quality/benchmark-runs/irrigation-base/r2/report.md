Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Обе нормы оставляют закрытый клапан закрытым в этом случае. W-2 выделяет конкретный источник команды в пределах общего правила.

Связанные замечания — [Z-003](#z-003).

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Приёмочные ожидания для открытых сценариев требуют решения автора. Устранение повтора W-7 можно выполнить независимо.

1. Определить критерий некорректности показаний и штатную реакцию на корректные показания. ([Z-004](#z-004), [Z-002](#z-002))
2. Определить положение открытого клапана после нажатия кнопки ручной остановки. ([Z-003](#z-003))
3. Определить ожидаемое значение для панели и данные для его вычисления или выбора. ([Z-001](#z-001))
4. Оставить критерий трёх повторов в W-6 и удалить дубль W-7. ([Z-005](#z-005))

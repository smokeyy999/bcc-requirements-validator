## Проверка набора в целом

Прямые противоречия затрагивают открытие по расписанию при ручной остановке и число повторов передачи. Для аварийной реакции отсутствует конечное положение клапана. Требуют уточнения правило полива по влажности, критерий некорректного показания, принадлежность зоны к категории омега и источник значения для панели. Для сигнала отложенной приёмки W-5 шаг и результат восстанавливаются по W-1 с опорой на R-M0010-01 и R-M0006-01. В режиме ручной остановки нажать «Возобновить» и проверить, что следующая штатная автоматическая команда открытия вне расписания больше не игнорируется из-за ручной остановки.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. ## Критичные дефекты

- [Z-004](#z-004) · Команда расписания входит в класс автоматических команд открытия. До возобновления W-1 требует её игнорировать, а W-2 требует немедленно открыть закрытый клапан. Режим ручной остановки нельзя принять с обоими исходами.

**Дефект · Противоречивость · Критичная.** Команда расписания входит в класс автоматических команд открытия. До возобновления W-1 требует её игнорировать, а W-2 требует немедленно открыть закрытый клапан. Режим ручной остановки нельзя принять с обоими исходами.

Затронутые утверждения — [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

> При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».  

[R-M0007-01](#r-m0007-01) · Управление поливом теплицы / Автоматика · [строка 7](../../../../../benchmark/irrigation/requirements.md#L7)

> В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.  

**Сценарий.** Контроллер в режиме ручной остановки, клапан закрыт, «Возобновить» не нажата. Расписание выдаёт команду открытия.

**Последствие.** Один и тот же тест требует оставить клапан закрытым и немедленно открыть его.

**Общее условие.** В режиме ручной остановки до нажатия «Возобновить» расписание выдаёт автоматическую команду открытия. Основания — [R-M0006-01](#r-m0006-01) «При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».», [R-M0007-01](#r-m0007-01) «В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.».

   **Основание.** [R-M0006-01](#r-m0006-01) «При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».».

   При выборе этого варианта привести в соответствие [R-M0007-01](#r-m0007-01).

2. **Вариант 2.** В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.

   **Основание.** [R-M0007-01](#r-m0007-01) «В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.».

   **Ожидаемый результат.** Клапан немедленно открывается.

   При выборе этого варианта привести в соответствие [R-M0006-01](#r-m0006-01).

**Дефект · Противоречивость · Существенная.** W-6 и W-7 считают повторные передачи одного значения на панель от первого таймаута. Для этой операции требуются одновременно три и пять повторов, поэтому её приёмочный результат не определён.

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/requirements.md#L14)

### Z-003 · Из какого источника и по какому правилу определить ожидаемое значение на входе панели при известном показании датчика?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 описывают передачу контроллера панели. R-M0003-01 называет источник показаний контроллера. Связь этого показания либо другого источника со значением на входе панели не установлена.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/requirements.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/requirements.md#L14)

> Число повторных передач значения на панель после первого таймаута равно пяти.  

**Сценарий.** Зафиксировать показание датчика и данные из указанного источника, принять передачу на панели и сравнить принятое значение с ожидаемым по согласованному правилу.

**Последствие.** W-6 и W-7 описывают передачу контроллера панели. R-M0003-01 называет источник показаний контроллера. Связь этого показания либо другого источника со значением на входе панели не установлена.

**Уже установлено.** Контроллер передаёт значение панели и использует показания датчика влажности в своей работе. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Как связать значение на входе панели с исходными данными для приёмки?

**Что различит проверка.** Панель получает значение, совпадающее с зафиксированным показанием датчика. / Панель получает отличающееся значение, совпадающее с результатом расчёта по указанному источнику.

### Z-005 · Принадлежность зоны к категории омега

**Предполагаемый пробел · Ясность · Существенная.** W-3 задаёт количество включаемых зон и их категорию. По тексту можно проверить количество, а признака категории омега нет.

[R-M0008-02](#r-m0008-02) · Управление поливом теплицы / Автоматика · [строка 8](../../../../../benchmark/irrigation/requirements.md#L8)

> Для полива включается одна «зона категории омега».  

**Сценарий.** В цикле полива включилась ровно одна зона.

**Последствие.** Проверяющий может подтвердить количество, но не соответствие включённой зоны категории.

**Уже установлено.** При поливе должна включаться ровно одна зона категории омега. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** По какому признаку распознать зону категории омега?

**Что различит проверка.** Единственная включённая зона соответствует категории, проверка W-3 проходит. / Та же зона не соответствует категории, проверка W-3 не проходит.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке затронутых сценариев. Сначала нужно согласовать поведение при ручной остановке, аварийное положение клапана и число повторов передачи.

1. Задать единый исход для открытия по расписанию при ручной остановке и конечное положение клапана при заведомо некорректном показании. ([Z-004](#z-004), [Z-006](#z-006))
2. Согласовать одно число повторных передач после первого таймаута. ([Z-007](#z-007))
3. Задать правило запуска полива по влажности, критерий некорректного показания и признак категории омега. ([Z-001](#z-001), [Z-002](#z-002), [Z-005](#z-005))
4. Указать источник и правило определения ожидаемого значения на входе панели. ([Z-003](#z-003))

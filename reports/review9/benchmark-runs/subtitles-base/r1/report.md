### Уточнить ожидаемое поведение

**Должен ли после отклонения длинной реплики появиться файл с единственной допустимой репликой или свободный путь должен остаться свободным?**

**Где и по какому наблюдаемому признаку проверять объявление миллисекунд для каждого поля? Для метки в одну секунду числовое значение в любом случае должно быть 1000.**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Проверить значение 1000 и сверить объявление единицы каждого поля в указанном автором месте.

<a id="z-001"></a>

### Z-001 · Должен ли после отклонения длинной реплики появиться файл с единственной допустимой репликой или свободный путь должен остаться свободным?

**Предполагаемый пробел · Полнота · Существенная.** T-7 и T-8 устанавливают отклонение реплики из 81 кодовой точки. Ни продолжение, ни прекращение экспорта при таком отклонении прямо не заданы.

Затронутые утверждения — [R-M0003-02](#r-m0003-02), [R-M0014-01](#r-m0014-01), [R-M0015-01](#r-m0015-01).

[R-M0003-02](#r-m0003-02) · Subtitle track export · [строка 3](../../../../../benchmark/subtitles/baseline.md#L3)

> A desktop subtitle editor exports one open track to a local file.  

[R-M0014-01](#r-m0014-01) · Subtitle track export / Export limits · [строка 14](../../../../../benchmark/subtitles/baseline.md#L14)

> Reject a cue when its text exceeds 80 Unicode code points.  

[R-M0015-01](#r-m0015-01) · Subtitle track export / Export limits · [строка 15](../../../../../benchmark/subtitles/baseline.md#L15)

> In the acceptance sample, a cue of 81 Unicode code points is rejected.  

**Сценарий.** Экспортировать в свободный локальный путь дорожку с одной допустимой репликой и одной репликой из 81 кодовой точки Unicode. Проверить наличие файла и, если он появился, убедиться, что он содержит только допустимую реплику.

**Что нужно уточнить.** Каков файловый результат экспорта дорожки с допустимой репликой после отклонения второй реплики?

**Как ответ изменит приёмку.** При продолжении экспорта появляется файл с допустимой репликой. При прекращении экспорта свободный путь остаётся свободным.

**Уже установлено.** Реплика из 81 кодовой точки отклоняется. Правило о сохранении состояния назначения действует для пустой дорожки. Основания — [R-M0014-01](#r-m0014-01), [R-M0003-02](#r-m0003-02), [R-M0015-01](#r-m0015-01), [R-M0010-02](#r-m0010-02).

**Открытое решение.** Какой файловый результат требуется для смешанной дорожки после отклонения длинной реплики?

**Что различит проверка.** По указанному пути появился файл только с допустимой репликой. / По указанному пути файл не появился.

<a id="z-002"></a>

### Z-002 · Объявление единицы временных меток

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 требует объявления миллисекунд для каждого поля. Значение 1000 для метки в одну секунду проверяет шкалу, а для проверки самого объявления нужен наблюдаемый признак.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать допустимую дорожку с временной меткой в одну секунду и проверить экспортированное поле.

**Последствие.** Значение 1000 позволяет проверить шкалу, но по нему нельзя принять требование об объявлении единицы.

**Уже установлено.** Каждое поле объявляет миллисекунды. Метке в одну секунду соответствует число 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

**Открытое решение.** Какой наблюдаемый признак подтверждает, что каждое поле объявляет миллисекунды?

**Что различит проверка.** Объявление миллисекунд только в описании каждого поля проходит проверку, если такое описание признаётся объявлением. / То же объявление не проходит проверку, если оно должно присутствовать в самом экспортированном поле.

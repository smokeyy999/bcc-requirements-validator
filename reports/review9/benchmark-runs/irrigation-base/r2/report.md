**Предполагаемый пробел · Ясность · Существенная.** W-4 задаёт результат «Аварийное положение — закрыто.» Критерий распознавания некорректного показания отсутствует.

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать пограничное показание и определить его принадлежность к некорректным по согласованному критерию. Если оно некорректно, проверить закрытие клапана.

**Что нужно уточнить.** Относится ли выбранное пограничное показание к некорректным по критерию W-4?

**Как ответ изменит приёмку.** Для некорректного показания закрытие обязательно. Для показания вне этой категории положение клапана по W-4 не оценивается.

**Уже установлено.** Контроллер использует показания датчика влажности и закрывает клапан при некорректном показании. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить критерий отнесения показания к некорректным.

**Что различит проверка.** Показание подпадает под W-4. Для прохождения проверки клапан должен закрыться. / Показание вне области W-4. Закрытие клапана по этому правилу для данного входа не проверяется.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Для полной приёмки управления клапаном и обмена с панелью нужны уточнения.

1. Задать критерий некорректности и правило управления клапаном по корректной влажности. ([Z-001](#z-001), [Z-002](#z-002))
2. Определить положение открытого клапана сразу после ручной остановки. ([Z-004](#z-004))
3. Указать источник значения для проверки содержимого повторной передачи. ([Z-003](#z-003))
4. Свести W-6 и W-7 в одно требование, сохранив первый таймаут как условие и ровно три повтора. ([Z-005](#z-005))

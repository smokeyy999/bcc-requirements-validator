### Z-004 · По какому критерию контроллер должен определять, что полученное показание датчика некорректно?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт результат «Аварийное положение — закрыто.». Критерий, по которому показание подпадает под это правило, отсутствует.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать одно фиксированное показание. По согласованному критерию определить, применимо ли W-4. Если показание некорректно, проверить закрытие клапана.

**Что нужно уточнить.** Относится ли фиксированное показание в испытании к некорректным значениям.

**Как ответ изменит приёмку.** Для некорректного показания W-4 требует закрытия клапана. Для допустимого показания W-4 не применяется.

**Уже установлено.** При некорректном показании контроллер обязан выполнить переход. «Аварийное положение — закрыто.» Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить, подпадает ли фиксированное показание под обозначение «некорректного значения датчика».

**Что различит проверка.** Для этого входа открытый клапан обязан закрыться, и сохранение открытого положения нарушает W-4. / Этот вход находится вне области W-4, и по нему нельзя оценить выполнение аварийного закрытия.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Для полной приёмки автоматики и обмена с панелью нужны ответы на четыре вопроса.

1. Определить реакцию клапана на допустимые показания и отдельно задать критерий некорректного показания для проверки аварийного закрытия. ([Z-001](#z-001), [Z-004](#z-004))
2. Установить ожидаемое состояние уже открытого клапана после нажатия кнопки ручной остановки. ([Z-003](#z-003))
3. Задать содержимое повторных передач на панель. ([Z-002](#z-002))
4. Оставить одно требование о трёх повторных передачах после первого таймаута. ([Z-005](#z-005))

### Уточнить ожидаемое поведение

**Каким должно стать положение клапана после получения выбранного для проверки корректного показания, если зона выбрана, клапан закрыт, ручная остановка снята и команды расписания нет?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Выбрать зону, снять ручную остановку и при закрытом клапане подать согласованное корректное показание без команды расписания. Сверить положение клапана с ответом автора.

**Из какого источника определяется значение, которое панель должна получить при повторной передаче по W-6?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Задать известное показание датчика и контрольные данные для указанного источника. Вызвать первый таймаут, проверить ровно три повторные передачи и сверить полученное панелью значение с ожидаемым по указанному источнику.

**В каком положении должен оказаться уже открытый клапан сразу после ручной остановки до поступления других управляющих событий?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Во время полива нажать кнопку ручной остановки, проверить положение клапана и сверить его с ответом автора. Затем до нажатия «Возобновить» подать автоматическую команду открытия и проверить, что контроллер её игнорирует.

**По каким признакам контроллер должен относить показание к некорректным для применения W-4, включая показание на границе допустимости, если такая граница задана?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — При открытом клапане подать выбранное показание, классификацию которого нужно уточнить. Если оно некорректно по согласованному критерию, проверить закрытие по W-4. Если оно корректно, оценивать реакцию по штатному правилу.

### Z-001 · Каким должно стать положение клапана после получения выбранного для проверки корректного показания, если зона выбрана, клапан закрыт, ручная остановка снята и команды расписания нет?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер «работает по показаниям датчика влажности». W-3 задаёт выбор зоны, а W-4 задаёт реакцию на некорректное показание. Для корректного показания штатная реакция клапана остаётся открытой.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/baseline.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** Выбрать зону, снять ручную остановку и при закрытом клапане подать согласованное корректное показание без команды расписания. Сверить положение клапана с ответом автора.

**Последствие.** Контроллер «работает по показаниям датчика влажности». W-3 задаёт выбор зоны, а W-4 задаёт реакцию на некорректное показание. Для корректного показания штатная реакция клапана остаётся открытой.

**Уже установлено.** Контроллер использует показания влажности. Оператор выбирает зону. Некорректное показание требует закрытия клапана. После возобновления очередная команда открытия исполняется. Основания — [R-M0003-01](#r-m0003-01), [R-M0008-02](#r-m0008-02), [R-M0009-01](#r-m0009-01), [R-M0010-01](#r-m0010-01).

**Открытое решение.** Ожидаемое положение клапана после выбранного корректного показания в штатном режиме.

**Что различит проверка.** Клапан открывается после получения показания. / Клапан остаётся закрытым после получения того же показания.

### Z-002 · Из какого источника определяется значение, которое панель должна получить при повторной передаче по W-6?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают три повтора передачи значения панели. В документе заданы показание на входе контроллера и номер зоны, выбранный оператором. Связь передаваемого значения с его источником отсутствует.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/baseline.md#L14)

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Сценарий.** Задать известное показание датчика и контрольные данные для указанного источника. Вызвать первый таймаут, проверить ровно три повторные передачи и сверить полученное панелью значение с ожидаемым по указанному источнику.

**Последствие.** W-6 и W-7 задают три повтора передачи значения панели. В документе заданы показание на входе контроллера и номер зоны, выбранный оператором. Связь передаваемого значения с его источником отсутствует.

**Уже установлено.** Контроллер передаёт значение панели и выполняет ровно три повтора после первого таймаута. Показание датчика поступает контроллеру, номер зоны задаёт оператор на панели. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0008-02](#r-m0008-02), [R-M0009-01](#r-m0009-01).

**Открытое решение.** Связь между значением, получаемым панелью при повторе, и данными, из которых контроллер его берёт.

**Что различит проверка.** При трёх повторах панель получает контрольное показание датчика, если оно указано как источник. / При тех же трёх повторах панель получает отличающееся контрольное значение, если указан другой источник.

**Открытое решение.** Положение уже открытого клапана непосредственно после ручной остановки.

### Z-004 · По каким признакам контроллер должен относить показание к некорректным для применения W-4, включая показание на границе допустимости, если такая граница задана?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо фиксирует результат словами «Аварийное положение — закрыто.» Открытым остаётся критерий, по которому показание подпадает под W-4.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать выбранное показание, классификацию которого нужно уточнить. Если оно некорректно по согласованному критерию, проверить закрытие по W-4. Если оно корректно, оценивать реакцию по штатному правилу.

**Что нужно уточнить.** Принадлежность выбранного показания к некорректным по W-4.

**Как ответ изменит приёмку.** При некорректном показании W-4 требует закрытия. При корректном показании W-4 к этому входу не применяется.

**Уже установлено.** W-4 требует перевести клапан в закрытое положение при получении некорректного показания. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Классификация выбранного показания для применения W-4.

**Что различит проверка.** Если выбранное показание некорректно, для прохождения теста по W-4 клапан должен закрыться. / Если то же показание корректно, обязательное аварийное закрытие для этого входа в тест по W-4 не входит.

### Z-005 · Дублирование числа повторов

**Дефект · Дублирование · Низкая.** Для одной передачи на панель после первого таймаута W-6 требует «ровно три раза», а W-7 повторяет «равно трём». W-6 полностью задаёт проверяемое действие. Удаление W-7 оставит одну запись для сопровождения.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

**Последствие.** Обе записи требуют ровно три повтора. Раздельное сопровождение создаёт риск расхождения при изменении числа.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Аварийное положение, блокировка будущих открытий, возобновление и число повторов определены. Для полной приёмки нужны ожидаемые результаты по открытым вопросам.

1. Определить критерий некорректного показания и отдельно задать штатную реакцию на корректное показание. ([Z-004](#z-004), [Z-001](#z-001))
2. Уточнить положение уже открытого клапана при ручной остановке. ([Z-003](#z-003))
3. Связать значение, получаемое панелью при повторе, с источником данных. ([Z-002](#z-002))
4. Оставить число повторов в W-6 и удалить дублирующую запись W-7. ([Z-005](#z-005))

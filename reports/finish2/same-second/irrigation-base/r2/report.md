## Проверка набора в целом

Для штатного полива отсутствует ожидаемая реакция на корректное показание. Для аварийного закрытия задано положение клапана, но требуется критерий срабатывания. Отдельного уточнения требуют эффект ручной остановки при открытом клапане и источник значения для панели. Правило трёх повторов однозначно и продублировано.

Открытых предполагаемых пробелов — 3. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Задать различимые показание датчика и номер выбранной зоны. Вызвать первый таймаут исходной передачи, проверить ровно три повтора и сверить значение в сообщениях на входе панели с указанным источником.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

> Число повторных передач значения на панель после первого таймаута равно трём.

**Последствие.** W-6 и W-7 задают три повтора после первого таймаута. Показание влажности и номер зоны описаны отдельно, а связь передаваемого значения с его источником не задана.

Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0008-01](#r-m0008-01).

**Открытое решение.** Связать значение на входе панели с конкретным источником у контроллера.

**Что различит проверка.** При трёх повторах значение на входе панели соответствует заданному показанию датчика, если источником указано показание. / При тех же трёх повторах значение на входе панели соответствует выбранному номеру зоны, если источником указан номер зоны.

<a id="decision"></a>

## Готовность и порядок исправлений

ТЗ не готово к разработке штатного управления поливом и его приёмке до определения реакции на корректные показания. Проверки возобновления и количества повторов можно подготовить по действующему тексту.

1. Задать ожидаемую реакцию клапана на корректные показания в штатном режиме. ([Z-001](#z-001))
2. Определить критерий аварийного входа и положение открытого клапана после ручной остановки. ([Z-004](#z-004), [Z-003](#z-003))
3. Связать передаваемое на панель значение с его источником. ([Z-002](#z-002))
4. Оставить правило трёх повторов в W-6 и удалить его дубль W-7. ([Z-005](#z-005))

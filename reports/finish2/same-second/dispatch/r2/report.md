## Проверка набора в целом

Правила отправки задают несовместимые исходы для черновика и ведомости из 25 строк. Для хранения подтверждения значение 7 имеет два значения срока, а для показа «Передано» отсутствует измеримый порог. В правиле об отказе перевозчика требуется исправить ссылку S-97. Текст сообщения и состояние ведомости уже заданы в S-7.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-001](#z-001) · S-1 разрешает отправку только в состоянии «Готова», а S-2 требует передачи той же ведомости при попытке отправить её из состояния «Черновик». Приёмка отправки черновика требует единого ожидаемого исхода.
- [Z-002](#z-002) · S-3 ограничивает вместимость одной ведомости 24 строками груза. S-4 принимает ведомость из 25 строк и разрешает её отправку. Для этой ведомости порядок изменения состава или исключение из предела не заданы. Приёмка допуска к отправке невозможна даже при выполненном условии «Готова».

### R-M0006-01 · Отправка допустима только для ведомости в состоянии «Готова».

Отправка грузовых ведомостей / Отправка · [строка 6](../../../../../benchmark/dispatch/requirements.md#L6)

> Оператор может отправить ведомость только в состоянии «Готова».  

**Связано с нарушением в спецификации.** S-1 разрешает отправку только в состоянии «Готова», а S-2 требует передачи той же ведомости при попытке отправить её из состояния «Черновик». Приёмка отправки черновика требует единого ожидаемого исхода.

Связанные замечания — [Z-001](#z-001).

### R-M0010-01 · В ведомости допускается максимум 24 строки груза.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке отправки. Сначала нужно согласовать передачу черновика и допуск ведомости из 25 строк.

1. Согласовать исход попытки отправки черновика и допустимость отправки ведомости из 25 строк. ([Z-001](#z-001), [Z-002](#z-002))
2. Установить единый срок хранения для значения 7 и максимальную задержку показа «Передано» после подтверждения перевозчика. ([Z-003](#z-003), [Z-005](#z-005))
3. Исправить ссылку S-97 редакторской правкой. ([Z-006](#z-006))

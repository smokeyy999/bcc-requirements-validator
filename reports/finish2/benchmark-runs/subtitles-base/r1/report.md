**Уже установлено.** Реплика из 81 кодовой точки Unicode отклоняется. Правило о сохранении назначения относится к пустой дорожке. Основания — [R-M0003-01](#r-m0003-01), [R-M0014-01](#r-m0014-01), [R-M0015-01](#r-m0015-01), [R-M0010-02](#r-m0010-02).

### Z-003 · Какая рабочая станция соответствует обозначению ST-1 в T-4?

**Предполагаемый пробел · Ясность · Существенная.** T-4 задаёт объём дорожки, начало и конец замера и предел в 2 секунды. Для применения этого предела нужно определить, какую станцию обозначает ST-1.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Subtitle track export / Format · [строка 9](../../../../../benchmark/subtitles/baseline.md#L9)

> For a track with 100 cues on workstation ST-1, show the completion dialog no later than 2 seconds after the export command.  

**Сценарий.** Экспортировать одну и ту же дорожку из 100 допустимых реплик на двух станциях, рассматриваемых как ST-1. Для станции, соответствующей уточнённому обозначению, проверить появление диалога завершения не позднее чем через 2 секунды после команды.

**Что нужно уточнить.** Соответствует ли рабочая станция, на которой проведён замер, обозначению ST-1?

**Как ответ изменит приёмку.** На ST-1 замер определяет выполнение T-4. На другой станции тот же замер лежит вне условий T-4.

**Уже установлено.** На ST-1 для дорожки из 100 реплик диалог завершения должен появиться не позднее чем через 2 секунды после команды. Основания — [R-M0009-01](#r-m0009-01).

**Открытое решение.** По чему приёмщик определяет соответствие рабочей станции обозначению ST-1?

**Что различит проверка.** Замер на проверяемой станции засчитывается при оценке T-4. / Замер на той же станции лежит вне условий T-4.

## Готовность и порядок исправлений

Можно начинать разработку по определённым правилам. Ожидаемые результаты для трёх проверок следует зафиксировать до приёмки.

1. Определить состояние файла назначения после отклонения реплики в смешанной дорожке. ([Z-001](#z-001))
2. Указать, какая рабочая станция соответствует ST-1. ([Z-003](#z-003))
3. Указать представление объявления миллисекунд для каждого поля временной метки. ([Z-002](#z-002))

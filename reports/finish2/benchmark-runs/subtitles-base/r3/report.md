### Z-001 · Обозначение единицы временной метки

**Неоднозначность · Однозначность · Существенная.** Фраза «Each timestamp field declares milliseconds» допускает указание единицы в определении поля или в самом экспортированном поле. От этого зависит приёмка поля, содержащего только 1000.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds; the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать метку в одну секунду, проверить числовое значение 1000 и оценить поле без обозначения единицы по выбранному правилу.

**Последствие.** Один и тот же файл может пройти или провалить проверку T-3.

**Уже установлено.** T-3 задаёт миллисекунды и число 1000 для одной секунды. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Где требуется указать единицу временной метки.

**Что различит проверка.** Поле со значением 1000 без обозначения единицы проходит проверку. / То же поле проваливает проверку из-за отсутствия обозначения единицы.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Достаточно ли указать миллисекунды в определении поля, чтобы поле со значением 1000 без обозначения единицы прошло проверку T-3?

1. **Вариант 1.** Миллисекунды заданы определением поля. В файле достаточно числового значения.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Поле со значением 1000 проходит проверку.

2. **Вариант 2.** В экспортированном файле каждое поле явно обозначает миллисекунды.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Поле со значением 1000 без обозначения единицы проваливает проверку.

**Черновик приёмочного теста.** Экспортировать метку в одну секунду, проверить числовое значение 1000 и оценить поле без обозначения единицы по выбранному правилу.

### Z-002 · Каков ожидаемый результат экспорта дорожки с репликами из 81 и 80 кодовых точек Unicode после обязательного отклонения первой, включая состояние файла и судьбу второй реплики?

**Предполагаемый пробел · Полнота · Существенная.** T-7 и T-8 требуют отклонить реплику из 81 кодовой точки Unicode. Они оставляют открытым результат экспорта дорожки, где есть и реплика из 80 кодовых точек.

Затронутые утверждения — [R-M0014-01](#r-m0014-01), [R-M0015-01](#r-m0015-01).

[R-M0014-01](#r-m0014-01) · Subtitle track export / Export limits · [строка 14](../../../../../benchmark/subtitles/baseline.md#L14)

> Reject a cue when its text exceeds 80 Unicode code points.  

[R-M0015-01](#r-m0015-01) · Subtitle track export / Export limits · [строка 15](../../../../../benchmark/subtitles/baseline.md#L15)

> In the acceptance sample, a cue of 81 Unicode code points is rejected.  

**Сценарий.** Экспортировать дорожку с репликами из 81 и 80 кодовых точек Unicode по пути, где файла ещё нет. Проверить, появился ли файл, какие реплики в него вошли и что реплика из 81 кодовой точки исключена из результата.

**Последствие.** T-7 и T-8 требуют отклонить реплику из 81 кодовой точки Unicode. Они оставляют открытым результат экспорта дорожки, где есть и реплика из 80 кодовых точек.

**Уже установлено.** Реплику из 81 кодовой точки требуется отклонить. Реплика из 80 кодовых точек не превышает порог T-7. T-5 задаёт состояние файла для пустой входной дорожки. Основания — [R-M0014-01](#r-m0014-01), [R-M0015-01](#r-m0015-01), [R-M0003-01](#r-m0003-01), [R-M0010-02](#r-m0010-02).

**Открытое решение.** Какой результат остаётся по пути назначения после отклонения длинной реплики в смешанной дорожке.

**Что различит проверка.** Создаётся файл, содержащий только реплику из 80 кодовых точек. / Экспорт прекращается, файл не создаётся и реплика из 80 кодовых точек не записывается.

## Готовность и порядок исправлений

ТЗ готово к разработке однозначно заданных частей. Для завершения приёмки нужно определить формат поля временной метки и результат экспорта смешанной дорожки.

1. Определить, где указывается единица временной метки, и зафиксировать исход проверки поля с числом 1000. ([Z-001](#z-001))
2. Уточнить состояние выходного файла и судьбу реплики из 80 кодовых точек при обязательном отклонении реплики из 81 кодовой точки. ([Z-002](#z-002))

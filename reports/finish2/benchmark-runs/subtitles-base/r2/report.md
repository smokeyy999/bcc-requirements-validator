### Z-001 · Обозначение миллисекунд в поле

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 задаёт и числовую шкалу, и объявление единицы в каждом поле. Значение 1000 подтверждает шкалу для одной секунды. Критерий проверки объявления единицы в файле отсутствует.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать дорожку с временной меткой в одну секунду. В поле обнаружено число 1000.

**Последствие.** Числовая проверка проходит, а результат проверки объявления единицы зависит от того, какое представление допускает T-3.

**Уже установлено.** Каждое поле объявляет миллисекунды. Метка в одну секунду имеет числовое значение 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Определить, какое представление в файле приёмка считает объявлением миллисекунд в каждом поле.

**Что различит проверка.** Поле со значением 1000 и атрибутом единицы «ms» проходит проверку, если такой атрибут принят как объявление. / То же поле не проходит проверку, если для объявления установлен другой формат.

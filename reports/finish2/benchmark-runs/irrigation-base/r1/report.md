**Открытое решение.** Определить состав передаваемого значения и правило его получения для заданного входа.

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо требует закрыть клапан при некорректном показании. Критерия, по которому конкретное показание попадает под это правило, в документе нет.

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

**Сценарий.** При открытом клапане подать пограничное показание. Если по согласованному критерию оно некорректно, проверить закрытие клапана. Если оно корректно, проверять реакцию по правилу для корректного входа.

**Что нужно уточнить.** Считается ли выбранное пограничное показание некорректным по W-4?

**Как ответ изменит приёмку.** Для некорректного показания W-4 требует закрытия. Для корректного показания закрытие по W-4 не проверяется.

**Уже установлено.** Получение некорректного значения датчика требует перевода клапана в закрытое положение. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить принадлежность показаний к некорректным для W-4.

**Что различит проверка.** Для выбранного показания открытый клапан остаётся открытым, и проверка W-4 завершается отказом, если показание признано некорректным. / При том же наблюдении проверка W-4 неприменима, если показание признано корректным.

## Готовность и порядок исправлений

Можно принять число повторов. Приёмочные тесты управления по показаниям и содержимого обмена требуют уточнений.

1. Определить критерий некорректности и проверить аварийное закрытие. ([Z-003](#z-003))
2. Задать ожидаемую реакцию клапана на корректные показания в указанном сценарии. ([Z-001](#z-001))
3. Определить ожидаемое значение для сверки трёх повторов на границе обмена с панелью. ([Z-002](#z-002))
4. Оставить W-6 как единое требование о трёх повторах. ([Z-004](#z-004))

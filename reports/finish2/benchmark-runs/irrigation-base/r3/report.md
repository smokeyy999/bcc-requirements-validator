## Проверка набора в целом

ТЗ задаёт аварийное положение, блокировку последующих команд до возобновления, выбор зоны и число повторов. Для полной приёмки нужны критерий некорректности, правила реакции на корректную влажность и ручную остановку, а также содержимое передачи на панель.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Вопросы к автору ТЗ

Вопросы приведены в порядке согласования. Автор ТЗ фиксирует решение, затем QA проверяет указанный сценарий.

### Уточнить ожидаемое поведение

**Какое значение контроллер передаёт панели и по каким данным определить его ожидаемое содержимое?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Задать различимые исходные данные, вызвать таймаут первой передачи и проверить содержимое каждой из трёх повторных передач на входе панели.

**По какому критерию показание датчика считается некорректным для W-4?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Зафиксировать тестовое показание и подать его при открытом клапане. Если показание подпадает под согласованный критерий, проверить закрытие. Иначе W-4 к этому входу не применяется.

**Как корректное показание влажности влияет на подачу команды открытия при выбранной зоне и снятой ручной остановке?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — При закрытом клапане, выбранной зоне и снятой ручной остановке подать одно и то же корректное показание без команды расписания. Сверить подачу команды открытия с согласованным правилом.

**В каком положении должен оказаться уже открытый клапан после нажатия кнопки ручной остановки при отсутствии новых команд?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — Нажать кнопку при открытом клапане без новых команд и сверить его положение с ответом. Затем подать автоматическую команду открытия и проверить, что контроллер её игнорирует до возобновления.

**Последствие.** W-6 и W-7 задают три повторные передачи после первого таймаута. Содержимое передачи на панель не определено. Источники показания влажности и номера зоны описаны без связи с этой передачей.

**Уже установлено.** Контроллер трижды повторяет передачу на панель. Показание приходит от датчика, номер зоны задаёт оператор. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0008-01](#r-m0008-01).

**Открытое решение.** Определить содержимое передаваемого значения по исходным данным.

**Что различит проверка.** В каждом повторе панель получает заданное показание влажности. / В каждом повторе панель получает номер выбранной зоны.

### Z-002 · По какому критерию показание датчика считается некорректным для W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 задаёт закрытие клапана при некорректном показании. Без критерия некорректности нельзя выбрать вход для этой проверки.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** Зафиксировать тестовое показание и подать его при открытом клапане. Если показание подпадает под согласованный критерий, проверить закрытие. Иначе W-4 к этому входу не применяется.

**Что нужно уточнить.** Подпадает ли выбранное тестовое показание под критерий некорректности W-4.

**Как ответ изменит приёмку.** Для некорректного входа W-4 требует закрытия клапана. Для входа вне этого условия W-4 не задаёт ожидаемого положения.

**Уже установлено.** Контроллер использует показания датчика и закрывает клапан при некорректном входе. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Установить критерий отнесения показания к некорректным.

**Что различит проверка.** Выбранный вход подпадает под W-4, и приёмка требует закрытия клапана. / Выбранный вход вне области W-4, и испытание аварийного закрытия требует другого показания.

**Открытое решение.** Определить правило формирования команды открытия по корректному показанию.

## Готовность и порядок исправлений

Определённые правила готовы к разработке. Полную приёмку можно подготовить после уточнения ожидаемых результатов.

1. Задать критерий некорректности для испытания аварийного закрытия. ([Z-002](#z-002))
2. Определить реакцию на корректную влажность и положение открытого клапана при ручной остановке. ([Z-003](#z-003), [Z-004](#z-004))
3. Определить содержимое повторных передач для проверки на входе панели. ([Z-001](#z-001))
4. Оставить одну формулировку правила трёх повторов. ([Z-005](#z-005))

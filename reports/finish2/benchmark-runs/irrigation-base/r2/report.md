## Проверка набора в целом

ТЗ задаёт аварийное положение клапана, блокировку автоматических открытий до возобновления и число повторов передачи. Для приёмки нужно уточнить критерий некорректного показания, реакцию на корректные показания, положение открытого клапана после ручной остановки и источник передаваемого значения.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Из какого источника следует брать ожидаемое значение для проверки исходной передачи на панель и трёх её повторов?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают три повтора исходной передачи. По показаниям датчика и выбору зоны нельзя установить, откуда взять ожидаемое значение для сверки.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/baseline.md#L14)

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Сценарий.** Задать различимые исходные данные, вызвать первый таймаут и сверить содержимое исходной передачи и всех трёх повторов со значением из указанного источника.

**Последствие.** W-6 и W-7 задают три повтора исходной передачи. По показаниям датчика и выбору зоны нельзя установить, откуда взять ожидаемое значение для сверки.

**Уже установлено.** Контроллер отправляет значение на панель и повторяет передачу трижды после первого таймаута. Отдельно описаны показание датчика и номер выбранной зоны. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0008-01](#r-m0008-01).

**Открытое решение.** Указать связь между значением в передаче на панель и источником, по которому QA может определить ожидаемое содержимое.

**Что различит проверка.** Если источником назначено показание датчика, во всех трёх повторах ожидается исходное показание. / Если источником назначен номер зоны, во всех трёх повторах ожидается исходный номер зоны.

### Z-002 · При каких корректных показаниях влажности и условиях контроллер должен открыть исходно закрытый клапан без команды расписания и при выключенной ручной остановке?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер работает по показаниям влажности. W-4 задаёт закрытие при некорректном показании. Для корректного показания при закрытом клапане правило открытия отсутствует.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/baseline.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** При закрытом клапане, выключенной ручной остановке и без команды расписания подать корректное показание и сверить состояние клапана с заданным правилом открытия.

**Последствие.** Контроллер работает по показаниям влажности. W-4 задаёт закрытие при некорректном показании. Для корректного показания при закрытом клапане правило открытия отсутствует.

**Уже установлено.** Контроллер использует показания влажности. Аварийное закрытие задано для некорректного показания. При ручной остановке автоматические команды открытия блокируются. Основания — [R-M0003-01](#r-m0003-01), [R-M0009-01](#r-m0009-01), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

**Открытое решение.** Задать правило открытия клапана по корректному показанию в указанном режиме.

**Что различит проверка.** На выбранном корректном показании клапан открывается. / На том же корректном показании клапан остаётся закрытым.

**Открытое решение.** Задать положение уже открытого клапана после обработки нажатия.

<a id="z-004"></a>

### Z-004 · По какому критерию контроллер должен считать полученное показание датчика некорректным?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо требует закрыть клапан при некорректном показании. Критерий, по которому показание попадает под это правило, отсутствует.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать показание датчика и определить его класс по заданному критерию. Если показание некорректно, проверить закрытие клапана по W-4.

**Что нужно уточнить.** Относится ли выбранное показание датчика к некорректным по критерию W-4.

**Как ответ изменит приёмку.** Для некорректного показания закрытие обязательно. Для корректного показания ожидаемое положение определяют применимые правила обычного управления.

**Уже установлено.** Входом служит показание датчика влажности. Некорректное показание требует аварийного закрытия. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Задать критерий отнесения показания к некорректным.

**Что различит проверка.** Выбранное показание подпадает под W-4. Приёмка требует закрытия клапана. / То же показание находится вне области W-4. По этому правилу состояние клапана не оценивается.

### R-M0013-01 · После первого таймаута контроллер выполняет ровно три повторные передачи значения на панель.

Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Связано с нарушением в спецификации.** W-6 и W-7 задают три повтора исходной передачи. По показаниям датчика и выбору зоны нельзя установить, откуда взять ожидаемое значение для сверки. W-6 и W-7 дублируют одно обязательство. После первого таймаута контроллер должен ровно трижды повторить передачу значения на панель. При изменении числа повторов обе формулировки придётся обновить. Для приёмки числа повторов достаточно фразы «ровно три раза после первого таймаута». Обоснование выбора числа не меняет ожидаемый результат. Дублирование зарегистрировано отдельно.

Связанные замечания — [Z-001](#z-001), [Z-005](#z-005).

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Для полной приёмки автоматики и проверки содержимого передач нужны уточнения.

1. Задать положение открытого клапана после ручной остановки. ([Z-003](#z-003))
2. Определить критерий некорректного показания и отдельно задать правило открытия по корректным показаниям. ([Z-004](#z-004), [Z-002](#z-002))
3. Указать источник значения для проверки передачи на панель и её повторов. ([Z-001](#z-001))
4. Оставить одну формулировку правила о трёх повторах. ([Z-005](#z-005))

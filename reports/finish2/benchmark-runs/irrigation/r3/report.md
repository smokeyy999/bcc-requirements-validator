## Проверка набора в целом

ТЗ задаёт взаимоисключающие исходы для команды расписания при ручной остановке и для повторов передачи панели. Для аварийной реакции требуется определить условие срабатывания и конечное положение клапана. Остаётся определить штатное действие по показанию, категорию зоны, источник передаваемого значения и содержание испытания «Возобновить».

Открытых предполагаемых пробелов — 2. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-004](#z-004) · До нажатия «Возобновить» W-1 требует игнорировать все автоматические команды открытия. W-2 требует немедленно открыть клапан по автоматической команде расписания в том же режиме. Принять поведение ручной остановки для этой команды нельзя.
- [Z-008](#z-008) · W-4 прямо требует перевести клапан в аварийное положение. Положение не названо, поэтому даже на входе с уже установленной некорректностью аварийную реакцию принять нельзя.
- [Z-009](#z-009) · W-6 требует ровно три повтора, а W-7 требует пять. Оба правила считают повторные передачи того же значения на панель после первого таймаута. Единого критерия приёмки повторов нет.

### Z-004 · Команда расписания при ручной остановке

**Дефект · Противоречивость · Критичная.** До нажатия «Возобновить» W-1 требует игнорировать все автоматические команды открытия. W-2 требует немедленно открыть клапан по автоматической команде расписания в том же режиме. Принять поведение ручной остановки для этой команды нельзя.

Затронутые утверждения — [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

[R-M0006-01](#r-m0006-01) · Управление поливом теплицы / Автоматика · [строка 6](../../../../../benchmark/irrigation/requirements.md#L6)

> W-1. При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».  

[R-M0007-01](#r-m0007-01) · Управление поливом теплицы / Автоматика · [строка 7](../../../../../benchmark/irrigation/requirements.md#L7)

> W-2. В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.  

**Сценарий.** Клапан закрыт, действует ручная остановка, «Возобновить» не нажата. Расписание отправляет автоматическую команду открытия.

**Последствие.** По W-1 команда игнорируется и клапан остаётся закрытым. По W-2 команда немедленно открывает клапан. Исключение для расписания явно не установлено.

**Общее условие.** Во время ручной остановки до нажатия «Возобновить» поступает автоматическая команда открытия от расписания. Основания — [R-M0006-01](#r-m0006-01) «При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».», [R-M0007-01](#r-m0007-01) «В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой исход выбрать для команды расписания до нажатия «Возобновить» — клапан остаётся закрытым или немедленно открывается?

1. **Вариант 1.** При ручной остановке до нажатия «Возобновить» игнорируются все автоматические команды открытия, включая команды расписания.

   **Основание.** [R-M0006-01](#r-m0006-01) «W-1. При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».».

   **Ожидаемый результат.** Клапан остаётся закрытым.

   При выборе этого варианта привести в соответствие [R-M0007-01](#r-m0007-01).

2. **Вариант 2.** При ручной остановке команда открытия от расписания немедленно открывает клапан. Остальные автоматические команды открытия игнорируются до нажатия «Возобновить».

   **Основание.** [R-M0007-01](#r-m0007-01) «W-2. В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.».

   **Ожидаемый результат.** Клапан немедленно открывается.

   При выборе этого варианта привести в соответствие [R-M0006-01](#r-m0006-01).

**Черновик приёмочного теста.** При закрытом клапане и действующей ручной остановке подать команду открытия от расписания и проверить состояние клапана по выбранному правилу.

### Z-008 · Аварийное положение клапана

**Дефект · Полнота · Критичная.** W-4 прямо требует перевести клапан в аварийное положение. Положение не названо, поэтому даже на входе с уже установленной некорректностью аварийную реакцию принять нельзя.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/requirements.md#L9)

> W-4. При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение.  

**Сценарий.** Контроллер получил показание, которое по согласованному критерию считается некорректным.

**Последствие.** Известно, что контроллер обязан перевести клапан в аварийное положение, но невозможно определить требуемое конечное состояние.

**Уже установлено.** Условие W-4 выполнено, и контроллер обязан перевести клапан в аварийное положение. Основания — [R-M0009-01](#r-m0009-01).

**Открытое решение.** Задать конечное положение клапана при срабатывании W-4.

**Что различит проверка.** По тому же некорректному показанию клапан достигает закрытого положения. / По тому же некорректному показанию клапан достигает открытого положения.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какое конечное положение клапана обязательно при некорректном показании?

Внести ответ на этот вопрос в [R-M0009-01](#r-m0009-01) для сценария «Контроллер получил показание, которое по согласованному критерию считается некорректным.».

**Черновик приёмочного теста.** Подать согласованное некорректное показание и проверить достижение указанного положения.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке затронутых сценариев. Первоочередные решения нужны для ручной остановки, аварийного положения клапана и числа повторов после таймаута.

1. Согласовать действие по команде расписания до нажатия «Возобновить». ([Z-004](#z-004))
2. Задать конечное аварийное положение клапана и отдельно определить критерий некорректности показания. ([Z-008](#z-008), [Z-002](#z-002))
3. Установить единое число повторных передач после первого таймаута. ([Z-009](#z-009))
4. Описать проверочную команду и наблюдаемый результат обязательного испытания «Возобновить». ([Z-006](#z-006))
5. Определить штатное действие по корректному показанию и критерий принадлежности зоны к категории «омега». ([Z-001](#z-001), [Z-007](#z-007))
6. Указать источник значения, которое контроллер передаёт панели. ([Z-003](#z-003))

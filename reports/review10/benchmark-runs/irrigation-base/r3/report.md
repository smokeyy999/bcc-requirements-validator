W-4 задаёт целевое положение клапана словами «Аварийное положение — закрыто.» Для приёмки нужно определить критерий некорректности, реакцию на корректное показание, эффект ручной остановки на текущий полив и источник значения для панели. W-6 и W-7 дублируют число повторов.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Каким должно быть положение уже открытого клапана после получения согласованного корректного показания при выбранной зоне, вне ручной остановки и без команды расписания?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер работает по показаниям влажности. W-4 задаёт реакцию на некорректное показание. Для согласованного корректного показания без команды расписания итоговое положение клапана не задано.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/baseline.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** Выбрать зону, установить клапан в открытое положение и вне ручной остановки подать согласованное корректное показание без команды расписания. Сверить итоговое положение клапана с ответом.

**Последствие.** Контроллер работает по показаниям влажности. W-4 задаёт реакцию на некорректное показание. Для согласованного корректного показания без команды расписания итоговое положение клапана не задано.

**Уже установлено.** Контроллер работает по показаниям влажности, зона выбирается оператором. Обязательное аварийное закрытие задано для некорректного показания. Основания — [R-M0003-01](#r-m0003-01), [R-M0009-01](#r-m0009-01), [R-M0008-01](#r-m0008-01), [R-M0007-01](#r-m0007-01).

**Открытое решение.** Итоговое положение уже открытого клапана после получения выбранного корректного показания в условиях теста.

**Что различит проверка.** После получения показания клапан остаётся открытым. / После получения того же показания клапан закрывается.

<a id="z-002"></a>

### Z-002 · По какому критерию полученное показание датчика считается некорректным для W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 задаёт положение «закрыто», но не определяет, какие показания считаются некорректными. Сам по себе предполагаемый диапазон датчика границу применимости W-4 не устанавливает.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** Подать выбранное для проверки критерия показание при открытом клапане. Если по согласованному критерию показание некорректно, проверить обязательное закрытие. Если показание корректно, оценивать положение клапана по правилам для корректного входа.

**Что нужно уточнить.** Неизвестно, относится ли выбранное показание к некорректным по W-4.

**Как ответ изменит приёмку.** Для некорректного показания клапан обязан закрыться. Для корректного показания W-4 не задаёт его положение.

**Уже установлено.** Источник входа задан. Для заведомо некорректного показания результат указан прямо: «Аварийное положение — закрыто.» Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Критерий, по которому одно и то же показание подпадает под W-4.

**Что различит проверка.** Показание некорректно. Если клапан остаётся открытым, W-4 нарушено. / То же показание корректно. Если клапан остаётся открытым, это не нарушает W-4.

<a id="z-003"></a>

### Z-003 · Из какого источника берётся значение, которое контроллер передаёт на панель по W-6?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают три повтора передачи на панель после первого таймаута. Документ называет датчик источником показаний для контроллера, но не связывает эти показания с передаваемым значением.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/baseline.md#L14)

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Сценарий.** Зафиксировать контрольное значение для согласованного источника и вызвать первый таймаут передачи на панель. Подтвердить ровно три повторные передачи и сверить переданное значение с контрольным.

**Последствие.** W-6 и W-7 задают три повтора передачи на панель после первого таймаута. Документ называет датчик источником показаний для контроллера, но не связывает эти показания с передаваемым значением.

**Уже установлено.** Заданы отправитель, получатель и число повторов. Датчик поставляет контроллеру показания влажности. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Связь между значением в передаче на панель и его исходными данными.

**Что различит проверка.** При трёх повторах передаётся контрольное показание датчика, если автор укажет его источником. / При тех же трёх повторах передаётся отличающееся контрольное значение из другого источника, если автор укажет его.

### Z-004 · Каким должно быть положение уже открытого клапана после нажатия кнопки ручной остановки, если новых команд нет?

**Предполагаемый пробел · Полнота · Существенная.** W-1 и W-2 определяют обработку команд открытия в режиме ручной остановки. Положение уже открытого клапана сразу после нажатия кнопки остаётся неопределённым.

Затронутые утверждения — [R-M0003-02](#r-m0003-02), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

[R-M0006-01](#r-m0006-01) · Управление поливом теплицы / Автоматика · [строка 6](../../../../../benchmark/irrigation/baseline.md#L6)

> При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».  

[R-M0007-01](#r-m0007-01) · Управление поливом теплицы / Автоматика · [строка 7](../../../../../benchmark/irrigation/baseline.md#L7)

> В режиме ручной остановки команда открытия от расписания не открывает клапан.  

**Сценарий.** Во время полива нажать кнопку ручной остановки при открытом клапане и без новых команд сверить его положение с ответом. Затем до нажатия «Возобновить» подать автоматическую команду открытия и проверить, что она проигнорирована.

**Последствие.** W-1 и W-2 определяют обработку команд открытия в режиме ручной остановки. Положение уже открытого клапана сразу после нажатия кнопки остаётся неопределённым.

**Уже установлено.** Ручная остановка блокирует последующие автоматические команды открытия до нажатия «Возобновить». Основания — [R-M0006-01](#r-m0006-01), [R-M0003-02](#r-m0003-02), [R-M0007-01](#r-m0007-01), [R-M0010-01](#r-m0010-01).

**Открытое решение.** Положение уже открытого клапана после ручной остановки при отсутствии новых команд.

**Что различит проверка.** После нажатия клапан закрывается, текущий полив прекращается. / После нажатия клапан остаётся открытым, текущий полив продолжается.

### Z-005 · Дублирование числа повторных передач

**Дефект · Дублирование · Низкая.** W-6 и W-7 задают одно число повторных передач на панель после первого таймаута. Обе нормы покрывает один тест.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/baseline.md#L14)

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Сценарий.** Вызвать первый таймаут и подсчитать повторные передачи отдельно от исходной.

**Последствие.** Одна проверка трёх повторов покрывает два самостоятельных требования с совпадающим содержанием.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

Проект правки по [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01) — Оставить одну норму о трёх повторных передачах после первого таймаута и привязать к ней общий тест.

**Черновик приёмочного теста.** Открыть исправленные пункты [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01) и проверить выполнение предложенной правки «Оставить одну норму о трёх повторных передачах после первого таймаута и привязать к ней общий тест.».

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Приёмочные ожидания для перечисленных сценариев требуют уточнения. Подтверждённых блокирующих дефектов нет.

1. Определить критерий срабатывания аварийного закрытия и положение уже открытого клапана после ручной остановки. ([Z-002](#z-002), [Z-004](#z-004))
2. Задать ожидаемое положение клапана после согласованного корректного показания в указанном сценарии. ([Z-001](#z-001))
3. Указать источник значения для проверки передачи на панель. ([Z-003](#z-003))
4. Свести W-6 и W-7 к одной норме о трёх повторах и привязать к ней общий тест. ([Z-005](#z-005))

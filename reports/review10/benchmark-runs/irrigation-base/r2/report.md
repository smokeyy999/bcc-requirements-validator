## Проверка набора в целом

Для штатного управления клапаном отсутствует правило реакции на корректные показания влажности. Требуется уточнить состояние открытого клапана после ручной остановки, критерий некорректного показания и источник значения для панели. Число повторов определено двумя совпадающими требованиями.

Открытых предполагаемых пробелов — 3. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Вопросы к автору ТЗ

Вопросы приведены в порядке согласования. Автор ТЗ фиксирует решение, затем QA проверяет указанный сценарий.

### Согласовать до приёмки

**Какое состояние должен принять закрытый клапан при получении выбранного для проверки корректного показания влажности, если зона выбрана и ручная остановка снята?**

Блокирует приёмку · [Z-002](#z-002). Зависимый сценарий — При снятой ручной остановке, выбранной зоне и закрытом клапане подать согласованное корректное показание влажности и проверить заданное для него состояние клапана.

### Уточнить ожидаемое поведение

**Из какого исходного значения контроллер формирует содержимое передачи на панель?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Задать различимые показание влажности и номер выбранной зоны, вызвать первый таймаут и проверить содержимое всех трёх повторных передач по указанному источнику.

**В каком состоянии должен быть уже открытый клапан сразу после ручной остановки, если новых команд открытия ещё не было?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — При открытом клапане нажать кнопку ручной остановки и проверить состояние клапана до следующей команды. Затем проверить, что до нажатия «Возобновить» последующие автоматические команды открытия игнорируются.

**По какому признаку показание датчика считается некорректным для применения W-4?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — При открытом клапане подать контрольное показание, классифицировать его по указанному критерию и, если оно некорректно, проверить закрытие клапана.

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт результат «Аварийное положение — закрыто.» Для испытания нужен критерий, по которому входное показание считается некорректным.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

**Сценарий.** При открытом клапане подать контрольное показание, классифицировать его по указанному критерию и, если оно некорректно, проверить закрытие клапана.

**Последствие.** W-4 прямо задаёт результат «Аварийное положение — закрыто.» Для испытания нужен критерий, по которому входное показание считается некорректным.

**Что различит проверка.** Если показание некорректно, оставшийся открытым клапан означает провал проверки W-4. / Если показание корректно, оставшийся открытым клапан на этом входе не нарушает W-4.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке штатного управления клапаном до задания реакции на корректные показания влажности.

1. Задать правило изменения состояния клапана по корректным показаниям влажности. ([Z-002](#z-002))
2. Определить состояние открытого клапана после ручной остановки и критерий применения аварийного закрытия. ([Z-003](#z-003), [Z-004](#z-004))
3. Указать источник значения, передаваемого на панель. ([Z-001](#z-001))
4. Свести правила о трёх повторных передачах к одной норме. ([Z-005](#z-005))

## Проверка набора в целом

ТЗ задаёт несовместимые исходы для команды расписания при ручной остановке и для повторов после таймаута. Аварийный переход обязателен, но его конечное положение отсутствует. Обязательное испытание кнопки «Возобновить» отложено. Для остальных проверок нужны критерии некорректности показания и принадлежности зоны, реакция на допустимое показание и источник значения для панели.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-004](#z-004) · Команда расписания входит в класс автоматических команд открытия. При действующей ручной остановке W-1 требует её игнорировать, а W-2 требует немедленно открыть клапан. Проверить, удерживает ли ручная остановка клапан закрытым в этом сценарии, невозможно.
- [Z-007](#z-007) · W-4 обязывает перевести клапан в аварийное положение, но указанное положение нигде не задано. Аварийный переход нельзя принять даже на заведомо некорректном входе.
- [Z-008](#z-008) · W-6 и W-7 задают один счётчик повторов одной передачи на панель после первого таймаута. Значения три и пять взаимоисключающие, поэтому обязательный сценарий восстановления обмена нельзя принять.

Блокирует приёмку · [Z-007](#z-007). Зависимый сценарий — При открытом клапане подать заведомо некорректное показание и сравнить конечное положение с заданным автором.

Блокирует приёмку · [Z-008](#z-008). Зависимый сценарий — Вызвать первый таймаут, оставить повторные передачи без подтверждения и подсчитать передачи после первого таймаута.

**Какой шаг должен выполнить приёмщик при проверке кнопки «Возобновить» по W-5 и какое наблюдение подтверждает, что нажатие завершило ранее действовавший период игнорирования?**

Уточнить, какие действия и наблюдения обязательны для приёмки по W-5.

### Уточнить ожидаемое поведение

**Как должен отреагировать контроллер на допустимое показание влажности при закрытом клапане, если ручная остановка не активна и команды расписания нет?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Зафиксировать допустимое показание, для которого автор указал ожидаемую реакцию. Подать его при закрытом клапане без ручной остановки и команды расписания. Сверить наблюдаемую реакцию с заданной.

**По какому критерию числовое показание датчика считается некорректным для применения W-4?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Подать одно контрольное числовое показание. По заданному критерию проверить, должен ли для этого входа сработать обязательный аварийный переход W-4.

**Из какого источника контроллер берёт значение, которое передаёт панели и повторно отправляет после первого таймаута?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Зафиксировать известное показание датчика и контрольное значение указанного автором источника. Вызвать первый таймаут и сверить значение в первой повторной передаче панели с контрольным значением этого источника.

**Как определить, относится ли конкретная зона к категории омега по W-3?**

Требует уточнения · [Z-006](#z-006). Зависимый сценарий — Запустить полив, проверить включение ровно одной зоны и сверить принадлежность этой зоны к категории омега по заданному правилу.

### Z-004 · Открытие по расписанию при ручной остановке

**Дефект · Противоречивость · Критичная.** Команда расписания входит в класс автоматических команд открытия. При действующей ручной остановке W-1 требует её игнорировать, а W-2 требует немедленно открыть клапан. Проверить, удерживает ли ручная остановка клапан закрытым в этом сценарии, невозможно.

Затронутые утверждения — [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01).

[R-M0006-01](#r-m0006-01) · Управление поливом теплицы / Автоматика · [строка 6](../../../../../benchmark/irrigation/requirements.md#L6)

> При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».  

[R-M0007-01](#r-m0007-01) · Управление поливом теплицы / Автоматика · [строка 7](../../../../../benchmark/irrigation/requirements.md#L7)

> В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.  

**Сценарий.** Клапан закрыт, действует ручная остановка, «Возобновить» ещё не нажали. Расписание отправляет команду открытия.

**Последствие.** Клапан должен одновременно остаться закрытым по W-1 и открыться по W-2.

**Общее условие.** Действует ручная остановка, «Возобновить» ещё не нажали, от расписания поступает команда открытия. Основания — [R-M0006-01](#r-m0006-01) «При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».», [R-M0007-01](#r-m0007-01) «В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой исход принять для команды расписания при ручной остановке: клапан остаётся закрытым или открывается?

1. **Вариант 1.** До нажатия «Возобновить» игнорируются все автоматические команды открытия, включая команду расписания.

   **Основание.** [R-M0006-01](#r-m0006-01) «При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».».

   **Ожидаемый результат.** Клапан остаётся закрытым.

   При выборе этого варианта привести в соответствие [R-M0007-01](#r-m0007-01).

2. **Вариант 2.** При ручной остановке команда открытия от расписания немедленно открывает клапан.

   **Основание.** [R-M0007-01](#r-m0007-01) «В режиме ручной остановки команда открытия от расписания немедленно открывает клапан.».

   **Ожидаемый результат.** Клапан открывается.

   При выборе этого варианта привести в соответствие [R-M0006-01](#r-m0006-01).

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке в части ручной остановки, аварийного перехода и повторных передач. Приёмка кнопки «Возобновить» требует согласованного сценария.

1. Установить единый исход для команды расписания при ручной остановке и задать конечное аварийное положение клапана. ([Z-004](#z-004), [Z-007](#z-007))
2. Установить одно точное число повторов после первого таймаута. ([Z-008](#z-008))
3. Задать обязательный шаг проверки кнопки «Возобновить» и достаточное для приёмки наблюдение. ([Z-005](#z-005))
4. Определить критерий некорректного показания, реакцию на допустимое показание, принадлежность зоны к категории омега и источник значения для панели. ([Z-002](#z-002), [Z-001](#z-001), [Z-006](#z-006), [Z-003](#z-003))

### R-M0014-01 · После первого таймаута число повторных передач на панель равно трём.

Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/baseline.md#L14)

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Нарушений не выявлено.** При сквозной проверке это утверждение исключено из оснований замечания. W-6 и W-7 задают один критерий приёмки: ровно три повторные передачи после первого таймаута. Редакционный повтор не меняет ожидаемого поведения контроллера.

## Готовность и порядок исправлений

ТЗ частично готово. Можно проверять выбор зоны, блокировку последующих автоматических открытий при ручной остановке и число повторов передачи. Приёмка аварийного закрытия блокируется до определения критерия некорректного показания.

1. Определить признаки некорректного показания и выбрать входы для испытания аварийного закрытия. (Z-003)
2. Задать действия клапана по корректным показаниям влажности и при ручной остановке во время полива. (Z-001, Z-004)
3. Согласовать результат совместной обработки очередной команды открытия и некорректного показания после возобновления. (Z-005)
4. Определить передаваемое значение и его источник для проверки на панели. (Z-002)

<a id="z-002"></a>

### Z-002 · Место объявления единицы времени

**Неоднозначность · Однозначность · Существенная.** T-3 допускает прочтение поля как элемента файла или как элемента описания формата. Оба прочтения сохраняют значение 1000 для одной секунды, но дают разные результаты проверки объявления единицы.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second  

**Сценарий.** Экспортировать метку в одну секунду. В файле записано число 1000, а единица указана только в описании формата.

**Последствие.** Один и тот же файл может пройти или не пройти проверку объявления единицы.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Объявлять миллисекунды в экспортируемом файле или достаточно указать их в описании формата?

1. **Вариант 1.** В экспортируемом файле для каждого поля временной метки явно объявляются миллисекунды.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл с числом 1000 без объявления единицы в самом файле не проходит проверку.

2. **Вариант 2.** Миллисекунды объявляются в описании формата каждого поля временной метки. В файле достаточно числового значения.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл с числом 1000 проходит проверку единицы и масштаба.

**Черновик приёмочного теста.** Проверить значение 1000 и объявление единицы в артефакте, который назовёт автор.

2. Указать, где проверять объявление миллисекунд. (Z-002)
3. Идентифицировать ST-1 для приёмочного замера. (Z-003)

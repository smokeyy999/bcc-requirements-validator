## Проверка набора в целом

Правила расходятся в передаче черновика, допуске готовой ведомости из 25 строк и длительности хранения при значении 7. Для показа «Передано» отсутствует измеримый предел. При отказе текст и состояние заданы, остаётся уточнить, покрывает ли показ по S-7 требование S-6.

Открытых предполагаемых пробелов — 1. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

- [Z-001](#z-001) · S-1 разрешает отправку только из состояния «Готова». S-2 при той же попытке отправки черновика требует передать его перевозчику. Нельзя определить ожидаемый результат основного сценария.

**Что нужно уточнить.** Неизвестно, исчерпывает ли показ по S-7 правило вывода текста, на которое ссылается S-6 при том же отказе перевозчика.

**Как ответ изменит приёмку.** Если правила совпадают, показ строки покрывает S-6. Если S-6 включает дополнительное условие вывода, для приёмки нужна его проверка.

**Уже установлено.** При отказе перевозчика терминал показывает «Передача отклонена» и оставляет ведомость в состоянии «Готова». Основания — [R-M0013-01](#r-m0013-01), [R-M0014-02](#r-m0014-02).

**Открытое решение.** Полностью ли показ строки по S-7 покрывает требование S-6 к выводу текста?

**Что различит проверка.** Показ «Передача отклонена» при отказе достаточен для приёмки S-6. / При том же отказе показ «Передача отклонена» выполняет S-7, а для приёмки S-6 требуется проверка дополнительного правила вывода текста.

## Готовность и порядок исправлений

ТЗ не готово к разработке. До реализации нужно согласовать исход отправки черновика и допуск готовой ведомости из 25 строк.

1. Согласовать факт передачи черновика и допустимость отправки готовой ведомости из 25 строк. ([Z-001](#z-001), [Z-002](#z-002))
2. Согласовать единицу хранения и длительность при значении 7. ([Z-003](#z-003))
3. Задать предельное время от подтверждения перевозчика до показа слова «Передано». ([Z-005](#z-005))
4. Уточнить, полностью ли показ текста по S-7 выполняет S-6 при отказе перевозчика. ([Z-006](#z-006))

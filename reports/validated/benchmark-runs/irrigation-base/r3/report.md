## Проверка набора в целом

ТЗ задаёт аварийное закрытие, блокировку последующих открытий, возобновление и число повторов передачи. Для приёмки остаётся определить критерий некорректности, правило открытия по корректной влажности, реакцию уже открытого клапана на ручную остановку и содержимое передачи на панель.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

**Открытое решение.** К какой категории относится проверяемое показание по критерию W-4?

### R-M0013-01 · После первого таймаута контроллер делает ровно три повторные передачи значения на панель.

Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Связано с нарушением в спецификации.** W-6 и W-7 задают получателя и число повторов. Связь отправляемого значения с показанием датчика или другим источником не установлена. W-6 и W-7 задают ровно три повтора одной передачи после первого таймаута. Редакционная правка сохраняет полный критерий в W-6 и устраняет двойное сопровождение. «Ровно три раза после первого таймаута» задаёт общее число повторов. Исключение при успехе одного из повторов не указано. Точное число уже является проверяемым условием.

Связанные замечания — [Z-002](#z-002), [Z-005](#z-005).

Основания для снятия замечания — [R-M0014-01](#r-m0014-01).

## Готовность и порядок исправлений

Частично готово к разработке. Заданные переходы и число повторов можно реализовать. Ожидаемые результаты по открытым сценариям нужно согласовать до их приёмки.

1. Определить критерий некорректности для проверки аварийного закрытия. ([Z-004](#z-004))
2. Определить, при каких корректных показаниях открывается клапан выбранной зоны. ([Z-001](#z-001))
3. Уточнить положение уже открытого клапана после ручной остановки. ([Z-003](#z-003))
4. Указать источник и правило получения передаваемого значения для проверки исходной передачи и повторов. ([Z-002](#z-002))
5. Оставить критерий трёх повторов в W-6 и удалить дублирующую запись W-7. ([Z-005](#z-005))

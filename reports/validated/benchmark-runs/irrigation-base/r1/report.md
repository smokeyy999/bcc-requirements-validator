**По какому критерию полученное показание датчика считается некорректным для применения W-4?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — При открытом клапане подать пограничное показание. По согласованному критерию определить, применимо ли W-4. Для некорректного показания проверить обязательное закрытие, для корректного исключить эту подачу из проверки W-4.

### Z-002 · По какому критерию полученное показание датчика считается некорректным для применения W-4?

**Предполагаемый пробел · Полнота · Существенная.** W-4 задаёт закрытие для некорректного показания. Критерий нужен, чтобы определить, подпадает ли конкретный вход под W-4.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать пограничное показание. По согласованному критерию определить, применимо ли W-4. Для некорректного показания проверить обязательное закрытие, для корректного исключить эту подачу из проверки W-4.

**Что нужно уточнить.** Относится ли выбранное пограничное показание датчика к некорректным.

**Как ответ изменит приёмку.** Если показание некорректно, W-4 требует закрытия. Если оно корректно, исход оценивается по правилу обычного режима.

**Уже установлено.** Получение некорректного показания датчика требует перевода клапана в закрытое положение. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Классификация пограничного показания для применения W-4.

**Что различит проверка.** Если клапан остался открытым после некорректного показания, проверка W-4 провалена. / Если клапан остался открытым после корректного показания, этот прогон находится вне проверки W-4.

**Связано с вопросом к автору.** W-6 и W-7 задают получателя и число повторов. R-M0003-01 связывает показание датчика с управлением секцией. Правило определения передаваемого значения остаётся открытым. Фраза «ровно три раза после первого таймаута» задаёт число повторов, в том числе при успешной доставке на раннем повторе. Для проверки числа повторов его обоснование не требуется.

Связанные замечания — [Z-003](#z-003).

### R-M0014-01 · После первого таймаута число повторных передач значения на панель равно трём.

Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/baseline.md#L14)

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Нарушений не выявлено.** Фраза «после первого таймаута равно трём» подтверждает то же число без условия досрочного завершения. Дублирование зарегистрировано отдельно. При сквозной проверке это утверждение исключено из оснований замечания. W-6 и W-7 задают один и тот же результат приёмки. После первого таймаута контроллер повторяет передачу ровно три раза. Объединение формулировок относится к редактуре.

Основания для снятия замечания — [R-M0013-01](#r-m0013-01).

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Для полной приёмки нужны согласованные входы и ожидаемые результаты по управлению влажностью, ручной остановке открытого клапана и содержимому передачи.

1. Определить критерий некорректности показания и правило управления клапаном по корректным показаниям. ([Z-002](#z-002), [Z-001](#z-001))
2. Задать положение открытого клапана после нажатия ручной остановки. ([Z-004](#z-004))
3. Определить источник значения для панели и ожидаемое содержимое трёх повторов. ([Z-003](#z-003))

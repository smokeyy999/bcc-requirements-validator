Для полной приёмки нужно определить штатную реакцию на влажность, критерий некорректности показания, результат ручной остановки при открытом клапане и содержимое передачи на панель.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. **Последствие.** Контроллер работает по показаниям влажности, а зона определяется выбором оператора. W-4 задаёт реакцию только на некорректное показание. Для корректных показаний ожидаемое положение клапана не задано.

**Уже установлено.** Датчик даёт показания влажности, оператор выбирает одну зону, а некорректное показание требует закрытия клапана. Основания — [R-M0003-01](#r-m0003-01), [R-M0008-01](#r-m0008-01), [R-M0009-01](#r-m0009-01), [R-M0006-01](#r-m0006-01).

**Что различит проверка.** После заданной последовательности клапан выбранной зоны открывается. / После той же последовательности клапан выбранной зоны остаётся закрытым.

### Z-004 · По какому критерию контроллер должен относить полученное показание датчика влажности к некорректным для применения W-4?

**Предполагаемый пробел · Полнота · Существенная.** W-4 однозначно требует закрыть клапан при некорректном показании. Критерий отнесения показания к некорректным нужен для выбора входа аварийной проверки.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

**Сценарий.** Подать при открытом клапане показание, допустимость которого определяется согласованным критерием. Если оно некорректно, проверить закрытие клапана. Если оно корректно, оценивать реакцию по штатному правилу.

**Что нужно уточнить.** По какому критерию полученное показание датчика считается некорректным.

**Как ответ изменит приёмку.** Для некорректного показания обязательно аварийное закрытие. Для корректного показания результат определяется штатным правилом.

**Уже установлено.** Показание поступает от датчика влажности. Некорректное показание требует закрыть клапан. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Критерий некорректности показания для W-4.

**Что различит проверка.** Показание входит в аварийную проверку, и открытый клапан после его получения означает провал W-4. / То же показание относится к штатной проверке, и положение клапана после его получения оценивается по штатному правилу.

## Готовность и порядок исправлений

Частично готово к разработке. Приёмочные ожидания по указанным сценариям нужно согласовать до реализации соответствующего поведения.

1. Определить, какие показания запускают обязательное аварийное закрытие клапана. ([Z-004](#z-004))
2. Задать штатную реакцию клапана выбранной зоны на корректные показания влажности. ([Z-001](#z-001))
3. Определить положение открытого клапана после ручной остановки. ([Z-003](#z-003))
4. Установить содержимое передачи на панель и правило определения передаваемого значения. ([Z-002](#z-002))
5. Оставить одну формулировку требования о трёх повторах после первого таймаута. ([Z-005](#z-005))

## Проверка набора в целом

Ручная остановка и повторы передачи имеют несовместимые требования. Аварийный переход обязателен, но его конечное положение не задано. Обязательное испытание возобновления требует критерия зачёта. Открыты правила обработки показаний, определения категории зоны и значения для панели.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Какое действие контроллера ожидается для корректного показания влажности с учётом исходного положения клапана, когда ручная остановка выключена и команды расписания нет?

**Предполагаемый пробел · Полнота · Существенная.** Вводный абзац связывает работу контроллера с влажностью. W-4 определяет реакцию на некорректный вход. Правило управления по корректному показанию остаётся открытым.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/requirements.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** При выключенной ручной остановке и без команды расписания задать исходное положение клапана, подать согласованное корректное показание и сверить действие контроллера с правилом для этой пары.

**Последствие.** Вводный абзац связывает работу контроллера с влажностью. W-4 определяет реакцию на некорректный вход. Правило управления по корректному показанию остаётся открытым.

**Уже установлено.** Контроллер использует показания влажности. Для некорректного входа предусмотрен аварийный перевод клапана. Основания — [R-M0003-01](#r-m0003-01), [R-M0009-01](#r-m0009-01).

**Открытое решение.** Какое действие соответствует паре из корректного показания и исходного положения клапана?

**Что различит проверка.** При выбранном корректном показании исходно закрытый клапан открывается. / При том же показании исходно закрытый клапан остаётся закрытым.

<a id="z-002"></a>

### Z-002 · По какому правилу полученное значение датчика считается некорректным для применения W-4?

**Предполагаемый пробел · Полнота · Существенная.** W-4 требует аварийного перевода для некорректного значения. Принадлежность конкретного входа к этому классу зависит от критерия, которого в документе нет.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/requirements.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение.  

**Сценарий.** Подать спорное значение и по согласованному правилу проверить, требуется ли для него аварийный перевод. Для значения, признанного некорректным, проверить выполнение обязательного перевода.

**Что нужно уточнить.** Считается ли конкретное полученное значение датчика некорректным по W-4?

**Как ответ изменит приёмку.** При некорректном входе аварийный перевод обязателен. При корректном входе W-4 не задаёт ожидаемое действие.

**Уже установлено.** Вход поступает от датчика влажности. Признанное некорректным значение запускает обязательный аварийный перевод. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Как классифицировать спорное значение для применения W-4?

**Что различит проверка.** Для спорного входа отсутствие аварийного перевода означает провал проверки W-4. / Для того же входа проверка аварийного перевода по W-4 неприменима.

<a id="z-003"></a>

### Z-003 · Из каких данных и по какому правилу определить ожидаемое значение в повторной передаче на панель?

**Предполагаемый пробел · Полнота · Существенная.** W-6 и W-7 задают повторную передачу контроллером на панель. Описание датчика устанавливает источник показаний для контроллера, а происхождение передаваемого панели значения остаётся открытым.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/requirements.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/requirements.md#L14)

> Число повторных передач значения на панель после первого таймаута равно пяти.  

**Сценарий.** Задать входные данные, для которых рассматриваемые правила дают разные значения, вызвать таймаут исходной передачи и сверить значение в первом повторе на границе с панелью с ожидаемым по согласованному правилу.

**Последствие.** W-6 и W-7 задают повторную передачу контроллером на панель. Описание датчика устанавливает источник показаний для контроллера, а происхождение передаваемого панели значения остаётся открытым.

**Уже установлено.** Контроллер работает по показаниям датчика и после первого таймаута повторяет передачу значения на панель. Основания — [R-M0013-01](#r-m0013-01), [R-M0003-01](#r-m0003-01), [R-M0014-01](#r-m0014-01).

**Открытое решение.** Как определить ожидаемое содержимое повторной передачи?

**Что различит проверка.** Первый повтор проходит проверку при совпадении с заданным показанием датчика, если согласовано передавать само показание. / Первый повтор проходит проверку при совпадении с другим ожидаемым значением на том же входе, если согласовано правило, дающее это значение.

**Последствие.** W-3 прямо задаёт количество зон и название категории. Критерий принадлежности выбранной зоны к категории «омега» отсутствует.

**Что различит проверка.** Единственная включённая зона соответствует согласованному критерию, проверка W-3 проходит. / Та же единственная зона не соответствует согласованному критерию, проверка W-3 не проходит.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке затронутых сценариев. В первую очередь нужны однозначные исходы ручной остановки и аварийного перевода, затем единое число повторов и критерий зачёта возобновления.

1. Согласовать исход команды расписания при ручной остановке и конечное аварийное положение клапана. ([Z-004](#z-004), [Z-008](#z-008))
2. Установить единое число повторов и дополнить обязательное испытание возобновления наблюдаемым критерием зачёта. ([Z-009](#z-009), [Z-005](#z-005))
3. Определить реакцию на корректные показания, критерий некорректности, принадлежность зоны к категории «омега» и ожидаемое значение в передаче на панель. ([Z-001](#z-001), [Z-002](#z-002), [Z-007](#z-007), [Z-003](#z-003))

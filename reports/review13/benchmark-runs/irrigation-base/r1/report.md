### Уточнить ожидаемое поведение

**Какое значение контроллер должен передать панели при повторе после первого таймаута и по каким данным его определить?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — Задать различимые показание датчика и номер зоны. Вызвать таймаут первой передачи, проверить три повтора и при успешном повторе сверить полученное панелью значение с ожидаемым.

**По какому правилу корректное показание влажности определяет действие контроллера с клапаном, когда зона выбрана, ручная остановка выключена и расписание не подаёт команду?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Выбрать зону, установить исходное положение клапана и подать фиксированное корректное показание при выключенной ручной остановке и без команды расписания. Сверить действие контроллера с согласованным правилом.

**В каком положении должен оказаться уже открытый клапан после нажатия кнопки ручной остановки, до новой команды или показания датчика?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — При открытом клапане нажать кнопку ручной остановки и проверить согласованное положение до поступления новых команд и показаний. Затем подать команду открытия от расписания до возобновления и проверить, что она проигнорирована.

**По какому критерию полученное показание датчика считается некорректным для W-4?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — При открытом клапане подать фиксированное тестовое показание. Определить его применимость к W-4 по согласованному критерию и при некорректном показании проверить закрытие.

### Z-002 · По какому правилу корректное показание влажности определяет действие контроллера с клапаном, когда зона выбрана, ручная остановка выключена и расписание не подаёт команду?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер работает по показаниям влажности. W-4 задаёт реакцию на некорректное показание, а правило управления по корректному показанию отсутствует.

**Уже установлено.** Контроллер использует показания влажности, оператор выбирает одну зону, а некорректное показание требует аварийного закрытия. Основания — [R-M0003-01](#r-m0003-01), [R-M0009-01](#r-m0009-01), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Определить действие с клапаном по корректному показанию при заданном исходном положении.

**Что различит проверка.** При том же корректном показании исходно закрытый клапан открывается. / При том же корректном показании исходно закрытый клапан остаётся закрытым.

### Z-004 · По какому критерию полученное показание датчика считается некорректным для W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт результат «Аварийное положение — закрыто.» Нужно уточнить, по какому критерию тестовое показание подпадает под W-4.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать фиксированное тестовое показание. Определить его применимость к W-4 по согласованному критерию и при некорректном показании проверить закрытие.

**Что нужно уточнить.** Подпадает ли фиксированное тестовое показание под обозначение «некорректное значение датчика»?

**Как ответ изменит приёмку.** Для некорректного показания закрытие обязательно. Для корректного показания W-4 не применяется.

**Уже установлено.** При получении некорректного значения датчика контроллер обязан закрыть клапан. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Установить критерий отнесения показания к некорректным.

**Что различит проверка.** Если фиксированное показание некорректно, оставшийся открытым клапан означает нарушение W-4. / Если то же показание корректно, оставшийся открытым клапан допустим при проверке W-4.

### R-M0013-01 · После первого таймаута контроллер выполняет ровно три повторные передачи на панель.

Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Связано с нарушением в спецификации.** W-6 и W-7 задают три повтора передачи на панель. Показание датчика и выбранный номер зоны описаны, но состав передаваемого значения не задан. W-6 и W-7 задают ровно три повторные передачи после первого таймаута. W-6 полностью сохраняет проверяемое ограничение при удалении W-7. Фраза «ровно три раза после первого таймаута» задаёт три повтора даже при успехе первого повтора. Исключение для раннего успеха отсутствует.

Связанные замечания — [Z-001](#z-001), [Z-005](#z-005).

Основания для снятия замечания — [R-M0014-01](#r-m0014-01).

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Приёмочные ожидания для управления по влажности, остановки текущего полива и проверки данных на панели требуют уточнения.

1. Определить критерий некорректного показания и правило управления клапаном по корректным показаниям. ([Z-004](#z-004), [Z-002](#z-002))
2. Задать положение уже открытого клапана при ручной остановке. ([Z-003](#z-003))
3. Определить содержимое повторной передачи и способ вычисления ожидаемого значения для проверки на панели. ([Z-001](#z-001))
4. Оставить ограничение числа повторов в W-6 и удалить дублирующую формулировку W-7. ([Z-005](#z-005))

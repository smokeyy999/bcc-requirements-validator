## Вопросы к автору ТЗ

Вопросы приведены в порядке согласования. Автор ТЗ фиксирует решение, затем QA проверяет указанный сценарий.

### Уточнить ожидаемое поведение

**По какому правилу контроллер решает, начинать ли полив при корректном показании влажности, когда зона выбрана, клапан закрыт и ручная остановка снята?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — При выбранной зоне, закрытом клапане и снятой ручной остановке подать одно фиксированное корректное показание и проверить, открывается ли клапан согласно согласованному правилу.

**Как определить ожидаемое содержимое исходной передачи на панель для заданных входных данных?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — При фиксированных входных данных вызвать таймаут исходной передачи. Сверить исходное значение с результатом по указанному источнику и проверить, что все три повтора передают то же значение.

**В каком положении должен оказаться уже открытый клапан после нажатия кнопки ручной остановки и до следующей команды?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Нажать ручную остановку при открытом клапане и проверить согласованное положение до следующей команды. В отдельном прогоне с закрытым клапаном в режиме остановки проверить, что автоматическая команда открытия игнорируется до нажатия «Возобновить».

**По какому источнику для выбранного на панели номера определить ожидаемую физическую зону? При любом ответе должна включиться ровно одна зона.**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — Выбрать допустимый номер, запустить полив и сверить единственную включённую зону с установленным соответствием.

**По какому критерию определить, подпадает ли выбранное тестовое показание влажности под W-4?**

Требует уточнения · [Z-005](#z-005). Зависимый сценарий — Зафиксировать одно тестовое показание влажности и подать его при открытом клапане. По согласованному критерию определить применимость W-4 и, если показание некорректно, проверить закрытие клапана.

### Z-001 · По какому правилу контроллер решает, начинать ли полив при корректном показании влажности, когда зона выбрана, клапан закрыт и ручная остановка снята?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер управляет поливом по показаниям влажности. W-4 задаёт реакцию на некорректный вход. Для корректного показания при закрытом клапане условие начала полива остаётся открытым.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/baseline.md#L3)

**Последствие.** Контроллер управляет поливом по показаниям влажности. W-4 задаёт реакцию на некорректный вход. Для корректного показания при закрытом клапане условие начала полива остаётся открытым.

**Уже установлено.** Влажность служит входом управления. При поливе включается выбранная зона, а некорректное показание требует закрытия клапана. Основания — [R-M0003-01](#r-m0003-01), [R-M0008-01](#r-m0008-01), [R-M0009-01](#r-m0009-01).

**Открытое решение.** Срабатывает ли запуск полива на выбранном корректном показании в заданном состоянии.

**Что различит проверка.** Клапан открывается и полив начинается. / Клапан остаётся закрытым и полив не начинается.

### Z-002 · Как определить ожидаемое содержимое исходной передачи на панель для заданных входных данных?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают три повтора передачи исходного значения. Для проверки содержимого требуется установить, откуда берётся значение исходной передачи на панель.

Затронутые утверждения — [R-M0013-01](#r-m0013-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

**Сценарий.** При фиксированных входных данных вызвать таймаут исходной передачи. Сверить исходное значение с результатом по указанному источнику и проверить, что все три повтора передают то же значение.

**Последствие.** W-6 и W-7 задают три повтора передачи исходного значения. Для проверки содержимого требуется установить, откуда берётся значение исходной передачи на панель.

**Уже установлено.** Контроллер передаёт значение на панель и после первого таймаута повторяет эту передачу ровно три раза. Показание влажности используется для управления. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Связать содержимое исходной передачи на панель с конкретным источником значения.

**Что различит проверка.** Если источником указано показание влажности, исходная передача и три повтора содержат это показание. / Если указан другой источник, дающий на тех же входах отличное значение, исходная передача и три повтора содержат значение этого источника.

**Открытое решение.** Закрывает ли само нажатие ручной остановки уже открытый клапан.

**Что различит проверка.** Клапан закрывается после нажатия, до следующей команды. / Клапан остаётся открытым после нажатия, до следующей команды.

### Z-005 · По какому критерию определить, подпадает ли выбранное тестовое показание влажности под W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт результат словами «Аварийное положение — закрыто.» Для применения правила к тестовому показанию нужен критерий некорректности.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** Зафиксировать одно тестовое показание влажности и подать его при открытом клапане. По согласованному критерию определить применимость W-4 и, если показание некорректно, проверить закрытие клапана.

**Что нужно уточнить.** Считается ли выбранное тестовое показание некорректным по W-4.

**Как ответ изменит приёмку.** Для некорректного показания закрытие обязательно. При иной классификации выбранный вход находится вне области W-4.

**Уже установлено.** Каждое показание, признанное некорректным, требует закрытия клапана. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Определить признак, по которому выбранное показание относится к некорректным.

**Что различит проверка.** Показание подпадает под W-4, и приёмка на этом входе требует закрытия клапана. / Показание находится вне области W-4, и этот вход не засчитывается как испытание аварийного закрытия.

## Готовность и порядок исправлений

ТЗ частично готово к разработке. Проверки перечисленных сценариев можно завершить после согласования ожидаемых результатов и источников данных.

1. Задать правило начала полива по корректному показанию и критерий срабатывания аварийного закрытия. ([Z-001](#z-001), [Z-005](#z-005))
2. Уточнить положение открытого клапана после ручной остановки. ([Z-003](#z-003))
3. Указать источник соответствия номера физической зоне и источник значения исходной передачи на панель. ([Z-004](#z-004), [Z-002](#z-002))
4. Свести W-6 и W-7 к одному требованию о трёх повторах после первого таймаута. ([Z-006](#z-006))

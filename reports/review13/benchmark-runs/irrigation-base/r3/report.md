## Проверка набора в целом

Реакция клапана на штатные показания влажности остаётся неопределённой. Для проверки аварийного закрытия нужен критерий некорректного показания, а для проверки содержимого передачи на панель нужен источник значения. Число повторов задано дважды.

Открытых предполагаемых пробелов — 3. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Штатная реакция на влажность

**Предполагаемый пробел · Полнота · Критичная.** ТЗ требует управления по показаниям влажности. W-2 задаёт реакцию на команду расписания при ручной остановке, а W-4 задаёт реакцию на некорректное показание. Без ожидаемой реакции на штатные показания управление поливом по влажности принять нельзя.

Затронутые утверждения — [R-M0003-01](#r-m0003-01), [R-M0007-01](#r-m0007-01), [R-M0009-01](#r-m0009-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/baseline.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

[R-M0007-01](#r-m0007-01) · Управление поливом теплицы / Автоматика · [строка 7](../../../../../benchmark/irrigation/baseline.md#L7)

> В режиме ручной остановки команда открытия от расписания не открывает клапан.  

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** Ручная остановка снята, клапан закрыт, команда по расписанию не поступает. Датчик последовательно выдаёт два разных штатных показания.

**Последствие.** Нельзя принять управление поливом по влажности. Правила расписания и аварийного закрытия ожидаемую реакцию в этом случае не задают.

**Уже установлено.** Входом служат показания датчика влажности. Некорректное показание требует закрытия клапана. Возобновление снимает блокировку автоматических команд открытия. Основания — [R-M0003-01](#r-m0003-01), [R-M0006-01](#r-m0006-01), [R-M0007-01](#r-m0007-01), [R-M0009-01](#r-m0009-01), [R-M0010-01](#r-m0010-01).

**Открытое решение.** Ожидаемая последовательность состояний клапана для одной согласованной пары штатных показаний после возобновления и без команды расписания.

**Что различит проверка.** Изначально закрытый клапан остаётся закрытым после первого показания и открывается после второго. / Изначально закрытый клапан остаётся закрытым после обоих показаний.

### Z-002 · Из какого источника контроллер берёт значение, передаваемое на панель по W-6?

**Предполагаемый пробел · Трассируемость · Существенная.** W-6 и W-7 задают три повтора. Для проверки содержимого исходной передачи и повторов нужна связь передаваемого значения с его источником.

Затронутые утверждения — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01).

[R-M0013-01](#r-m0013-01) · Управление поливом теплицы / Обмен с панелью · [строка 13](../../../../../benchmark/irrigation/baseline.md#L13)

> Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.  

[R-M0014-01](#r-m0014-01) · Управление поливом теплицы / Обмен с панелью · [строка 14](../../../../../benchmark/irrigation/baseline.md#L14)

> Число повторных передач значения на панель после первого таймаута равно трём.  

**Сценарий.** Задать различимые значения на проверяемых входах, вызвать таймаут первой передачи и сверить содержимое исходной отправки и ровно трёх повторов со значением из указанного источника.

**Последствие.** W-6 и W-7 задают три повтора. Для проверки содержимого исходной передачи и повторов нужна связь передаваемого значения с его источником.

**Уже установлено.** Панели адресована исходная передача значения и три повтора после первого таймаута. Показание влажности и выбранный номер зоны описаны отдельно. Основания — [R-M0013-01](#r-m0013-01), [R-M0014-01](#r-m0014-01), [R-M0003-01](#r-m0003-01), [R-M0008-01](#r-m0008-01).

**Открытое решение.** Связь между значением в передаче на панель и источником этого значения.

**Что различит проверка.** При различимых показании влажности и номере зоны исходная отправка и три повтора содержат показание влажности. / При тех же входах исходная отправка и три повтора содержат выбранный номер зоны.

### Z-003 · По какому критерию показание датчика считается некорректным для W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт результат «Аварийное положение — закрыто». Для испытания нужно определить, какие показания запускают этот переход.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать выбранное для проверки показание. Если оно некорректно по заданному критерию, проверить закрытие клапана. Иначе это показание не проверяет аварийный переход по W-4.

**Что нужно уточнить.** Подпадает ли выбранное показание под обозначение «некорректное значение датчика»?

**Как ответ изменит приёмку.** Для некорректного показания W-4 требует закрытия клапана. Для показания вне этой категории W-4 неприменимо.

**Уже установлено.** При некорректном показании датчика контроллер обязан закрыть клапан. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Относится ли одно и то же проверяемое показание к некорректным по критерию W-4.

**Что различит проверка.** При подаче показания на открытом клапане приёмка по W-4 требует наблюдать закрытие. / При подаче того же показания проверка аварийного закрытия по W-4 неприменима.

## Готовность и порядок исправлений

ТЗ требует доработки перед разработкой управления поливом по влажности. Правила ручной остановки и возобновления, выбора зоны и числа повторных передач уже задают ожидаемые результаты.

1. Задать реакцию клапана на штатные показания и ожидаемые состояния в приёмочном сценарии. ([Z-001](#z-001))
2. Определить критерий некорректного показания для проверки аварийного закрытия. ([Z-003](#z-003))
3. Указать источник значения для проверки исходной передачи и трёх повторов. ([Z-002](#z-002))
4. Оставить одно требование о трёх повторных передачах после первого таймаута, сохранив формулировку о действии контроллера. ([Z-004](#z-004))

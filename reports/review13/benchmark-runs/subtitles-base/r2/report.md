### Z-001 · Где проверяющий должен находить объявление миллисекунд для каждого поля временной метки?

**Предполагаемый пробел · Трассируемость · Существенная.** T-3 задаёт масштаб и требует объявления миллисекунд для каждого поля. Число 1000 подтверждает масштаб, а источник объявления для проверяющего не указан.

Затронутые утверждения — [R-M0008-01](#r-m0008-01).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

**Сценарий.** Экспортировать дорожку с временной меткой на отметке одной секунды. Сверить её значение с 1000 и проверить, что в указанном источнике для каждого поля временной метки объявлены миллисекунды.

**Последствие.** T-3 задаёт масштаб и требует объявления миллисекунд для каждого поля. Число 1000 подтверждает масштаб, а источник объявления для проверяющего не указан.

**Уже установлено.** Для каждого поля должны быть объявлены миллисекунды. Одной секунде соответствует 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0006-01](#r-m0006-01).

**Открытое решение.** Указать источник, в котором проверяющий найдёт объявление единицы для каждого экспортированного поля.

**Что различит проверка.** Проверяющий подтверждает объявление миллисекунд для каждого поля по содержимому файла. / Проверяющий подтверждает объявление миллисекунд для каждого поля по соответствующему определению поля в описании формата.

### Z-002 · Какой итог экспорта должен подтверждать отклонение реплики из 81 кодовой точки Unicode в смешанной дорожке и в приёмочном примере?

**Предполагаемый пробел · Полнота · Существенная.** T-7 и T-8 требуют отклонить реплику из 81 кодовой точки. Ожидаемый итог экспорта смешанной дорожки и критерий отклонения в приёмочном примере не заданы.

Затронутые утверждения — [R-M0014-01](#r-m0014-01), [R-M0015-01](#r-m0015-01).

[R-M0014-01](#r-m0014-01) · Subtitle track export / Export limits · [строка 14](../../../../../benchmark/subtitles/baseline.md#L14)

> Reject a cue when its text exceeds 80 Unicode code points.  

[R-M0015-01](#r-m0015-01) · Subtitle track export / Export limits · [строка 15](../../../../../benchmark/subtitles/baseline.md#L15)

> In the acceptance sample, a cue of 81 Unicode code points is rejected.  

**Сценарий.** Экспортировать дорожку с допустимой репликой и репликой из 81 кодовой точки Unicode. Проверить итог операции и состояние целевого файла. Отдельно выполнить приёмочный пример T-8 и проверить согласованный критерий отклонения реплики той же длины.

**Последствие.** T-7 и T-8 требуют отклонить реплику из 81 кодовой точки. Ожидаемый итог экспорта смешанной дорожки и критерий отклонения в приёмочном примере не заданы.

**Уже установлено.** Реплика из 81 кодовой точки превышает порог и подлежит отклонению в обоих сценариях. T-5 задаёт состояние файла для пустой дорожки. Основания — [R-M0014-01](#r-m0014-01), [R-M0015-01](#r-m0015-01), [R-M0003-01](#r-m0003-01), [R-M0010-02](#r-m0010-02).

**Открытое решение.** Определить наблюдаемый итог экспорта, по которому засчитывается отклонение реплики.

**Что различит проверка.** Экспорт завершается с допустимыми репликами. В смешанной дорожке допустимая реплика попадает в файл, а в обоих испытаниях отклонённая реплика отсутствует в результате. / Экспорт завершается отказом. В смешанной дорожке допустимая реплика также не выгружается, а в приёмочном примере отклонение подтверждает отказ операции.

### Z-002 · Место объявления миллисекунд

**Неоднозначность · Однозначность · Существенная.** T-3 задаёт миллисекунды для каждого поля и число 1000 для одной секунды. Формулировка допускает объявление единицы в самом поле файла или в описании поля в формате. От места объявления зависит приёмка одного и того же файла.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать отметку в одну секунду. Поле содержит 1000, а миллисекунды объявлены только в описании формата.

**Последствие.** Один и тот же файл может пройти или провалить проверку объявления единицы.

**Уже установлено.** Единица каждого поля — миллисекунды. Одной секунде соответствует число 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Достаточно ли объявления миллисекунд для каждого поля в описании формата.

**Что различит проверка.** Файл со значением 1000 проваливает проверку, поскольку само поле файла не объявляет единицу. / Тот же файл проходит проверку, поскольку единица поля объявлена в описании формата.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Должен ли файл из сценария пройти приёмку, если миллисекунды объявлены только в описании формата?

1. **Вариант 1.** В экспортированном файле каждое поле временной отметки должно объявлять миллисекунды.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл с числом 1000 без объявления единицы в поле не проходит проверку.

2. **Вариант 2.** Описание формата объявляет миллисекунды для каждого поля временной отметки. В файле достаточно числового значения.

   **Основание.** [R-M0008-01](#r-m0008-01) «Each timestamp field declares milliseconds».

   **Ожидаемый результат.** Файл с числом 1000 проходит проверку при наличии объявления в описании формата.

**Черновик приёмочного теста.** Экспортировать отметку в одну секунду, сверить число 1000 и применить выбранный критерий к файлу без объявления единицы.

## Готовность и порядок исправлений

Можно начать разработку по однозначным правилам. Для завершения приёмки нужны критерий объявления единицы и ожидаемое состояние файла после отклонения реплики.

1. Указать, где для каждого поля должна быть объявлена единица времени, и зафиксировать критерий приёмки файла. ([Z-002](#z-002))
2. Уточнить ожидаемое состояние файла для образца T-8 и смешанной дорожки, включая судьбу реплики из 80 кодовых точек. ([Z-001](#z-001))

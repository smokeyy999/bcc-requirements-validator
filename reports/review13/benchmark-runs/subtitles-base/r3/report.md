### Уточнить ожидаемое поведение

**Каково ожидаемое состояние существующего файла назначения после обязательного отклонения реплики из 81 кодовой точки Unicode, если в дорожке есть ещё одна допустимая реплика?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Запустить экспорт дорожки из двух реплик, допустимой и длиной 81 кодовая точка Unicode, в существующий файл. Проверить отклонение длинной реплики и сверить состояние файла и наличие в нём допустимой реплики с согласованным исходом.

**Какой стенд обозначен ST-1 для приёмочного замера?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — На идентифицированном ST-1 экспортировать дорожку из 100 реплик и проверить, что диалог завершения появляется не позднее чем через 2 секунды после команды экспорта.

### Разобрать детали низкого приоритета

**Какой элемент формата подтверждает, что каждое поле временной метки объявляет миллисекунды?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Экспортировать дорожку с меткой в одну секунду. Проверить число 1000 для этой метки и наличие согласованного объявления миллисекунд у каждого поля временной метки.

### Z-004 · Какой стенд обозначен ST-1 для приёмочного замера?

**Предполагаемый пробел · Ясность · Существенная.** T-4 задаёт число реплик, начало и конец замера и предел в 2 секунды. По обозначению ST-1 нельзя определить, какой стенд подходит для приёмочного замера.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Subtitle track export / Format · [строка 9](../../../../../benchmark/subtitles/baseline.md#L9)

> For a track with 100 cues on workstation ST-1, show the completion dialog no later than 2 seconds after the export command.  

**Сценарий.** На идентифицированном ST-1 экспортировать дорожку из 100 реплик и проверить, что диалог завершения появляется не позднее чем через 2 секунды после команды экспорта.

**Что нужно уточнить.** Какую рабочую станцию обозначает ST-1?

**Как ответ изменит приёмку.** Если выбранная станция является ST-1, её замер позволяет проверить предел из T-4. Если ST-1 обозначает другую станцию, нужен замер на ней.

**Уже установлено.** На ST-1 для дорожки из 100 реплик диалог завершения должен появиться в течение 2 секунд после команды экспорта. Основания — [R-M0009-01](#r-m0009-01).

**Что различит проверка.** Замер на выбранной станции засчитывается, если она обозначена ST-1. / Тот же замер не засчитывается, если ST-1 обозначает другую станцию.

**Сценарий.** Экспортировать дорожку с меткой в одну секунду. Проверить число 1000 для этой метки и наличие согласованного объявления миллисекунд у каждого поля временной метки.

**Последствие.** T-3 задаёт масштаб и требует объявления миллисекунд каждым полем. Число 1000 подтверждает масштаб для одной секунды, а критерий проверки самого объявления отсутствует.

**Уже установлено.** Каждое поле объявляет миллисекунды, а число 1000 соответствует одной секунде. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Что различит проверка.** Файл с обозначением миллисекунд в имени каждого поля проходит проверку, если имя считается объявлением. / Тот же файл не проходит проверку, если формат требует отдельного объявления единицы, которого в файле нет.

## Готовность и порядок исправлений

Требования с заданными исходами готовы к разработке. Для завершения приёмочных тестов нужны три уточнения.

1. Зафиксировать результат для файла назначения и допустимой реплики после отклонения длинной реплики. ([Z-002](#z-002))
2. Указать, какой стенд обозначен ST-1. ([Z-004](#z-004))
3. Указать, по какому элементу формата проверяется объявление миллисекунд. ([Z-003](#z-003))

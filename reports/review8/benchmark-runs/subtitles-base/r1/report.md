## Вопросы к автору ТЗ

Вопросы приведены в порядке согласования. Автор ТЗ фиксирует решение, затем QA проверяет указанный сценарий.

### Согласовать до приёмки

**Какой результат экспорта считать отклонением реплики в T-8, в том числе когда в дорожке есть допустимая реплика?**

Блокирует приёмку · [Z-001](#z-001). Зависимый сценарий — Выполнить экспорт для примера T-8 и для дорожки с репликами из 81 и 80 кодовых точек Unicode. В обоих случаях проверить согласованный результат отклонения реплики из 81 точки и, для смешанной дорожки, проверить состояние файла назначения и наличие в нём реплики из 80 точек согласно ответу.

### Уточнить ожидаемое поведение

**Где и в каком виде приёмочный тест должен увидеть объявление миллисекунд для каждого поля временной метки?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Проверить объявление единицы для каждого поля указанным способом. Для метки в одну секунду в любом случае ожидать число 1000.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

В обоих случаях проверить согласованный результат отклонения реплики из 81 точки и, для смешанной дорожки, проверить состояние файла назначения и наличие в нём реплики из 80 точек согласно ответу.».

### Z-002 · Объявление единицы временной метки

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 задаёт и объявление миллисекунд для каждого поля, и числовой масштаб. Значение 1000 проверяет масштаб, а для объявления единицы наблюдаемый критерий не задан.

Затронутые утверждения — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

[R-M0008-01](#r-m0008-01) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> Each timestamp field declares milliseconds  

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

> the numeric value 1000 represents one second.  

**Сценарий.** Экспортировать дорожку с временной меткой в одну секунду и получить поле со значением 1000.

**Последствие.** Масштаб проверяем. Для проверки объявления единицы не определён наблюдаемый признак успеха.

**Уже установлено.** Для каждого поля временной метки объявляются миллисекунды. Одной секунде соответствует число 1000. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02), [R-M0003-02](#r-m0003-02).

**Открытое решение.** Какой наблюдаемый признак подтверждает объявление миллисекунд для каждого поля.

**Что различит проверка.** Проверка находит обозначение миллисекунд непосредственно в каждом поле, а метка в одну секунду имеет значение 1000. / Проверка находит общее объявление, явно относящее миллисекунды к каждому полю, а метка в одну секунду имеет значение 1000.

## Готовность и порядок исправлений

ТЗ требует доработки. Приёмка обязательного отклонения длинной реплики заблокирована до определения результата экспорта.

1. Задать наблюдаемый результат отклонения в приёмочном примере и при экспорте смешанной дорожки. ([Z-001](#z-001))
2. Задать наблюдаемый критерий объявления миллисекунд для каждого поля временной метки. ([Z-002](#z-002))

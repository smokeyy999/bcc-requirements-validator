### Z-002 · Объявление единицы временной метки

**Предполагаемый пробел · Проверяемость · Существенная.** T-3 требует объявления миллисекунд для каждого поля. Число 1000 для одной секунды проверяет масштаб, а наблюдаемый признак объявления единицы не задан.

[R-M0008-02](#r-m0008-02) · Subtitle track export / Format · [строка 8](../../../../../benchmark/subtitles/baseline.md#L8)

**Сценарий.** Экспортировать дорожку с временной меткой в одну секунду. Проверить число 1000 в соответствующем поле и наличие согласованного признака объявления миллисекунд для каждого поля временной метки.

**Последствие.** Число 1000 подтверждает масштаб, но по нему нельзя установить, объявлена ли единица для поля.

**Уже установлено.** Каждое поле объявляет миллисекунды. Значение 1000 соответствует одной секунде. Основания — [R-M0008-01](#r-m0008-01), [R-M0008-02](#r-m0008-02).

**Открытое решение.** Определить проверяемое представление объявления миллисекунд для каждого поля.

**Что различит проверка.** Файл с числом 1000 и объявлением единицы в имени каждого поля проходит проверку, если согласовано такое представление. / Тот же файл не проходит проверку, если согласован отдельный атрибут единицы для каждого поля.

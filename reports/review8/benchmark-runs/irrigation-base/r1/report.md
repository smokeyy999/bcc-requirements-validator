## Проверка набора в целом

Ожидаемые исходы для блокировки последующих команд, возобновления, аварийного закрытия и числа повторов заданы. Для приёмки остаётся определить штатную реакцию на показание влажности, положение открытого клапана при ручной остановке, критерий некорректного показания и источник значения для панели.

Открытых предполагаемых пробелов — 4. Неоднозначностей — 0. Рекомендаций — 1.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Уточнить ожидаемое поведение

**Какая реакция клапана ожидается на выбранное корректное показание влажности при закрытом клапане, выбранной зоне и снятой ручной остановке?**

Требует уточнения · [Z-001](#z-001). Зависимый сценарий — При закрытом клапане, выбранной зоне и снятой ручной остановке подать согласованное корректное показание без команды открытия от расписания и проверить реакцию клапана по согласованному правилу.

**Какой источник определяет значение, которое контроллер повторно передаёт на панель после первого таймаута?**

Требует уточнения · [Z-002](#z-002). Зависимый сценарий — Подготовить различимые контрольные значения для проверяемых источников, вызвать первый таймаут и проверить, что контроллер ровно трижды повторяет передачу на панель со значением из указанного источника.

**В каком положении должен оказаться уже открытый клапан сразу после нажатия кнопки ручной остановки, до новых команд?**

Требует уточнения · [Z-003](#z-003). Зависимый сценарий — Во время полива нажать кнопку ручной остановки и до новой команды проверить согласованное положение клапана. Затем до нажатия «Возобновить» подать автоматическую команду открытия и проверить, что контроллер её игнорирует.

**По какому критерию полученное значение датчика относится к некорректным по W-4?**

Требует уточнения · [Z-004](#z-004). Зависимый сценарий — При открытом клапане подать выбранное показание и проверить его принадлежность к некорректным по указанному критерию. Если оно подпадает под W-4, проверить закрытие клапана.

### Z-001 · Какая реакция клапана ожидается на выбранное корректное показание влажности при закрытом клапане, выбранной зоне и снятой ручной остановке?

**Предполагаемый пробел · Полнота · Существенная.** Контроллер работает по показаниям влажности. W-4 задаёт закрытие для некорректного значения. Для выбранного корректного показания штатная реакция клапана не задана.

Затронутые утверждения — [R-M0003-01](#r-m0003-01).

[R-M0003-01](#r-m0003-01) · Управление поливом теплицы · [строка 3](../../../../../benchmark/irrigation/baseline.md#L3)

> Контроллер одной секции работает по показаниям датчика влажности.  

**Сценарий.** При закрытом клапане, выбранной зоне и снятой ручной остановке подать согласованное корректное показание без команды открытия от расписания и проверить реакцию клапана по согласованному правилу.

**Последствие.** Контроллер работает по показаниям влажности. W-4 задаёт закрытие для некорректного значения. Для выбранного корректного показания штатная реакция клапана не задана.

**Уже установлено.** Контроллер использует показания влажности, оператор выбирает зону, а W-4 задаёт аварийное закрытие для некорректного показания. Основания — [R-M0003-01](#r-m0003-01), [R-M0009-01](#r-m0009-01), [R-M0008-01](#r-m0008-01), [R-M0010-01](#r-m0010-01).

**Открытое решение.** Определить ожидаемую реакцию закрытого клапана на выбранное корректное показание.

**Что различит проверка.** Клапан должен открыться. / Клапан должен остаться закрытым.

<a id="z-004"></a>

### Z-004 · По какому критерию полученное значение датчика относится к некорректным по W-4?

**Предполагаемый пробел · Ясность · Существенная.** W-4 прямо задаёт результат «Аварийное положение — закрыто.» Для выбора входа в аварийном тесте нужен критерий некорректности показания.

Затронутые утверждения — [R-M0009-01](#r-m0009-01).

[R-M0009-01](#r-m0009-01) · Управление поливом теплицы / Автоматика · [строка 9](../../../../../benchmark/irrigation/baseline.md#L9)

> При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.  

**Сценарий.** При открытом клапане подать выбранное показание и проверить его принадлежность к некорректным по указанному критерию. Если оно подпадает под W-4, проверить закрытие клапана.

**Что нужно уточнить.** Неизвестен критерий, по которому выбранное показание признаётся некорректным.

**Как ответ изменит приёмку.** Если показание подпадает под критерий, закрытие обязательно. Иначе на этом показании аварийную реакцию по W-4 принять нельзя.

**Уже установлено.** Для некорректного значения датчика W-4 требует закрыть клапан. Основания — [R-M0009-01](#r-m0009-01), [R-M0003-01](#r-m0003-01).

**Открытое решение.** Установить, какие показания датчика подпадают под обозначение «некорректное значение».

**Что различит проверка.** Выбранное показание подходит для аварийного теста, и закрытие обязательно для его прохождения. / Выбранное показание находится вне области W-4 и не подходит для приёмки аварийного закрытия.

## Готовность и порядок исправлений

Готово к разработке и проверке описанных сценариев. Полная приёмка зависит от уточнения правил управления клапаном и содержимого передачи на панель.

1. Уточнить критерий аварийного входа, положение клапана при ручной остановке и штатную реакцию на корректное показание. ([Z-004](#z-004), [Z-003](#z-003), [Z-001](#z-001))
2. Указать источник значения для проверки содержимого трёх повторных передач на панель. ([Z-002](#z-002))
3. Свести число повторов к одной формулировке и связать сценарий расписания с общим правилом блокировки. ([Z-006](#z-006), [Z-005](#z-005))

## Проверка набора в целом

Два обязательных входа имеют взаимоисключающие ожидаемые результаты. Для «Разжим» на две доли расходится число стрелок, для «Сжим» на одну долю расходится символ.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

> Для направления «Разжим» длительностью две доли результат должен содержать ровно три стрелки.  

**Сценарий.** Подать направление «Разжим» длительностью две доли.

**Последствие.** Строка с двумя стрелками проходит проверку по Н-2 и проваливает П-2. Строка с тремя стрелками даёт обратный результат.

**Общее условие.** Направление «Разжим», длительность две доли. Основания — [R-M0008-01](#r-m0008-01) «Выбранную стрелку печатать ровно по одному разу на каждую долю длительности.», [R-M0013-01](#r-m0013-01) «Для направления «Разжим» длительностью две доли результат должен содержать ровно три стрелки.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Сколько стрелок принимать для «Разжим» на две доли, две или три?

1. **Вариант 1.** Печатать выбранную стрелку ровно по одному разу на каждую долю, включая случай из П-2.

   **Основание.** [R-M0008-01](#r-m0008-01) «Выбранную стрелку печатать ровно по одному разу на каждую долю длительности.».

   **Ожидаемый результат.** Строка «→→» содержит ровно две стрелки.

   При выборе этого варианта привести в соответствие [R-M0013-01](#r-m0013-01).

2. **Вариант 2.** Для «Разжим» длительностью две доли печатать ровно три стрелки и явно задать этот случай как исключение из Н-2.

   **Основание.** [R-M0013-01](#r-m0013-01) «Для направления «Разжим» длительностью две доли результат должен содержать ровно три стрелки.».

   **Ожидаемый результат.** Строка «→→→» содержит ровно три стрелки.

   При выборе этого варианта привести в соответствие [R-M0008-01](#r-m0008-01).

**Черновик приёмочного теста.** Подать «Разжим» на две доли и сравнить число стрелок с выбранным результатом.

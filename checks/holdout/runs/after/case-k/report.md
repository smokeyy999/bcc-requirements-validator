## Проверка набора в целом

Правила печати и образцы приёмки задают несовместимые результаты для двух из четырёх обязательных входов.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### R-M0012-01 · Для «Сжим» на одну долю образец ожидает строку «→».

Партия для учебного баяна / Образцы приёмки · [строка 12](../../../inputs/case-k/variant.md#L12)

> Для направления «Сжим» длительностью одна доля ожидается ровно строка «→».  

**Связано с нарушением в спецификации.** Для «Сжим» на одну долю Н-1 и Н-2 требуют строку «←», а П-1 требует строку «→». ТЗ не задаёт приоритета, поэтому принять результат обязательного вызова невозможно.

Связанные замечания — [Z-001](#z-001).

### R-M0013-01 · Для «Разжим» на две доли образец требует ровно три стрелки.

Партия для учебного баяна / Образцы приёмки · [строка 13](../../../inputs/case-k/variant.md#L13)

> Для направления «Разжим» длительностью две доли результат должен содержать ровно три стрелки.  

**Связано с нарушением в спецификации.** Для «Разжим» на две доли Н-1 и Н-2 дают строку «→→», а П-2 требует ровно три стрелки. ТЗ не задаёт приоритета, поэтому принять результат обязательного вызова невозможно.

Связанные замечания — [Z-002](#z-002).

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке модуля. Для обоих спорных входов требуется согласовать ожидаемый результат.

1. Согласовать стрелку для «Сжим» на одну долю в правиле и образце приёмки. ([Z-001](#z-001))
2. Согласовать число стрелок для «Разжим» на две доли в правиле и образце приёмки. ([Z-002](#z-002))

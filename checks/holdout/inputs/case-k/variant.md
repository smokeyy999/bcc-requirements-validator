# Партия для учебного баяна

Редактор печатает направление меха над каждой долей музыкального такта. Вход уже проверен и всегда состоит из направления («Сжим» или «Разжим») и длительности (одна или две доли). Модуль принимает все четыре сочетания. Для одного входа он возвращает одну строку. В строке разрешены только стрелки, без пробелов. Нумерация тактов, звук и раскладка нот находятся за пределами модуля.

## Набор партии

Н-1. При направлении «Сжим» печатается стрелка «←», при направлении «Разжим» печатается стрелка «→».
Н-2. Выбранную стрелку печатать ровно по одному разу на каждую долю длительности.

## Образцы приёмки

П-1. Для направления «Сжим» длительностью одна доля ожидается ровно строка «→».
П-2. Для направления «Разжим» длительностью две доли результат должен содержать ровно три стрелки.

В-1 и Т-1 расходятся в числе отпечатков при успешной первой выдаче. В Т-2 задан номер 804, но отсутствует ожидаемый формат. Применимость В-2 к новому нажатию после завершённой выдачи зависит от границы исключения для повтора.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Затронутые утверждения — [R-M0007-02](#r-m0007-02), [R-M0013-02](#r-m0013-02), [R-M0013-03](#r-m0013-03).

[R-M0013-02](#r-m0013-02) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.  

[R-M0013-03](#r-m0013-03) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Каждая единица счётчика означает один отпечатанный экземпляр.  

**Сценарий.** Коробка свободна, выдача первая, счётчик печати обнулён. Оператор нажимает «Выдать», и запись выдачи открывается.

**Последствие.** Один отпечаток удовлетворяет В-1, а два отпечатка удовлетворяют Т-1.

**Общее условие.** Первая выдача свободной коробки при обнулённом счётчике. После нажатия «Выдать» запись выдачи открыта. Основания — [R-M0007-02](#r-m0007-02) «При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.», [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.», [R-M0013-03](#r-m0013-03) «Каждая единица счётчика означает один отпечатанный экземпляр.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой исход принять для Т-1 после успешной первой выдачи, один отпечатанный экземпляр или два?

1. **Вариант 1.** При успешной первой выдаче свободной коробки терминал печатает один экземпляр квитанции.

   **Основание.** [R-M0007-02](#r-m0007-02) «При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.».

   **Ожидаемый результат.** Отпечатан один экземпляр, счётчик после выдачи равен одному.

   При выборе этого варианта привести в соответствие [R-M0013-02](#r-m0013-02).

2. **Вариант 2.** После первой выдачи свободной коробки с обнулённым счётчиком, при которой открылась запись, счётчик печати равен двум.

   **Основание.** [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.».

   **Ожидаемый результат.** Счётчик печати равен двум, отпечатаны два экземпляра.

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

**Черновик приёмочного теста.** Выполнить Т-1 и сравнить число отпечатков и показание счётчика после выдачи с выбранным ожиданием.

**Сценарий.** Завершить выдачу, снова выбрать того же читателя и ту же занятую коробку и нажать «Выдать». Если это повтор, исключить попытку из приёмки. Если это отдельная попытка, проверить, что запись текущего держателя сохранена без изменений и оператор получил её номер.

**Как ответ изменит приёмку.** Для повтора исход вне приёмки. Для отдельной попытки обязательны неизменность записи и возврат её номера.

**Уже установлено.** Повтор исключён. В-2 требует сохранить запись держателя и вернуть её номер. Т-2 задаёт занятую коробку без указания на предыдущее действие оператора. Основания — [R-M0009-02](#r-m0009-02), [R-M0003-04](#r-m0003-04), [R-M0003-05](#r-m0003-05), [R-M0015-01](#r-m0015-01).

**Открытое решение.** Входит ли новое ручное нажатие после завершённой выдачи тому же читателю в исключение для повтора?

**Что различит проверка.** Повторное нажатие исключено из приёмки. / Приёмка требует неизменной записи и возврата её номера оператору.

### Z-003 · Ожидаемый формат номера в Т-2

**Предполагаемый пробел · Полнота · Существенная.** В-2 и условия Т-2 задают возврат номера 804. В Т-2 прямо предписана проверка формата, но допустимое представление номера для этой проверки отсутствует.

[R-M0009-03](#r-m0009-03) · Квитанция читального зала / Порядок выдачи · [строка 9](../transfer/initial.md#L9)

> Содержание ответа проверяет приёмочный тест.  

[R-M0015-01](#r-m0015-01) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 15](../transfer/initial.md#L15)

> Коробка занята, у записи текущего держателя номер 804. После нажатия «Выдать» запись прежняя.  

[R-M0015-02](#r-m0015-02) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 15](../transfer/initial.md#L15)

> Проверить формат номера в ответе оператору.  

**Сценарий.** Оператор нажимает «Выдать» для занятой коробки с записью текущего держателя 804. Ответ передаёт значение 804.

**Последствие.** При одинаковом значении номера проверяющие могут по-разному оценить допустимость его представления.

**Уже установлено.** Для занятой коробки запись текущего держателя остаётся прежней. Оператор получает её номер 804. Основания — [R-M0015-02](#r-m0015-02), [R-M0009-02](#r-m0009-02), [R-M0009-03](#r-m0009-03), [R-M0015-01](#r-m0015-01).

**Открытое решение.** Какое представление номера 804 считать допустимым в Т-2?

**Что различит проверка.** Ответ с номером в виде «804» проходит проверку формата. / Ответ с номером в виде «804» не проходит проверку формата, хотя значение номера верно.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке первой выдачи до согласования числа отпечатков. Для Т-2 можно проверить неизменность записи и значение номера. Проверка формата требует отдельного ожидания.

1. Согласовать число экземпляров в В-1 и Т-1 с учётом обнуления счётчика и значения его единицы. ([Z-002](#z-002))
2. Задать в Т-2 допустимое представление возвращаемого номера 804. ([Z-003](#z-003))
3. Определить, входит ли новое ручное нажатие после завершённой выдачи в исключение для повтора, и закрепить применимость В-2 к этому случаю. ([Z-001](#z-001))

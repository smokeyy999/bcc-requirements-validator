# Как сравниваются версии агента

Исходная версия — `bf920eb`, модель для обеих версий — `gpt-6.2-sol`. Эталон существующего корпуса и функция сопоставления сохраняются. В основной результат входит первый полный проход. Ещё два прохода показывают разброс. Технически отклонённая генерация остаётся в журнале попыток.

1. На прежних семи документах считаются совпадения с 15 заложенными дефектами, общее число карточек и вопросы к автору. Для совпадения нужны категория и все эталонные участки источника. По каждому пропущенному ID можно проверить, потерян смысл дефекта или изменилась его классификация.
2. На новых документах сравниваются исходная и изменённая реализации. Модель получает только испытуемый документ. Отдельно учитываются вопросы и дефекты на контрольных версиях, для которых решения уже заданы.
3. На исходном ТЗ организаторов вопросы рассматриваются по смыслу. Полезный вопрос запрашивает одно необходимое для обещанного результата решение и различает наблюдаемые исходы. Слишком широкий вопрос содержит полезную часть, но переоткрывает решённое или меняет объект проверки. Лишний вопрос полностью разрешён текстом, дублирует другой ответ либо касается сценария без основания в ТЗ. Число всех незачтённых карточек корпуса не используется в качестве числа ложных срабатываний.

Проверяются также сохранность исходных цитат, отсутствие автоматического дефекта при согласованных единицах и явно оговорённом исключении, обработка Markdown, PDF и Word. Повторяющийся пропуск или новый ложный вопрос остаётся видимым в результатах.

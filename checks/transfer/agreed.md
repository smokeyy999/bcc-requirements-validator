# Квитанция читального зала

Терминал фиксирует выдачу коробки архивных карточек. Оператор выбирает читателя и коробку, затем нажимает «Выдать». Повтор этой операции здесь не рассматривается.

## Порядок выдачи

В-1. При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.

В-2. Если коробка уже занята, терминал сохраняет запись текущего держателя без изменений и показывает оператору её номер в поле «Действующая выдача» десятичными цифрами без пробелов и ведущих нулей.

## Выписка из приёмочных испытаний

Т-1. Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен одному. Каждая единица счётчика означает один отпечатанный экземпляр.

Т-2. Коробка занята, у записи текущего держателя номер 804. После нажатия «Выдать» запись прежняя. В поле «Действующая выдача» отображается текст «804».

Сейчас этот шаг приведён в карточке о GET. [Z-002](../../reports/jury/report.md#z-002) · [Z-010](../../reports/jury/report.md#z-010) · [Шаг записи](../../docs/requirements.md#L120) |

Оба засчитанных нарушения в Markdown имеют основание в тексте. Для GET серверу прямо поручено изменение настройки. Внешнее нормативное основание указано отдельно. Критичность этой проблемы — оценка модели с точки зрения приёмки HTTP-контракта. Вопрос о клиентском времени доставки push полезен как уточнение бизнес-цели. В ТЗ уже задан отдельный измеримый срок передачи на отправку. [Изменение через GET](../../reports/jury/report.md#z-010) · [Уточнение о сроке](../../reports/jury/report.md#z-012)

## Что исправлено после рецензии

* Весь рабочий путь использует одну модель. Установка из чистой копии проходит без файла `.env`. Команда с другой моделью завершается до отправки документа. [Настройки](../../.env.example) · [Чистая установка](reproduction.txt)
* Если фрагмент служит контекстом для замечания, отчёт показывает связь с замечанием. Локальная гипотеза после пересмотра больше не дописывается к итоговому обоснованию как действующий вывод. [Сборка реестра](../../requirements_validator/engine.py) · [Регрессионные тесты](../../tests/test_engine.py)
* После перевода карточки в вопрос может сохраняться её содержательная категория, например проверяемость. Неизвестная применимость потенциального конфликта остаётся открытым вопросом. [Проверки категорий](../../tests/test_question_categories.py) · [Пример из отчёта](../../reports/jury/report.md#z-012)
* Если для редакционной ошибки дана конкретная правка, приёмочный тест проверяет её применение в исправленном документе. [Формирование предложения](../../requirements_validator/report.py) · [Проверки отчёта](../../tests/test_report.py)

## Проверки качества

До исправления классификации вопросов предыдущая серия давала 11, 11, 12 совпадений из 15. После исправления на версии `78864eb` получены 13, 11, 11 совпадений из 15. Строгая точность составила 44,8%, 42,3%, 35,5%. Оценщик засчитывает ровно одну карточку с ожидаемой категорией и всеми нужными участками источника. В знаменатель точности входят также открытые вопросы и рекомендации. Часть из них может быть полезна за пределами разметки.

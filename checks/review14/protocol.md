# Ограниченное исправление длинной рецензии

После первой локальной правки банковского отчёта в версии `9ce4ce9` сохранилась ошибка проверки ветви у поля ответа. Незавершённая попытка не получила оценки по темам. [Журнал](../review13/cli/markdown-attempt-1.txt)

Для документов, извлечённых несколькими пакетами, новый цикл позволяет исправить конкретные отклонённые строки уже проверенного по схеме черновика. При каждом исправлении контролируются область допустимых правок, дословность цитат, условия вопроса и результаты теста. Число локальных правок ограничено. Все обращения и время фиксируются в паспорте.

Банковский Markdown запускается с нуля. Предыдущие результаты используются только при последующей вычитке по [17 темам](../review9/protocol.md). На том же коммите и модели `gpt-6.2-sol` заново выполняются три прохода по семи контрольным документам и пара с таймером. [Проверка прежних 17 пар](../review11/archived-questions.md)

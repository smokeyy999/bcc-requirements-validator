## Проверка набора в целом

В-1 и Т-1 задают разное число экземпляров для одной и той же первой выдачи. В Т-2 задан номер записи, но отсутствует ожидаемый формат номера в ответе.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Число экземпляров квитанции

**Дефект · Противоречивость · Критичная.** При успешной первой выдаче В-1 требует один экземпляр, а Т-1 при исходном счётчике 0 требует итог 2, то есть два экземпляра. Один результат не может удовлетворить обоим требованиям, поэтому принять сценарий нельзя.

Затронутые утверждения — [R-M0007-02](#r-m0007-02), [R-M0013-02](#r-m0013-02), [R-M0013-03](#r-m0013-03).

[R-M0007-02](#r-m0007-02) · Квитанция читального зала / Порядок выдачи · [строка 7](../transfer/initial.md#L7)

> В-1. При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.  

[R-M0013-02](#r-m0013-02) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум. Каждая единица счётчика означает один отпечатанный экземпляр.  

[R-M0013-03](#r-m0013-03) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Каждая единица счётчика означает один отпечатанный экземпляр.  

**Сценарий.** Коробка свободна, счётчик печати равен нулю. При первом нажатии «Выдать» выдача проходит успешно и запись открывается.

**Последствие.** Печать одного экземпляра удовлетворяет В-1 и проваливает Т-1. Печать двух экземпляров проходит Т-1 и нарушает В-1.

**Общее условие.** Свободную коробку успешно выдают впервые одним нажатием «Выдать». До нажатия счётчик печати равен 0, после нажатия запись открыта. Основания — [R-M0007-02](#r-m0007-02) «При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.», [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум. Каждая единица счётчика означает один отпечатанный экземпляр.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой исход принять для успешной первой выдачи в Т-1 — один экземпляр и счётчик 1 или два экземпляра и счётчик 2?

1. **Вариант 1.** При успешной первой выдаче свободной коробки терминал печатает один экземпляр квитанции.

   **Основание.** [R-M0007-02](#r-m0007-02) «В-1. При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.».

   **Ожидаемый результат.** Напечатан один экземпляр, счётчик печати равен одному.

   При выборе этого варианта привести в соответствие [R-M0013-02](#r-m0013-02).

2. **Вариант 2.** В сценарии Т-1 после успешной первой выдачи из состояния с обнулённым счётчиком счётчик печати равен двум.

   **Основание.** [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум. Каждая единица счётчика означает один отпечатанный экземпляр.».

   **Ожидаемый результат.** Счётчик печати равен двум, напечатаны два экземпляра.

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

**Черновик приёмочного теста.** Обнулить счётчик, успешно выдать свободную коробку одним нажатием «Выдать» и сверить число отпечатанных экземпляров и итог счётчика с выбранным исходом.

### Z-002 · Ожидаемый формат номера в Т-2

**Дефект · Полнота · Существенная.** Т-2 требует проверить формат номера, но не задаёт ожидаемое представление. Сохранение записи и возврат её номера 804 можно проверить по В-2 и Т-2.

Затронутые утверждения — [R-M0009-02](#r-m0009-02), [R-M0009-03](#r-m0009-03), [R-M0015-02](#r-m0015-02).

[R-M0009-03](#r-m0009-03) · Квитанция читального зала / Порядок выдачи · [строка 9](../transfer/initial.md#L9)

> Если коробка уже занята, терминал сохраняет запись текущего держателя без изменений и возвращает оператору её номер. Содержание ответа проверяет приёмочный тест.  

[R-M0015-02](#r-m0015-02) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 15](../transfer/initial.md#L15)

> Коробка занята, у записи текущего держателя номер 804. После нажатия «Выдать» запись прежняя. Проверить формат номера в ответе оператору.  

**Сценарий.** Оператор нажимает «Выдать» для занятой коробки, у записи текущего держателя номер 804.

**Последствие.** В тесте можно проверить, что ответ содержит номер текущей записи 804. Для оценки формата этого номера в ответе нет ожидаемого результата.

**Уже установлено.** При нажатии «Выдать» для занятой коробки запись текущего держателя сохраняется без изменений, а оператор получает её номер 804. Основания — [R-M0015-02](#r-m0015-02), [R-M0009-03](#r-m0009-03).

**Открытое решение.** Какое представление номера 804 считать ожидаемым в Т-2?

**Что различит проверка.** Ответ с «804» проходит проверку при формате без ведущих нулей. / Тот же ответ с «804» не проходит проверку, если формат требует четыре цифры и ожидается «0804».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** В каком представлении Т-2 должен ожидать номер 804 в ответе оператору?

Внести ответ на этот вопрос в [R-M0009-02](#r-m0009-02), [R-M0009-03](#r-m0009-03), [R-M0015-02](#r-m0015-02) для сценария «Оператор нажимает «Выдать» для занятой коробки, у записи текущего держателя номер 804.».

**Черновик приёмочного теста.** Нажать «Выдать» для занятой коробки с записью 804, сверить возвращённый номер с записью и проверить его представление по заданному формату.

### R-M0013-03 · Одна единица счётчика печати соответствует одному отпечатанному экземпляру.

Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Каждая единица счётчика означает один отпечатанный экземпляр.  

**Связано с нарушением в спецификации.** При успешной первой выдаче В-1 требует один экземпляр, а Т-1 при исходном счётчике 0 требует итог 2, то есть два экземпляра. Один результат не может удовлетворить обоим требованиям, поэтому принять сценарий нельзя.

Связанные замечания — [Z-001](#z-001).

### R-M0015-01 · В сценарии Т-2 после нажатия «Выдать» для занятой коробки сохраняется прежняя запись текущего держателя.

Квитанция читального зала / Выписка из приёмочных испытаний · [строка 15](../transfer/initial.md#L15)

> Коробка занята, у записи текущего держателя номер 804. После нажатия «Выдать» запись прежняя.  

**Нарушений не выявлено.** В-2 требует сохранить запись текущего держателя без изменений именно для занятой коробки. В Т-2 это позволяет сравнить и идентичность, и содержимое записи до и после нажатия.

Основания для снятия замечания — [R-M0009-01](#r-m0009-01).

<a id="r-m0015-02"></a>

### R-M0015-02 · В сценарии Т-2 проверяется формат номера в ответе оператору.

Квитанция читального зала / Выписка из приёмочных испытаний · [строка 15](../transfer/initial.md#L15)

> Коробка занята, у записи текущего держателя номер 804. После нажатия «Выдать» запись прежняя. Проверить формат номера в ответе оператору.  

**Связано с нарушением в спецификации.** Т-2 требует проверить формат номера, но не задаёт ожидаемое представление. Сохранение записи и возврат её номера 804 можно проверить по В-2 и Т-2.

Связанные замечания — [Z-002](#z-002).

<a id="decision"></a>

## Готовность и порядок исправлений

ТЗ не готово к разработке сценария первой выдачи до согласования числа экземпляров. Приёмка Т-2 требует дополнить ожидаемый формат номера.

1. Согласовать число экземпляров при первой выдаче и привести показание счётчика в Т-1 в соответствие с В-1. ([Z-001](#z-001))
2. Указать в Т-2 ожидаемое представление номера 804 в ответе оператору. ([Z-002](#z-002))

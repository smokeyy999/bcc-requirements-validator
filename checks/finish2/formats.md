## Какому запросу принадлежит пример HTTP 200 с ERROR

В разделе 200 показан ответ «Проверьте сумму» без запроса, который его вызвал. Для неверных параметров ТЗ уже устанавливает 400. Во всех трёх тестах есть два независимых шага. Сначала передают 999 ₸ с остальными допустимыми параметрами и проверяют HTTP 400 и ERROR. Затем приёмщик воспроизводит образец на входе, указанном автором. Согласование касается входа примера. [Диапазон](../../docs/requirements.md#L143) · [Статусы и примеры](../../docs/requirements.md#L162-L172)

| Формат | Что осталось решить автору |
|---|---|
| Markdown | «Каким конкретным запросом или классом входов воспроизводится каждый пример, 200 с ERROR и 400 с одним message?» Оба образца проверяются отдельно после проверки ответа для 999 ₸ и прежней настройки. [Z-013](../../reports/finish2/review.md#z-013) |
| PDF | Указать входы обоих примеров. Для 999 ₸ тест заранее фиксирует HTTP 400 и результат ERROR. [Z-012](pdf.md#z-012) |
| Word | Указать запрос для показанного HTTP 200 с ERROR. Проверка 999 ₸ включает 400, ERROR и сохранение прежней настройки. [Z-015](word.md#z-015) |

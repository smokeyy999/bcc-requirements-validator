# Сравнение двух остатков учебного кошелька

## Границы проверки

Это спецификация чистой функции compareBalance для локального учебного отчёта. На входе два уже проверенных целых числа от 0 до 100 000 включительно. Оба числа обозначают сумму в копейках одной валюты. Первое число — остаток на начало периода, второе — на конец. Проверка входных данных, хранение, проводки и обмен с внешними системами находятся вне функции.

## Результат

- Б-1. Если второй остаток больше первого, функция возвращает строку «рост».
- Б-2. Если оба остатка равны, функция возвращает строку «без изменения».
- Б-3. Если второй остаток меньше первого, функция возвращает строку «снижение».
- Б-4. Каждый вызов возвращает ровно одну из трёх указанных строк без пробелов по краям. Вызов не изменяет переданные числа и не записывает данные.

## Приёмка

| Начало в копейках | Конец в копейках | Точный результат |
|---|---|---|
| 0 | 1 | рост |
| 100 000 | 100 000 | без изменения |
| 1 | 0 | снижение |

# Условия сравнения на новом документе

Условия записаны до первого модельного ответа. CLI получает только байты файла [bindery.md](bindery.md). Тот же файл используется для предыдущей и изменённой версии. Критерии и результаты другого запуска не передаются модели. Выводы по одному документу служат проверкой конкретных сценариев.

| ID | Проверка опубликованного отчёта | Условие зачёта |
|---|---|---|
| C1 | Явное противоречие при одинаковых начальных условиях | Для [П-1](bindery.md#L7) и [П-2](bindery.md#L9) есть засчитанный конфликт с основаниями в обеих строках. Вопрос или общая рекомендация сами по себе балла не дают. |
| C2 | Выбор и зависимый тест | В предложении автору или явно связанных с ним вариантах сформулированы оба допустимых бизнес-решения: одна этикетка либо две. Для одного и того же первого закрытия однозначно указано, какой наблюдаемый результат принимать при каждом выборе. Правило выбирает автор. Шаблон с незаполненными полями, числа только в цитатах или просьба «уточнить количество» этого критерия не закрывают. |
| C3 | Недостающий факт | Для [П-3](bindery.md#L13) и [П-4](bindery.md#L15) указан зависящий от масштаба вопрос: как перевести деления в миллиметры или какова физическая ширина образца? Эти две строки не объявлены безусловным противоречием. |
| C4 | Наблюдаемое следствие допущения | Объяснены оба возможных итога для 16 делений: если пересчитанная ширина меньше 12 мм, пример «узкий» согласован с П-3. При ширине от 12 мм должен получиться «широкий», и пример расходится с правилом. Не принимается подстановка неподтверждённого масштаба как установленного факта. |
| C5 | Контроль разных условий | Отдельные ограничения для двух разных экранов [П-5](bindery.md#L19) и [П-6](bindery.md#L21) не названы противоречием между собой. |

По каждому критерию фиксируются ответ «да» или «нет» и ссылка на карточку либо фрагмент отчёта. Дословность цитат и связь отчёта с исходными байтами независимо проверяются существующим скриптом проекта. Незавершённый запуск заносится в журнал отдельно и не заменяет полный отчёт.

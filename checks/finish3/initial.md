## Проверка набора в целом

В-1 и Т-1 задают разный тираж при первой выдаче. В Т-2 задан номер 804, но отсутствует критерий проверки его формата.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Тираж квитанции при первой выдаче

**Дефект · Противоречивость · Критичная.** В-1 требует один экземпляр при успешной первой выдаче, а Т-1 для той же выдачи требует два. Ни один тираж не удовлетворяет обоим условиям приёмки.

Затронутые утверждения — [R-M0007-02](#r-m0007-02), [R-M0013-02](#r-m0013-02), [R-M0013-03](#r-m0013-03).

[R-M0007-02](#r-m0007-02) · Квитанция читального зала / Порядок выдачи · [строка 7](../transfer/initial.md#L7)

> При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.  

[R-M0013-02](#r-m0013-02) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум. Каждая единица счётчика означает один отпечатанный экземпляр.  

[R-M0013-03](#r-m0013-03) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Каждая единица счётчика означает один отпечатанный экземпляр.  

**Сценарий.** Коробка свободна, счётчик печати обнулён. Оператор выбирает читателя и коробку, нажимает «Выдать», запись первой выдачи успешно открывается.

**Последствие.** Печать одного экземпляра выполняет В-1 и проваливает Т-1. Печать двух экземпляров даёт обратный исход.

**Общее условие.** Коробка свободна, счётчик обнулён, после нажатия «Выдать» запись первой выдачи открыта. Основания — [R-M0007-02](#r-m0007-02) «При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.», [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум. Каждая единица счётчика означает один отпечатанный экземпляр.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой тираж принять для этого сценария: один или два экземпляра?

1. **Вариант 1.** При успешной первой выдаче свободной коробки терминал печатает один экземпляр квитанции.

   **Основание.** [R-M0007-02](#r-m0007-02) «При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.».

   **Ожидаемый результат.** Отпечатан один экземпляр, счётчик равен одному.

   При выборе этого варианта привести в соответствие [R-M0013-02](#r-m0013-02).

2. **Вариант 2.** При успешной первой выдаче свободной коробки с обнулённым счётчиком после нажатия «Выдать» счётчик печати равен двум.

   **Основание.** [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум. Каждая единица счётчика означает один отпечатанный экземпляр.».

   **Ожидаемый результат.** Отпечатаны два экземпляра, счётчик равен двум.

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

**Черновик приёмочного теста.** Выполнить первую выдачу свободной коробки с обнулённым счётчиком, подсчитать отпечатанные экземпляры и сверить итог счётчика с выбранным тиражом.

**Что различит проверка.** Ответ с представлением «804» проходит проверку, если этот формат допустим. / Тот же ответ не проходит проверку, если требуется другое представление номера 804.

Проверить, что запись сохранилась без изменений, оператор получил номер 804 и его представление соответствует согласованному формату.».

## Готовность и порядок исправлений

ТЗ не готово к передаче в разработку. Противоречие по тиражу блокирует приёмку первой выдачи, а проверку формата в Т-2 нужно дополнить.

1. Согласовать тираж первой выдачи и привести В-1 и Т-1 к одному ожидаемому результату. ([Z-001](#z-001))
2. Указать в Т-2 допустимый формат номера 804 в ответе оператору. ([Z-002](#z-002))

# Проверка прямых оснований замечаний

Предыдущая версия получила 15/15, 14/15 и 15/15. Во втором проходе две карточки категории «Полнота» ссылались на одно требование. Одна касалась аварийной реакции, другая — штатной работы. Ссылка на аварийную ветвь во второй карточке обозначала уже проверенный контекст. Исправление проверяется на способности связать вопрос с действующей для него ветвью правила и сохранить доступ к проверенному контексту. [Три прохода предыдущей версии](../finish2/comparison.md) · [Карточка штатного режима](../../reports/finish2/benchmark-runs/irrigation/r2/report.md#z-001) · [Карточка аварийного режима](../../reports/finish2/benchmark-runs/irrigation/r2/report.md#z-008)

Для новой серии используются те же семь документов, разметка, модель, правила регистрации попыток и штатный оценщик. На каждый вход приходится три отдельных запуска `gpt-6.2-sol` с одного чистого коммита. Время старта для каждого повтора должно быть различимым в паспортах. Учитывается первый успешно сохранённый и принятый оценщиком отчёт по каждой паре «вход, проход». [Исходные критерии](../finish/protocol.md) · [Проверка времён старта](../finish2/distinct-starts.md)

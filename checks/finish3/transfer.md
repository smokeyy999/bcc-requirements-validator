# Ревью до и после согласования требований

В версии `e49600f` модель `gpt-6.2-sol` задала два вопроса по исходному ТЗ читального зала и ни одного по согласованной редакции. Выполнены четыре из четырёх заранее заданных критериев. Каждый запуск получал только одну редакцию. [Критерии](../transfer/criteria.md) · [Исходное ТЗ](../transfer/initial.md) · [Согласованное ТЗ](../transfer/agreed.md)

| Проверка | Фактический результат |
|---|---|
| Конфликт в исходных требованиях | В-1 и Т-1 описывают одну первую успешную выдачу. Их результаты различаются на один экземпляр. В вопросе сформулированы обе ветви, а тест сравнивает тираж и счётчик с выбранной. [Z-001](initial.md#z-001) |
| Что требует ответа в Т-2 | Обязанность вернуть номер 804 действующей записи сохраняется. Вопрос касается только его представления в ответе оператору. [Z-002](initial.md#z-002) |
| Тираж после согласования | Тест проверяет один экземпляр и прирост счётчика с нуля до единицы. Повторного вопроса о тираже нет. [В-1](agreed.md#r-m0007-02) · [Т-1](agreed.md#r-m0013-02) |
| Номер после согласования | Запись с номером 804 сохраняется. Поле «Действующая выдача» должно показать ровно «804». [Поле](agreed.md#r-m0009-02) · [Неизменность записи](agreed.md#r-m0015-01) · [Точный текст](agreed.md#r-m0015-02) |

| Показатель | Исходное ТЗ | Согласованное ТЗ |
|---|---:|---:|
| Выделено утверждений | 12 | 12 |
| Карточек / нарушений / критичных | 2 / 2 / 1 | 0 / 0 / 0 |
| Вопросов автору | [2](initial.md#questions) | [0](agreed.md#questions) |

## Переплётная мастерская

Выполнены пять из пяти заранее заданных критериев. В первом полном отчёте на этом документе 9 утверждений, 2 вопроса и одно критичное нарушение. С исходником сверены 15 цитат. [Критерии](../v3/criteria.md) · [ТЗ](../v3/bindery.md) · [Паспорт](bindery/run-meta.json)

| Проверка | Фактический результат |
|---|---|
| C1. Конфликт на одном входе | Первое успешное закрытие одного заказа с исправным принтером в П-1 и П-2 требует разного числа этикеток. Обе нормы процитированы. [Z-001](bindery.md#z-001) |
| C2. Исходы обеих ветвей | Автор выбирает ровно одну либо ровно две этикетки. Тест проверяет выбранное число при том же закрытии без повтора. [Z-001](bindery.md#z-001) |
| C3. Источник перевода единиц | Чтобы принять надпись «узкий» для показания 16 делений, агент запрашивает источник физической ширины этого образца. [Z-002](bindery.md#z-002) |
| C4. Строгая и включительная границы | Ниже 12 мм «узкий» проходит. Начиная с 12 мм П-3 требует «широкий» и пример П-4 расходится с правилом. [Z-002](bindery.md#z-002) |
| C5. Разные экраны | На странице ожидающих проверяют максимум три строки, завершённых — четыре. Обе нормы проверяются независимо. [Ожидающие](bindery.md#r-m0019-01) · [Завершённые](bindery.md#r-m0021-01) |

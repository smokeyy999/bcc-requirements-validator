# Независимая вычитка свободной банковской очереди

В первом полном прогоне версии `5e39095` через `gpt-6.2-sol` можно передать владельцу **16 из 17 вопросов** с опубликованными тестами. В той же очереди полностью воспроизведены **12 из 17 прежних тем** версии `5669ac8`. Каждый зачёт требует открытого решения и сценария, который различает его исходы. [Протокол](protocol.md) · [Новый отчёт](../../reports/review5/review.md) · [Прежняя очередь](../finish4/queue-review.md)

Обе заявленные доработки воспроизвелись в свободном запуске. Вопрос о частичном возврате проверяет известный результат полного возврата, а вопрос о теле ошибки сравнивает полученные значения с сохранёнными. Самостоятельного вопроса о длине `cardId` в байтах в очереди нет. Срок получения и событие изменения признака по-прежнему проверяются отдельно.
Новые темы — связь возврата с исходной покупкой и воспроизведение текста «Некорректный запрос» для 400. Вторая требует уточнить обязательность дословного сообщения. Три прежних темы представлены частично и две пропущены. Совпадение числа вопросов с числом старых тем не даёт им автоматического зачёта.

### Z-008

**Должен ли клиент получить второй push в этом месяце после смены порога?**

Тест из отчёта — После первого push повысить порог и провести покупку ровно до нового порога. Сосчитать новые push.

Наблюдаемый результат из карточки — После второй покупки новых push нет. За месяц получен один push.

Наблюдаемый результат из карточки — После второй покупки получен ещё один push. За месяц получено два push.

**Готов.** Ответ меняет счётчик отправок в одном месяце. В тесте разрешается прямое расхождение двух функциональных правил. [Строка 39](../../docs/requirements.md#L39) · [Строка 40](../../docs/requirements.md#L40) · [Z-008](../../reports/review5/review.md#z-008)

**Готов.** Выбор метода записи влияет на клиентский запрос и проверку изменившегося состояния. [Строка 104](../../docs/requirements.md#L104) · [Строка 120](../../docs/requirements.md#L120) · [Z-012](../../reports/review5/review.md#z-012)

**Готов.** Срок у получателя вводится в тест только с согласия автора. Факт получения и минутный предел передачи остаются.

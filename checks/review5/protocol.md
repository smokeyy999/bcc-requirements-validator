# Критерии повторной проверки

Исходной точкой служат 17 вопросов и их тесты в банковском отчёте версии `5669ac8`. Предыдущая вычитка приняла 15 формулировок и предложила сузить две. Для сравнения сохраняем смысл каждого исходного вопроса, а также отдельно считаем размер новой очереди и число вопросов, которые можно передать автору дословно. Один новый вопрос может покрыть две прежние темы только тогда, когда его формулировка и тест явно проверяют оба решения. Пропущенный вопрос или ответ, дописанный при вычитке, не получает зачёта. [Предыдущая вычитка](../finish4/queue-review.md) · [Банковское ТЗ](../../docs/requirements.md)

| Проверка | Условие зачёта |
|---|---|
| Возврат | Полный возврат уменьшает итог месяца исходной покупки на возвращённую сумму. Отдельный выбор ограничен применимостью частичного возврата и, если он поддерживается, его учётом. Все ветки сохраняют результат полного возврата. |
| Ответ при недопустимой сумме | Обе ветки возвращают клиенту прежнюю настройку и ERROR. Открытый вопрос касается представления этих данных. Тест сверяет возвращённые значения с заранее сохранёнными. |
| Лишние вопросы | В каждом опубликованном вопросе и тесте есть основание в исходнике и открытое решение, от которого меняется ожидаемый результат. Сверяются также прежние вопросы про идентификатор и границы доставки. |
| Дополнительная пара | На изменённом документе штатный оценщик находит все три дефекта. На согласованной копии требуется ноль вопросов и ноль лишних карточек. [Исходный протокол](../finish/protocol.md) |
| Повторяемость | Семь прежних документов, три отдельных запуска на каждый, только `gpt-6.2-sol`. В каждом проходе штатный оценщик должен зачесть 15/15 по категории и всем эталонным участкам. Число всех карточек фиксируется отдельно. [Предыдущая серия](../finish4/comparison.md) |

Проверяется первый полный результат каждого запуска. Технические ошибки, попытки восстановления и результаты предыдущих версий сохраняются. Разработчикам знакомы документы и ранее разобранные пропуски. Модель при обычном запуске получает только исходное ТЗ.

Отдельно повторно рецензируем зафиксированную очередь из 17 карточек. Для этой проверки агент получает прошлые вопросы, тесты и их основания. Редакторские варианты и оценка прошлой вычитки в запрос не передаются. Это проверяет исправление формулировки при известной теме. Свободное обнаружение тех же тем измеряется отдельно первым новым сквозным прогоном.

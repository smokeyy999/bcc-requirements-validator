# Смысловая вычитка повторной рецензии

**17 из 17 исходных вопросов готовы к передаче автору.** Проверены вопрос, зависимый тест и различие результатов по каждому исходному ID. Все 17 карточек сохранились в очереди самостоятельно. [Критерии до запуска](protocol.md) · [Фактические формулировки](fixed-queue.md)

Модель сохранила три пары «вопрос и тест» дословно и заменила 14. Каждый результат сверён с исходным решением и зависимым тестом. Для Z-009 и Z-016 отдельно проверены необработанные вопросы, тесты и по два исхода модели. Единственная точечная правка добавила ссылку на основание Z-009. Ответы по существу уже находились в первом ответе принятой попытки. [Предыдущая вычитка](../finish4/queue-review.md) · [Принятая попытка](fixed-queue-attempts/attempt-2.json)

| ID | Решение автора | Результат вычитки |
|---|---|---|
| [Z-011](fixed-queue.md#z-011) | Повторный push | После повышения порога при уже отправленном push выбор автора даёт один или два push за месяц. |
| [Z-013](fixed-queue.md#z-013) | Метод сохранения | Согласованный метод проверяется заменой настройки и повторным вызовом. |
| [Z-016](fixed-queue.md#z-016) | Предыдущая настройка в ответе | Оба результата возвращают прежние значения. При HTTP 400 и ERROR тест извлекает из ответа прежние 40 000 ₸ и включённый переключатель. Меняются только расположение и структура полей. |
| [Z-017](fixed-queue.md#z-017) | Смысл 200 с ERROR | Состав одного и того же опубликованного тела проверяется по согласованному смыслу HTTP 200. Отдельный вопрос об исходном запросе сохранён в Z-014. |
| [Z-001](fixed-queue.md#z-001) | Срок получения push | Установленную минуту передачи сервисом проверяют всегда. Измерение клиентской задержки зависит от включения в приёмку. |
| [Z-002](fixed-queue.md#z-002) | Чтение настроек | Проверяются контракт чтения и вид результата для карты с настройкой и без неё. |
| [Z-003](fixed-queue.md#z-003) | Признак включения для сервиса | Две карты в разных состояниях позволяют проверить источник значения, доступный при обработке покупки. |
| [Z-004](fixed-queue.md#z-004) | Итог для экрана | Для конкретной карты и месяца проверяется происхождение и величина показанных расходов. |
| [Z-005](fixed-queue.md#z-005) | Фиксация отправки | Признак сверяется до и после наблюдаемого события у отправителя. |
| [Z-007](fixed-queue.md#z-007) | Дата совершения в Алматы | Ответ определяет календарный месяц по Ф-2 и применимость вывода о расхождении с примером. |
| [Z-008](fixed-queue.md#z-008) | Месяц квоты push | Для январской покупки с проведением в феврале выбор месяца квоты меняет результат повторной отправки. |
| [Z-009](fixed-queue.md#z-009) | Применимость частичного возврата | Полный февральский возврат 4 000 ₸ уменьшает январский итог ровно на 4 000 ₸. Для другой покупки сравниваются только исходы частичного возврата 1 000 ₸. |
| [Z-010](fixed-queue.md#z-010) | Сумма в передаче на push | Запрос касается передаваемой величины и её единицы. Два примера в тенге различают накопленный итог 50 500 и порог 50 000. |
| [Z-012](fixed-queue.md#z-012) | Последние цифры карты | Четыре известные цифры прослеживаются от согласованного источника до исходящего сообщения. |
| [Z-014](fixed-queue.md#z-014) | Вход для примера 200/ERROR | Сначала независимо проверяется HTTP 400 для 999 ₸. Исходный запрос примера устанавливается отдельно. |
| [Z-015](fixed-queue.md#z-015) | Другие классы отказов | Состав тела проверяется по каждому открытому классу. Для отклонённой суммы сохраняется уже установленный ERROR. |
| [Z-020](fixed-queue.md#z-020) | Достижимый случай 403 | Первый шаг устанавливает существование отдельного запрета. В любом случае известные сценарии 401 и 404 остаются в тесте. |

При автономной проверке повторно применены производственные JSON-схема, правила точечной правки и смысловые проверки рецензента. Совпали хэши инструкции, полных запросов и схем. Все 17 опубликованных пар «вопрос и тест» совпали с результатом валидатора. Каждая полная попытка включала исходный ответ модели и один запрос исправления. Первый запуск был отклонён при проверке карточки о представлении прежней настройки, второй принят.

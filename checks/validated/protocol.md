# Итоговое сравнение после проверки буквальных значений

Версия `31ea961` исправляет обнаруженную в промежуточном испытании потерю знаков в ожидаемых результатах. Все входы основного корпуса, критерии совпадения и порядок трёх проходов берутся из первоначального протокола. Каждый документ отправляется в отдельный сеанс `gpt-6.2-sol`. Сохраняются первый успешный результат и журналы технических отказов. [Первоначальный протокол](../quality/protocol.md)

Четыре документа, на которых впервые выявилась ошибка, теперь служат повторной проверкой. Ещё два входа и условия зачёта зафиксированы отдельно в `96f749a` до запуска итоговой реализации. Результаты этого независимого контроля считаются отдельно. [Протокол третьей предметной области](../holdout/protocol.md)

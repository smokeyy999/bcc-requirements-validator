# Независимая проверка финальной версии

Входы и разметка последней пары зафиксированы в `5892b85` до заморозки релизной версии `fa37472`. Разработчики получили предметный разбор после фиксации кода. Модель `gpt-6.2-sol` в изолированном сеансе получала один документ. Эталон и согласованная копия в запрос не входили. [Протокол](protocol.md)

|---|---:|---:|
| Готовых отчётов | 2/2 | 2/2 |
| Замечаний с совпадающими категорией и всеми фрагментами источника | 2/2 | 2/2 |
| Полнота на общих завершённых входах (2) | 2/2 | 2/2 |
| Строгие совпадения среди всех карточек | 2/2 | 2/2 |
| Вопросы / карточки в согласованной копии | 0 / 0 | 0 / 0 |
| Попыток CLI, включая отказы | 2 | 2 |
| Дословных цитат, сверенных с оригиналом | 43 | 42 |

| Проверяемый результат | Исходная версия | Релизная версия |
|---|---|---|
| Для места «сцена» требуется конкретная метка. М-2 задаёт только форму, а А-1 требует проверить точное значение. | [Z-002](runs/before/case-r/report.md#z-002) | [Z-002](runs/after/case-r/report.md#z-002) |
| Для возврата со сцены общее правило П-2 даёт «склад», а образец А-2 требует «сцена». | [Z-001](runs/before/case-r/report.md#z-001) | [Z-001](runs/after/case-r/report.md#z-001) |
| Согласованная копия | [Вопросов 0](runs/before/case-r-base/report.md) | [Вопросов 0](runs/after/case-r-base/report.md) |

В согласованной ведомости по каждой из четырёх комбинаций места и операции однозначно определяются новое место и двухбуквенная метка. Внутренняя ссылка из А-1 ведёт к М-2 с точной строкой. На этом документе обе версии задали ноль вопросов.

В изменённом документе ссылка по-прежнему ведёт к М-2, однако в нём остался только формат метки. Агент обеих версий запросил одно точное двухбуквенное значение для посимвольной проверки. При возврате предмета со сцены правило П-2 и пример А-2 требуют разных мест. Второй вопрос выбирает между «склад» и «сцена», а проверка подаёт именно операцию возврата. В каждой версии эти два вопроса относятся к разным решениям. Повторных вопросов, запросов отсутствующего внутреннего документа и сомнений в заданном формате в очереди нет. Такую же полноту и точность здесь показала исходная реализация. На ранее независимой музыкальной задаче релиз снова различил форму стрелки и их число.

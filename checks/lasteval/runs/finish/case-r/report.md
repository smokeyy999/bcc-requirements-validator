## Проверка набора в целом

П-2 и А-2 задают разные места для возврата со сцены. Для обязательного сравнения метки при выдаче со склада в М-2 отсутствует точный код.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

Печатная ведомость сценического реквизита / Переходы · [строка 8](../../../inputs/case-r/variant.md#L8)

> П-2. После операции «вернуть» новое место — «склад» независимо от предыдущего места.  

**Связано с нарушением в спецификации.** П-2 требует «склад» при возврате из любого места. А-2 для возврата со сцены ожидает «сцена». Ни одно значение нового места не удовлетворяет обоим требованиям, поэтому принять переход нельзя.

Связанные замечания — [Z-001](#z-001).

## Готовность и порядок исправлений

ТЗ требует уточнения до разработки. Для обеих приёмочных проб нужно однозначно определить ожидаемые результаты.

1. Согласовать новое место при возврате со сцены в П-2 и А-2. ([Z-001](#z-001))
2. Задать точный код метки сцены в М-2 для проверки в А-1. ([Z-002](#z-002))

# Печатная ведомость сценического реквизита

Обработчик получает запись об одном предмете. Текущее место имеет два значения, «склад» и «сцена». Операция поступает из перечисления с двумя значениями, «выдать» и «вернуть». Разбор пользовательского ввода выполнен заранее. Для каждой из четырёх комбинаций обработчик возвращает новое место и одну печатную метку. Метка состоит ровно из двух прописных букв ASCII и зависит только от нового места.

## Переходы

П-1. После операции «выдать» новое место — «сцена» независимо от предыдущего места.
П-2. После операции «вернуть» новое место — «склад» независимо от предыдущего места.

## Таблица меток

М-1. Для нового места «склад» печатать метку «WH».
М-2. Для нового места «сцена» печатать метку «ST».

## Приёмочные пробы

А-1. Выдать предмет со склада. Проверить место «сцена» и точное значение метки по пункту М-2 раздела «Таблица меток».
А-2. Вернуть предмет со сцены. В этой пробе проверить новое место. Ожидается «склад».

# Отложенная проверка на новой паре документов

Независимый проверяющий фиксирует оба входа, их отличия и правила зачёта до запуска испытуемых версий. Разработчикам до фиксации исправления не сообщаются предметная область, содержание или эталоны. Согласованный документ полностью определяет наблюдаемый результат для каждого допустимого входа. Проверяется, сможет ли агент одновременно обосновать две отдельные проблемы в изменённой копии и завершить согласованную копию без вопросов.

Основной критерий — число отдельных карточек, совпадающих с [разметкой](inputs/case-r/manifest.json) по категории и всем заданным диапазонам строк, согласно штатному `scripts.evaluate.match_seeds`. Второй показатель — количество вопросов автору и всех карточек в согласованном документе, ожидается ноль. В изменённом документе дополнительно проверяются смысл карточек, соответствие теста запрашиваемому решению и наличие повторных вопросов по тому же решению. Если ответ уже следует из текста либо существующая внутренняя ссылка ведёт к действующему пункту, повторный запрос этого решения рассматривается отдельно.

Обе программные версии проверяются из зафиксированных чистых локальных коммитов. На каждый вход модели `gpt-6.2-sol` выделяется отдельный сеанс с одним потоком извлечения. Модель видит один вход. На каждое сочетание версии и документа берётся первый сохранённый отчёт. При технической неудаче допускается не более трёх полных попыток в сумме, все журналы сохраняются. Результат включает долю готовых отчётов, число замечаний из двух, доставленных пользователю, и полноту на общих завершённых входах. Семантическое качество без готового отчёта остаётся неизмеренным. Эта пара оценивается отдельно от прежних серий.

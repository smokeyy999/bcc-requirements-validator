## Проверка набора в целом

В-1 и Т-1 задают разное число экземпляров для одной и той же первой выдачи. В Т-2 определён возвращаемый номер, но отсутствует критерий его формата.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Число экземпляров квитанции

**Дефект · Противоречивость · Критичная.** При успешной первой выдаче свободной коробки В-1 требует один экземпляр. Т-1 при той же выдаче требует показание 2 после обнуления, то есть два отпечатанных экземпляра. Ни один исход не удовлетворяет обоим требованиям, поэтому принять печать квитанции нельзя.

Затронутые утверждения — [R-M0007-02](#r-m0007-02), [R-M0013-02](#r-m0013-02), [R-M0013-03](#r-m0013-03).

[R-M0007-02](#r-m0007-02) · Квитанция читального зала / Порядок выдачи · [строка 7](../transfer/initial.md#L7)

> При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.  

[R-M0013-02](#r-m0013-02) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.  

[R-M0013-03](#r-m0013-03) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Каждая единица счётчика означает один отпечатанный экземпляр.  

**Сценарий.** Оператор выбирает читателя и свободную коробку, затем успешно выдаёт её впервые. Перед нажатием «Выдать» счётчик печати равен нулю.

**Последствие.** Один экземпляр удовлетворяет В-1 и не проходит Т-1. Два экземпляра проходят Т-1 и нарушают В-1.

**Общее условие.** Успешная первая выдача свободной коробки одним нажатием «Выдать» при обнулённом счётчике печати. Основания — [R-M0007-02](#r-m0007-02) «При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.», [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.», [R-M0013-03](#r-m0013-03) «Каждая единица счётчика означает один отпечатанный экземпляр.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой результат принять для Т-1, один отпечатанный экземпляр или два?

1. **Вариант 1.** При успешной первой выдаче свободной коробки печатается один экземпляр квитанции.

   **Основание.** [R-M0007-02](#r-m0007-02) «При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.».

   **Ожидаемый результат.** Напечатан один экземпляр, счётчик равен одному.

   При выборе этого варианта привести в соответствие [R-M0013-02](#r-m0013-02).

2. **Вариант 2.** При успешной первой выдаче свободной коробки с обнулённым счётчиком после нажатия «Выдать» счётчик печати равен двум.

   **Основание.** [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.».

   **Ожидаемый результат.** Счётчик печати равен двум, напечатаны два экземпляра.

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

**Черновик приёмочного теста.** Выполнить первую выдачу при нулевом счётчике и сверить число отпечатанных экземпляров и конечное значение счётчика с выбранным исходом.

### Z-002 · Ожидаемый формат номера в Т-2

**Дефект · Полнота · Существенная.** Т-2 прямо требует проверить формат номера. В-2 и предусловие Т-2 задают сохранение записи и возврат номера 804. Для проверки формата нужен ожидаемый вид ответа.

> Содержание ответа проверяет приёмочный тест.  

[R-M0015-01](#r-m0015-01) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 15](../transfer/initial.md#L15)

> Коробка занята, у записи текущего держателя номер 804. После нажатия «Выдать» запись прежняя.  

[R-M0015-02](#r-m0015-02) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 15](../transfer/initial.md#L15)

> Проверить формат номера в ответе оператору.  

**Сценарий.** Оператор пытается выдать занятую коробку. Номер записи текущего держателя до нажатия «Выдать» равен 804.

**Последствие.** По В-2 и предусловию Т-2 можно проверить, что оператору возвращён номер 804. Для проверки формы его представления критерия нет.

**Уже установлено.** После попытки выдать занятую коробку запись текущего держателя остаётся прежней, оператору возвращается её номер 804. Основания — [R-M0015-02](#r-m0015-02), [R-M0015-01](#r-m0015-01), [R-M0009-02](#r-m0009-02), [R-M0009-03](#r-m0009-03).

**Открытое решение.** Какое представление номера 804 считать правильным в ответе оператору по Т-2?

**Что различит проверка.** При критерии «только цифры» ответ «804» проходит проверку формата. / При критерии «номер со знаком №» тот же ответ «804» не проходит проверку формата.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** В каком представлении Т-2 должен принять номер 804 в ответе оператору?

Внести ответ на этот вопрос в [R-M0009-02](#r-m0009-02), [R-M0009-03](#r-m0009-03), [R-M0015-01](#r-m0015-01), [R-M0015-02](#r-m0015-02) для сценария «Оператор пытается выдать занятую коробку. Номер записи текущего держателя до нажатия «Выдать» равен 804.».

**Черновик приёмочного теста.** Выполнить попытку выдачи, сверить возвращённый номер с 804 и проверить его представление по согласованному критерию.

### R-M0013-02 · В Т-1 после нажатия «Выдать» при первой выдаче свободной коробки счётчик меняется с нуля до двух.

Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.  

**Связано с нарушением в спецификации.** При успешной первой выдаче свободной коробки В-1 требует один экземпляр. Т-1 при той же выдаче требует показание 2 после обнуления, то есть два отпечатанных экземпляра. Ни один исход не удовлетворяет обоим требованиям, поэтому принять печать квитанции нельзя.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке печати квитанции до согласования числа экземпляров. Для завершения Т-2 нужно указать ожидаемый формат номера.

1. Согласовать число экземпляров и привести В-1 и Т-1 к одному ожидаемому результату, включая конечное показание счётчика. ([Z-001](#z-001))
2. Указать в Т-2 допустимое представление номера 804 в ответе оператору. ([Z-002](#z-002))

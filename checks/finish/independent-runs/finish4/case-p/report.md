## Проверка набора в целом

Для «АБА» заданы взаимоисключающие надписи. Полный цикл измерим, но критерия его приёмки нет. Для повреждённого узора требуется выбрать ожидаемую рамку.

Открытых предполагаемых пробелов — 1. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

**Сценарий.** После сброса один раз подать метку «АБА» и проверить, что стенд показывает согласованную надпись.

**Последствие.** Исход «Отклонено» нарушает М-2, а исход «Принято» нарушает М-1. Исключение для «АБА» не установлено.

**Общее условие.** После сброса один раз подают метку «АБА». Каждая из трёх букв занимает два байта в UTF-8. Основания — [R-M0003-03](#r-m0003-03) «В каждом опыте после сброса подают указанный вход один раз и наблюдают указанный результат.», [R-M0011-02](#r-m0011-02) «Метка состоит из букв А и Б, каждая буква занимает два байта в UTF-8.», [R-M0011-05](#r-m0011-05) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».», [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какую надпись стенд должен показать для шестибайтовой метки «АБА» — «Принято» или «Отклонено»?

1. **Вариант 1.** Применять к «АБА» общее правило. При длине свыше четырёх байт показывать «Отклонено».

   **Основание.** [R-M0011-05](#r-m0011-05) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».».

   **Ожидаемый результат.** Для шестибайтовой метки «АБА» стенд показывает «Отклонено».

   При выборе этого варианта привести в соответствие [R-M0012-01](#r-m0012-01).

2. **Вариант 2.** Для «АБА» установить явное исключение из общего правила и показывать «Принято».

   **Основание.** [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

   **Ожидаемый результат.** Для той же шестибайтовой метки «АБА» стенд показывает «Принято».

   При выборе этого варианта привести в соответствие [R-M0011-05](#r-m0011-05).

**Черновик приёмочного теста.** После сброса один раз подать метку «АБА» и проверить, что стенд показывает согласованную надпись.

## Готовность и порядок исправлений

ТЗ не готово к разработке с однозначной приёмкой. Для опыта с меткой нужно согласовать надпись, для опыта с таймером — определить критерий прохождения.

1. Согласовать М-1 и М-2 так, чтобы для шестибайтовой метки «АБА» действовал один ожидаемый исход. ([Z-002](#z-002))
2. Задать наибольшее допустимое показание таймера Э-1 в целых миллисекундах. ([Z-003](#z-003))
3. Указать рамку для события «Узор повреждён». ([Z-001](#z-001))

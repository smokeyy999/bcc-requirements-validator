   **Основание.** [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

   **Ожидаемый результат.** Для шестибайтной метки «АБА» стенд показывает «Принято».

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке. Ни для одного из трёх обязательных опытов нельзя однозначно вынести полный приёмочный вердикт.

1. Согласовать М-1 и М-2, чтобы для «АБА» действовал один ожидаемый ответ. ([Z-002](#z-002))
2. Указать, какую рамку контроллер выводит после события «Узор повреждён». ([Z-001](#z-001))
3. Задать предел в целых миллисекундах для показания общего таймера и правило при равенстве. ([Z-003](#z-003))

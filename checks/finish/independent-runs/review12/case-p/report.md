Для «АБА» заданы взаимоисключающие надписи. Для повреждённого узора не назначена рамка, а для измеряемого полного цикла не задан критерий длительности.

- [Z-001](#z-001) · П-1 требует «предусмотренную для этого события рамку» и перечисляет две рамки. Для события рамка не назначена, поэтому обязательный опыт нельзя принять по наблюдаемому результату.

[R-M0012-01](#r-m0012-01) · Учебный стенд для мозаики / Текстовая метка · [строка 12](../../../independent/case-p/variant.md#L12)

> Для входа «АБА» стенд должен показать «Принято».  

**Сценарий.** После сброса один раз подать метку «АБА» длиной шесть байтов в UTF-8 и сверить надпись с согласованным результатом.

**Последствие.** М-1 требует «Отклонено», а М-2 требует «Принято». Явного исключения для «АБА» нет.

**Общее условие.** После сброса один раз подают метку «АБА». Её три буквы занимают шесть байтов в UTF-8, что превышает предел М-1 в четыре байта. Основания — [R-M0003-03](#r-m0003-03) «В каждом опыте после сброса подают указанный вход один раз и наблюдают указанный результат.», [R-M0011-02](#r-m0011-02) «Метка состоит из букв А и Б, каждая буква занимает два байта в UTF-8.», [R-M0011-04](#r-m0011-04) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».», [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

   **Основание.** [R-M0011-04](#r-m0011-04) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».».

2. **Вариант 2.** Для входа «АБА» действует явно заданное исключение из М-1. Стенд показывает «Принято».

   **Основание.** [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

   **Ожидаемый результат.** Стенд показывает «Принято».

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке по заданным требованиям. Ни для одного из трёх обязательных опытов нельзя однозначно вынести решение о приёмке.

1. Согласовать М-1 и М-2, закрепив одну надпись для «АБА». ([Z-002](#z-002))
2. Назначить рамку для события «Узор повреждён». ([Z-001](#z-001))
3. Задать допустимый предел полного цикла в целых миллисекундах и исход при равенстве. ([Z-003](#z-003))

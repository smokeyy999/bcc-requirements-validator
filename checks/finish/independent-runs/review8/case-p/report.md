## Проверка набора в целом

Во всех трёх обязательных опытах описано воздействие. Для «АБА» заданы несовместимые показания, для повреждённого узора не выбрана рамка, а для полного цикла не определена допустимая длительность.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-001](#z-001) · П-1 требует вывести предусмотренную рамку и перечисляет два варианта. Какой из них соответствует событию, не указано. Без этого результата опыт с повреждённым узором принять нельзя.

- [Z-003](#z-003) · Э-1 задаёт измерение в целых миллисекундах от нажатия до регистрации подтверждения. Э-2 требует «достаточно короткий» полный цикл без численного критерия, поэтому обязательную проверку длительности завершить нельзя.

### Z-002 · Несовместимые результаты для «АБА»

**Дефект · Противоречивость · Критичная.** Метка «АБА» занимает шесть байт UTF-8. М-1 требует «Отклонено», а М-2 для той же метки требует «Принято». Приоритет или исключение не заданы, поэтому опыт с меткой принять нельзя.

Затронутые утверждения — [R-M0011-02](#r-m0011-02), [R-M0011-04](#r-m0011-04), [R-M0012-01](#r-m0012-01).

> Метка состоит из букв А и Б, каждая буква занимает два байта в UTF-8.  

[R-M0011-04](#r-m0011-04) · Учебный стенд для мозаики / Текстовая метка · [строка 11](../../../independent/case-p/variant.md#L11)

> При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».  

[R-M0012-01](#r-m0012-01) · Учебный стенд для мозаики / Текстовая метка · [строка 12](../../../independent/case-p/variant.md#L12)

> Для входа «АБА» стенд должен показать «Принято».  

**Сценарий.** После сброса один раз подать метку «АБА» и проверить показание стенда по согласованному результату.

**Последствие.** По М-1 приёмка требует «Отклонено», по М-2 — «Принято».

**Общее условие.** Вход «АБА» состоит из трёх букв допустимого алфавита и занимает шесть байт UTF-8. Основания — [R-M0011-02](#r-m0011-02) «Метка состоит из букв А и Б, каждая буква занимает два байта в UTF-8.», [R-M0011-04](#r-m0011-04) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».», [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какое показание стенда является ожидаемым для входа «АБА»: «Отклонено» или «Принято»?

   **Основание.** [R-M0011-04](#r-m0011-04) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».».

   При выборе этого варианта привести в соответствие [R-M0012-01](#r-m0012-01).

   **Основание.** [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

   **Ожидаемый результат.** Шестибайтовая метка «АБА» даёт «Принято».

   При выборе этого варианта привести в соответствие [R-M0011-04](#r-m0011-04).

## Готовность и порядок исправлений

ТЗ не готово к разработке и однозначной приёмке. Для каждого опыта требуется решение автора.

1. Устранить расхождение М-1 и М-2 и закрепить единый ожидаемый результат для «АБА». ([Z-002](#z-002))
2. Указать рамку для события «Узор повреждён». ([Z-001](#z-001))
3. Задать численный предел показания общего таймера и результат при равенстве пределу. ([Z-003](#z-003))

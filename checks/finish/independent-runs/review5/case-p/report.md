> При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».  

[R-M0012-01](#r-m0012-01) · Учебный стенд для мозаики / Текстовая метка · [строка 12](../../../independent/case-p/variant.md#L12)

**Сценарий.** После сброса один раз подать метку «АБА» и сверить надпись стенда с согласованным результатом.

**Последствие.** По М-1 стенд должен показать «Отклонено», по М-2 для того же входа он должен показать «Принято». Исключение для «АБА» в тексте не задано.

**Общее условие.** После сброса один раз подают метку «АБА» из трёх двухбайтовых букв UTF-8. Основания — [R-M0003-02](#r-m0003-02) «В каждом опыте после сброса подают указанный вход один раз и наблюдают указанный результат.», [R-M0011-02](#r-m0011-02) «Метка состоит из букв А и Б, каждая буква занимает два байта в UTF-8.», [R-M0011-04](#r-m0011-04) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».», [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какую надпись закрепить для шестибайтной метки «АБА» — «Отклонено» по М-1 или «Принято» по М-2?

1. **Вариант 1.** При длине до четырёх байт включительно стенд показывает «Принято», при большей длине показывает «Отклонено». Это правило применяется и к «АБА».

   **Основание.** [R-M0011-04](#r-m0011-04) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».».

   При выборе этого варианта привести в соответствие [R-M0012-01](#r-m0012-01).

2. **Вариант 2.** Для входа «АБА» действует явное исключение из правила длины: стенд показывает «Принято».

   **Основание.** [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

   **Ожидаемый результат.** Для шестибайтной метки «АБА» стенд показывает «Принято».

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке. Для каждого из трёх обязательных опытов требуется решение автора.

1. Согласовать М-1 и М-2, закрепив одну ожидаемую надпись для шестибайтной метки «АБА». ([Z-002](#z-002))
2. Указать, какую рамку выводит контроллер при событии «Узор повреждён». ([Z-001](#z-001))
3. Задать предел показания общего таймера в целых миллисекундах и результат при равенстве пределу. ([Z-003](#z-003))

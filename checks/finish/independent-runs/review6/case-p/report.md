## Проверка набора в целом

Для «АБА» заданы взаимоисключающие ответы. Для повреждённого узора требуется назначить рамку, а для измеряемого полного цикла определить допустимую длительность.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

## Критичные дефекты

- [Z-001](#z-001) · После сброса для одной и той же шестибайтовой метки «АБА» М-1 требует «Отклонено», а М-2 требует «Принято». Текст не задаёт исключения или приоритета, поэтому ожидаемый ответ обязательного опыта определить нельзя.

**Сценарий.** После сброса один раз подать метку «АБА». Каждая из трёх букв занимает два байта в UTF-8, поэтому длина метки составляет шесть байт.

**Последствие.** М-1 требует показать «Отклонено», а М-2 для того же входа требует показать «Принято». Приоритет или исключение в тексте не заданы.

**Общее условие.** После сброса один раз подают метку «АБА». Три буквы по два байта в UTF-8 дают шесть байт. Основания — [R-M0003-03](#r-m0003-03) «В каждом опыте после сброса подают указанный вход один раз и наблюдают указанный результат.», [R-M0011-02](#r-m0011-02) «Метка состоит из букв А и Б, каждая буква занимает два байта в UTF-8.», [R-M0011-05](#r-m0011-05) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».», [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой ответ принять для «АБА» — «Отклонено» по М-1 или «Принято» как исключение по М-2?

1. **Вариант 1.** При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено». Правило применяется и к «АБА».

   **Основание.** [R-M0011-05](#r-m0011-05) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».».

   **Ожидаемый результат.** Для шестибайтовой метки «АБА» стенд показывает «Отклонено».

   При выборе этого варианта привести в соответствие [R-M0012-01](#r-m0012-01).

2. **Вариант 2.** Для входа «АБА» действует исключение из правила длины. Стенд показывает «Принято».

   **Основание.** [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

   **Ожидаемый результат.** Для той же шестибайтовой метки «АБА» стенд показывает «Принято».

   При выборе этого варианта привести в соответствие [R-M0011-05](#r-m0011-05).

## Готовность и порядок исправлений

ТЗ не готово к разработке с однозначной приёмкой. Для каждого из трёх обязательных опытов требуется решение автора.

1. Согласовать М-1 и М-2, закрепив один ответ для «АБА». ([Z-001](#z-001))
2. Назначить конкретную рамку событию «Узор повреждён». ([Z-002](#z-002))
3. Установить предел для показания таймера в целых миллисекундах и определить исход при равенстве. ([Z-003](#z-003))

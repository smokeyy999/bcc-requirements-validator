## Критичные дефекты

- [Z-001](#z-001) · Метка «АБА» занимает шесть байт. М-1 требует «Отклонено», а М-2 для той же подачи требует «Принято». Приоритет между требованиями не установлен, поэтому опыт принять невозможно.

**Дефект · Противоречивость · Критичная.** Метка «АБА» занимает шесть байт. М-1 требует «Отклонено», а М-2 для той же подачи требует «Принято». Приоритет между требованиями не установлен, поэтому опыт принять невозможно.

**Общее условие.** После сброса один раз подают метку «АБА» из трёх двухбайтовых букв. Основания — [R-M0003-02](#r-m0003-02) «В каждом опыте после сброса подают указанный вход один раз и наблюдают указанный результат.», [R-M0011-01](#r-m0011-01) «каждая буква занимает два байта в UTF-8.», [R-M0011-05](#r-m0011-05) «при большей длине — «Отклонено».», [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

   **Основание.** [R-M0011-05](#r-m0011-05) «При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».».

   При выборе этого варианта привести в соответствие [R-M0012-01](#r-m0012-01).

2. **Вариант 2.** Для входа «АБА» показывать «Принято», предусмотрев для этого входа исключение из правила длины.

   **Основание.** [R-M0012-01](#r-m0012-01) «Для входа «АБА» стенд должен показать «Принято».».

   **Ожидаемый результат.** «АБА» занимает шесть байт. Стенд показывает «Принято».

   При выборе этого варианта привести в соответствие [R-M0011-05](#r-m0011-05).

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке. Для каждого из трёх обязательных опытов требуется решение автора.

1. Согласовать М-1 и М-2, чтобы для «АБА» был один ожидаемый результат. ([Z-001](#z-001))
2. Указать рамку для события «Узор повреждён». ([Z-002](#z-002))
3. Задать предел полного цикла в целых миллисекундах и результат проверки при равенстве. ([Z-003](#z-003))

# Учебный стенд для мозаики

Стенд выполняет три независимых опыта. В каждом опыте после сброса подают указанный вход один раз и наблюдают указанный результат. Других входов и режимов в приёмке нет.

## Повреждённый узор

П-1. После события «Узор повреждён» контроллер обязан вывести предусмотренную для этого события рамку. У контроллера две рамки, «точки» и «штрихи». Для этого события установлены «точки».

## Текстовая метка

М-1. Метка состоит из букв А и Б, каждая буква занимает два байта в UTF-8. При длине до четырёх байт включительно стенд показывает «Принято», при большей длине — «Отклонено».
М-2. Для входа «АБА» стенд должен показать «Отклонено».

## Завершение показа

Э-1. При нажатии кнопки «Образец» внешний экран показывает слово «Готово» и в момент появления слова посылает стенду подтверждение. Сигнал подтверждения фиксируется без задержки. Общий таймер стенда измеряет целые миллисекунды от нажатия до регистрации этого подтверждения.
Э-2. По условиям приёмки интервал полного цикла, измеренный по Э-1, должен составлять не более 500 миллисекунд включительно.

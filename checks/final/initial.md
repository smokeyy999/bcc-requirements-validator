## Проверка набора в целом

В-1 и Т-1 задают разные тиражи квитанции при первой выдаче. Для занятой коробки значение ответа определено, но Т-2 не проверяет его и оставляет открытым критерий формата.

Открытых предполагаемых пробелов — 1. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Число экземпляров при первой выдаче

**Дефект · Противоречивость · Критичная.** В-1 требует один экземпляр, а Т-1 ожидает два при той же успешной первой выдаче. При нулевом начальном показании эти результаты взаимоисключающие, поэтому приёмка выдачи заблокирована.

Затронутые утверждения — [R-M0007-02](#r-m0007-02), [R-M0013-02](#r-m0013-02), [R-M0013-03](#r-m0013-03).

[R-M0007-02](#r-m0007-02) · Квитанция читального зала / Порядок выдачи · [строка 7](../transfer/initial.md#L7)

> При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.  

[R-M0013-02](#r-m0013-02) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.  

[R-M0013-03](#r-m0013-03) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Каждая единица счётчика означает один отпечатанный экземпляр.  

**Сценарий.** Перед первой выдачей коробка свободна, счётчик печати равен нулю. Оператор нажимает «Выдать», и запись выдачи открывается.

**Последствие.** Терминал, выполнивший В-1, не пройдёт Т-1 по числу экземпляров.

**Общее условие.** Первая выдача свободной коробки успешна. До нажатия «Выдать» счётчик обнулён, после нажатия запись открыта. Основания — [R-M0007-02](#r-m0007-02) «При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.», [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.», [R-M0013-03](#r-m0013-03) «Каждая единица счётчика означает один отпечатанный экземпляр.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой результат принять при успешной первой выдаче, один экземпляр или два?

1. **Вариант 1.** При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.

   **Основание.** [R-M0007-02](#r-m0007-02) «При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.».

   **Ожидаемый результат.** Отпечатан один экземпляр, итоговое значение счётчика равно одному.

   При выборе этого варианта привести в соответствие [R-M0013-02](#r-m0013-02).

2. **Вариант 2.** Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.

   **Основание.** [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.».

   **Ожидаемый результат.** Счётчик печати равен двум, отпечатаны два экземпляра.

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

**Черновик приёмочного теста.** Обнулить счётчик, выполнить первую выдачу свободной коробки и сверить число отпечатанных экземпляров и итоговое показание с выбранным результатом.

### Z-002 · Проверка значения номера в Т-2

**Дефект · Полнота · Существенная.** В-2 предписывает проверить содержание ответа и требует вернуть номер текущей записи. В Т-2 ожидаемое значение 804 известно, но проверка одного формата пропустит другой номер в том же формате.

Затронутые утверждения — [R-M0009-02](#r-m0009-02), [R-M0009-03](#r-m0009-03), [R-M0015-02](#r-m0015-02).

[R-M0009-02](#r-m0009-02) · Квитанция читального зала / Порядок выдачи · [строка 9](../transfer/initial.md#L9)

> Если коробка уже занята, терминал сохраняет запись текущего держателя без изменений и возвращает оператору её номер.  

[R-M0009-03](#r-m0009-03) · Квитанция читального зала / Порядок выдачи · [строка 9](../transfer/initial.md#L9)

> Содержание ответа проверяет приёмочный тест.  

[R-M0015-02](#r-m0015-02) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 15](../transfer/initial.md#L15)

> Коробка занята, у записи текущего держателя номер 804. После нажатия «Выдать» запись прежняя. Проверить формат номера в ответе оператору.  

**Сценарий.** Коробка занята, запись текущего держателя имеет номер 804. После нажатия «Выдать» запись сохраняется, а оператор получает другой номер в допустимом формате.

**Последствие.** Ошибка выбора записи может остаться незамеченной при проверке формата.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

Проект правки по [R-M0009-02](#r-m0009-02), [R-M0009-03](#r-m0009-03), [R-M0015-02](#r-m0015-02) — Дополнить проверку ответа сравнением возвращённого номера с номером записи текущего держателя.

**Черновик приёмочного теста.** Открыть исправленные пункты [R-M0009-02](#r-m0009-02), [R-M0009-03](#r-m0009-03), [R-M0015-02](#r-m0015-02) и проверить выполнение предложенной правки «Дополнить проверку ответа сравнением возвращённого номера с номером записи текущего держателя.».

### R-M0015-02 · В Т-2 требуется проверить формат номера в ответе оператору при попытке выдать занятую коробку.

> Коробка занята, у записи текущего держателя номер 804. После нажатия «Выдать» запись прежняя. Проверить формат номера в ответе оператору.  

**Связано с нарушением в спецификации.** В-2 предписывает проверить содержание ответа и требует вернуть номер текущей записи. В Т-2 ожидаемое значение 804 известно, но проверка одного формата пропустит другой номер в том же формате. Т-2 явно требует проверить формат номера. В-2 определяет значение ответа, а критерий допустимого представления остаётся открытым.

Связанные замечания — [Z-002](#z-002), [Z-003](#z-003).

## Готовность и порядок исправлений

ТЗ пока не готово к разработке и приёмке первой выдачи. Сохранение записи занятой коробки и возврат её номера можно реализовать по В-2.

1. Согласовать число экземпляров и привести В-1 и Т-1 к одному ожидаемому результату. ([Z-001](#z-001))
2. Добавить в Т-2 проверку, что возвращён номер 804. ([Z-002](#z-002))
3. Уточнить критерий формата номера для Т-2. ([Z-003](#z-003))

# Свободное банковское ревью и регрессионные проверки

До запуска зафиксированы [17 тем предыдущего отчёта](../review8/queue-review.md). Их названия, старые карточки, тексты тестов и готовые решения доступны только при последующей оценке. Новый запуск CLI получает [исходное ТЗ организаторов](../../docs/requirements.md). Модель извлекает утверждения и строит вопросы заново.

Тема получает полный зачёт, когда вопрос и связанный с ним приёмочный тест позволяют владельцу принять решение по всем существенным условиям. Частично воспроизведённая тема учитывается отдельно. Количество вопросов может отличаться от количества тем. Для каждого вопроса проверяются согласование, падежи, однозначность направления действия и сохранение смысла при чтении без карточки. Журнал сохраняет и технически неуспешные попытки. Для оценки берётся первый опубликованный банковский отчёт проверяемой версии.

На той же версии реализации выполняются три прохода на [семи документах](../../benchmark/README.md) и дополнительная проверка двух вариантов ТЗ с таймером. Для каждого прохода проверяются все 15 эталонных дефектов с исходными категориями и диапазонами цитат. На согласованном варианте таймера целевое число вопросов равно нулю. Все вызовы выполняются на `gpt-6.2-sol`.

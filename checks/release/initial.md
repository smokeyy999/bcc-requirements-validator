## Проверка набора в целом

В-1 и Т-1 задают разные результаты печати при успешной первой выдаче. Для занятой коробки определено значение возвращаемого номера, а проверке формата в Т-2 недостаёт ожидаемого представления.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

**Что различит проверка.** Ответ «№ 804» проходит проверку формата, если допустим префикс «№». / Тот же ответ «№ 804» не проходит проверку формата, если допустима только запись «804».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какое представление номера 804 в ответе оператору должен принять Т-2?

> Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум.  

**Связано с нарушением в спецификации.** Для одной и той же успешной первой выдачи В-1 требует один отпечаток, а Т-1 при обнулённом счётчике ожидает два. Из-за разных ожидаемых результатов сценарий первой выдачи нельзя принять.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке первой выдачи до согласования числа экземпляров. Для завершения проверки Т-2 нужно задать ожидаемый формат номера.

1. Согласовать число экземпляров при успешной первой выдаче и привести В-1 и ожидаемое показание счётчика в Т-1 в соответствие. ([Z-001](#z-001))
2. Указать в Т-2, какое представление номера 804 проходит проверку формата. ([Z-002](#z-002))

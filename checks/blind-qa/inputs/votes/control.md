# Табло решения трёх арбитров

Табло работает без памяти. На вход приходит одно готовое сообщение за раз. Разрешены ровно девять сообщений: восемь строк длиной три из букв Д и Н и отдельная команда «Перерыв». Других входов у этого модуля нет. На каждое сообщение табло выводит ровно один знак. Вся обработка происходит внутри табло.

## Правила голоса

Г-1. Для строки голосов табло показывает «+», если букв Д не меньше двух, иначе «−».

## Приёмочные испытания

А-1. Для строки ДНН на экране должен появиться «−».
А-2. Обязательно отдельно проверить обработку команды «Перерыв». Подать эту команду и проверить, что на экране появляется знак «П».

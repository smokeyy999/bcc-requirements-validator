## Проверка набора в целом

Для каждой из двух команд правило и приёмочный сценарий задают разные значения одного и того же выхода.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### R-M0007-01 · Команда «Обзор» задаёт отметку 0,45 м.

Установка указателя на макете железной дороги / Правила · [строка 7](../../../inputs/plotter/variant.md#L7)

> Ш-1. По команде «Обзор» указатель устанавливается на отметку 0,45 м.  

**Связано с нарушением в спецификации.** Для команды «Обзор» Ш-1 задаёт 0,45 м, то есть 450 мм, а П-1 ожидает 45 мм. Единственный выход не может удовлетворить обоим требованиям, поэтому команду нельзя принять.

Связанные замечания — [Z-001](#z-001).

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке. Автору нужно согласовать выход отдельно для каждой команды.

1. Согласовать координату для «Обзора» в Ш-1 и П-1. ([Z-001](#z-001))
2. Согласовать координату для «Настройки» в Ш-2 и П-2. ([Z-002](#z-002))

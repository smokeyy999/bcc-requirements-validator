Открытых предполагаемых пробелов — 1. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария.

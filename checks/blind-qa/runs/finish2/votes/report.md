## Проверка набора в целом

Для ДНН заданы взаимоисключающие знаки. Для обязательного испытания команды «Перерыв» отсутствует ожидаемый знак.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

**Последствие.** По тексту можно принять количество знаков, но нельзя оценить правильность показанного знака.

**Уже установлено.** А-2 задаёт подачу команды и проверку экрана. На экране должен быть ровно один знак. Г-1 определяет знак только для строк голосов. Основания — [R-M0012-01](#r-m0012-01), [R-M0003-03](#r-m0003-03), [R-M0003-06](#r-m0003-06), [R-M0007-01](#r-m0007-01).

**Что различит проверка.** Если ожидается «+», показ одного «+» проходит испытание. / Если ожидается «−», тот же показ одного «+» не проходит испытание.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

[R-M0011-01](#r-m0011-01) · Табло решения трёх арбитров / Приёмочные испытания · [строка 11](../../../inputs/votes/variant.md#L11)

> А-1. Для строки ДНН на экране должен появиться «+».  

**Сценарий.** Подать ДНН одним сообщением, проверить, что на экране ровно один знак, и сверить его с согласованным требованием для ДНН.

**Последствие.** При выводе «−» испытание А-1 не пройдено, а при выводе «+» нарушено правило Г-1.

**Общее условие.** На табло подают одну строку голосов ДНН. В ней одна буква Д, и на экране должен появиться ровно один знак. Основания — [R-M0007-02](#r-m0007-02) «Для строки голосов табло показывает «+», если букв Д не меньше двух, иначе «−».», [R-M0011-01](#r-m0011-01) «Для строки ДНН на экране должен появиться «+».», [R-M0003-06](#r-m0003-06) «На каждое сообщение табло выводит ровно один знак.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой единственный знак должен появиться на экране при подаче строки ДНН?

1. **Вариант 1.** Для ДНН применить общее правило. Если букв Д меньше двух, показать «−».

   **Основание.** [R-M0007-02](#r-m0007-02) «Г-1. Для строки голосов табло показывает «+», если букв Д не меньше двух, иначе «−».».

   **Ожидаемый результат.** На экране появляется «−».

   При выборе этого варианта привести в соответствие [R-M0011-01](#r-m0011-01).

2. **Вариант 2.** Для ДНН установить явное исключение из Г-1 и показать «+».

   **Основание.** [R-M0011-01](#r-m0011-01) «А-1. Для строки ДНН на экране должен появиться «+».».

   **Ожидаемый результат.** На экране появляется «+».

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

**Черновик приёмочного теста.** Подать ДНН одним сообщением, проверить, что на экране ровно один знак, и сверить его с согласованным требованием для ДНН.

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке в полном объёме. Сначала нужно согласовать знак для ДНН и задать знак для «Перерыва».

1. Согласовать единственный знак для ДНН и привести Г-1 и А-1 в соответствие. ([Z-002](#z-002))
2. Указать в А-2, какой единственный знак должен появиться при подаче команды «Перерыв». ([Z-001](#z-001))

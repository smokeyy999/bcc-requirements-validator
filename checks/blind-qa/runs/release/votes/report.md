Затронутые утверждения — [R-M0007-02](#r-m0007-02), [R-M0011-01](#r-m0011-01).

[R-M0007-02](#r-m0007-02) · Табло решения трёх арбитров / Правила голоса · [строка 7](../../../inputs/votes/variant.md#L7)

> Для строки голосов табло показывает «+», если букв Д не меньше двух, иначе «−».  

[R-M0011-01](#r-m0011-01) · Табло решения трёх арбитров / Приёмочные испытания · [строка 11](../../../inputs/votes/variant.md#L11)

> Для строки ДНН на экране должен появиться «+».  

**Сценарий.** Подать одно сообщение «ДНН». В нём одна буква Д.

**Последствие.** Каждый из двух знаков удовлетворяет одному требованию и нарушает другое.

**Общее условие.** На табло подают одну допустимую строку голосов ДНН с одной буквой Д. Основания — [R-M0007-02](#r-m0007-02) «Для строки голосов табло показывает «+», если букв Д не меньше двух, иначе «−».», [R-M0011-01](#r-m0011-01) «Для строки ДНН на экране должен появиться «+».».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой знак должен появиться на экране при подаче ДНН — «−» по Г-1 или «+» по А-1?

1. **Вариант 1.** Применить к ДНН общее правило. Табло показывает «+», если букв Д не меньше двух, иначе «−».

   **Основание.** [R-M0007-02](#r-m0007-02) «Для строки голосов табло показывает «+», если букв Д не меньше двух, иначе «−».».

   **Ожидаемый результат.** На экране появляется «−».

   При выборе этого варианта привести в соответствие [R-M0011-01](#r-m0011-01).

2. **Вариант 2.** Для строки ДНН на экране должен появиться «+».

   **Основание.** [R-M0011-01](#r-m0011-01) «Для строки ДНН на экране должен появиться «+».».

   **Ожидаемый результат.** На экране появляется «+».

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

**Черновик приёмочного теста.** Подать ДНН и сравнить единственный знак на экране с согласованным исходом.

1. Согласовать Г-1 и А-1 по ожидаемому знаку для ДНН. ([Z-002](#z-002))

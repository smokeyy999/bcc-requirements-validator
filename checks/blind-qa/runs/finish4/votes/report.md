## Проверка набора в целом

Для ДНН правило голосования и приёмочное испытание требуют разных знаков. Для команды «Перерыв» обязательное испытание не задаёт ожидаемый знак.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

> Для строки ДНН на экране должен появиться «+».  

**Сценарий.** Подать готовое сообщение «ДНН» одним входом. В строке одна буква Д.

**Последствие.** Г-1 требует «−», а А-1 требует «+». Табло выводит ровно один знак, поэтому выполнить оба требования невозможно.

**Общее условие.** Подать строку голосов ДНН одним сообщением и проверить единственный знак на экране. Основания — [R-M0003-05](#r-m0003-05) «восемь строк длиной три из букв Д и Н», [R-M0003-08](#r-m0003-08) «На каждое сообщение табло выводит ровно один знак.», [R-M0007-02](#r-m0007-02) «Для строки голосов табло показывает «+», если букв Д не меньше двух, иначе «−».», [R-M0011-01](#r-m0011-01) «Для строки ДНН на экране должен появиться «+».».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой знак должен появиться для ДНН, «−» по Г-1 или «+» как исключение?

1. **Вариант 1.** Применять Г-1 ко всем строкам голосов. При числе букв Д не меньше двух показывать «+», иначе «−».

   **Основание.** [R-M0007-02](#r-m0007-02) «Для строки голосов табло показывает «+», если букв Д не меньше двух, иначе «−».».

   **Ожидаемый результат.** Для ДНН на экране появляется «−».

   При выборе этого варианта привести в соответствие [R-M0011-01](#r-m0011-01).

2. **Вариант 2.** Для ДНН показывать «+» и явно закрепить этот случай как исключение из Г-1.

   **Основание.** [R-M0011-01](#r-m0011-01) «Для строки ДНН на экране должен появиться «+».».

   **Ожидаемый результат.** Для ДНН на экране появляется «+».

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

**Черновик приёмочного теста.** Подать ДНН и сравнить единственный знак на экране с согласованным ожиданием.

> Для строки голосов табло показывает «+», если букв Д не меньше двух, иначе «−».  

**Связано с нарушением в спецификации.** А-2 требует подать «Перерыв» и проверить экран. Из ТЗ известно, что появится ровно один знак, но его значение не задано. Без него обязательное испытание нельзя принять. ДНН содержит одну букву Д, поэтому Г-1 требует «−», а А-1 для той же строки требует «+». Исключение из Г-1 не задано. Единственный выводимый знак не может удовлетворить обоим требованиям.

Связанные замечания — [Z-001](#z-001), [Z-002](#z-002).

## Готовность и порядок исправлений

ТЗ не готово к разработке и приёмке полной обработки всех девяти допустимых сообщений. Для ДНН и «Перерыв» требуется согласовать ожидаемые знаки.

1. Согласовать единственный знак для ДНН и привести Г-1 и А-1 в соответствие. ([Z-002](#z-002))
2. Задать знак для команды «Перерыв» и указать его как ожидаемый результат А-2. ([Z-001](#z-001))

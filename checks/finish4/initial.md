## Проверка набора в целом

В-1 и Т-1 задают взаимоисключающее число отпечатков при первой выдаче. В Т-2 задан возвращаемый номер, но отсутствует критерий его формата.

Открытых предполагаемых пробелов — 0. Неоднозначностей — 0. Рекомендаций — 0.

Каждый ID утверждения учитывается один раз. В число нарушений входят подтверждённые дефекты и неоднозначности, для которых показаны две опирающиеся на текст трактовки с разными последствиями. Один и тот же конфликт имеет один ID при любом числе затронутых требований. Критичный дефект блокирует приёмку существенного обязательного сценария. Предполагаемый пробел оставляет открытым ожидаемое поведение или источник данных. Рекомендация предлагает улучшение. Вопросы и рекомендации имеют отдельные счётчики.

### Z-001 · Число экземпляров при первой выдаче

**Дефект · Противоречивость · Критичная.** Для одной успешной первой выдачи В-1 требует один экземпляр, а Т-1 при нулевом начальном счётчике ожидает два. Каждый отпечаток даёт одну единицу счётчика, поэтому ни один исход не удовлетворяет обоим требованиям приёмки.

Затронутые утверждения — [R-M0007-02](#r-m0007-02), [R-M0013-02](#r-m0013-02), [R-M0013-03](#r-m0013-03).

[R-M0007-02](#r-m0007-02) · Квитанция читального зала / Порядок выдачи · [строка 7](../transfer/initial.md#L7)

[R-M0013-02](#r-m0013-02) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Т-1. Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум. Каждая единица счётчика означает один отпечатанный экземпляр.  

[R-M0013-03](#r-m0013-03) · Квитанция читального зала / Выписка из приёмочных испытаний · [строка 13](../transfer/initial.md#L13)

> Каждая единица счётчика означает один отпечатанный экземпляр.  

**Сценарий.** Коробка свободна, счётчик печати обнулён. Оператор нажимает «Выдать» впервые, и запись выдачи успешно открывается.

**Последствие.** При одном экземпляре выполнено В-1 и провален Т-1. При двух экземплярах выполнен Т-1 и нарушено В-1.

**Общее условие.** Первая выдача свободной коробки, счётчик печати обнулён. После нажатия «Выдать» запись успешно открыта. Основания — [R-M0007-02](#r-m0007-02) «При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.», [R-M0013-02](#r-m0013-02) «Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум. Каждая единица счётчика означает один отпечатанный экземпляр.».

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

**Вопрос для решения.** Какой исход принять для Т-1: один отпечатанный экземпляр или два?

1. **Вариант 1.** При успешной первой выдаче свободной коробки терминал печатает один экземпляр квитанции.

   **Основание.** [R-M0007-02](#r-m0007-02) «В-1. При успешной первой выдаче свободной коробки терминал открывает одну запись выдачи и печатает один экземпляр квитанции.».

   **Ожидаемый результат.** Напечатан один экземпляр, счётчик равен 1.

   При выборе этого варианта привести в соответствие [R-M0013-02](#r-m0013-02).

2. **Вариант 2.** В Т-1 при первой выдаче свободной коробки с обнулённым счётчиком после нажатия «Выдать» запись открыта, счётчик печати равен двум.

   **Основание.** [R-M0013-02](#r-m0013-02) «Т-1. Перед первой выдачей коробка свободна, счётчик печати обнулён. После нажатия «Выдать» запись открыта, счётчик печати равен двум. Каждая единица счётчика означает один отпечатанный экземпляр.».

   **Ожидаемый результат.** Счётчик печати равен двум, напечатаны два экземпляра.

   При выборе этого варианта привести в соответствие [R-M0007-02](#r-m0007-02).

**Черновик приёмочного теста.** Выполнить успешную первую выдачу свободной коробки с обнулённым счётчиком. Сверить число отпечатанных экземпляров и конечное значение счётчика с выбранным исходом.

**Уже установлено.** Запись текущего держателя сохраняется без изменений, оператор получает её номер 804. Основания — [R-M0015-02](#r-m0015-02), [R-M0009-02](#r-m0009-02), [R-M0009-03](#r-m0009-03).

**Что различит проверка.** Представление «804» проходит проверку формата, если критерий его допускает. / То же представление «804» проваливает проверку формата, если критерий требует иного представления.

**Предложение для автора.** Предложение модели. Выбор формулировки и ожидаемого результата утверждает автор ТЗ.

Внести ответ на этот вопрос в [R-M0009-02](#r-m0009-02), [R-M0009-03](#r-m0009-03), [R-M0015-02](#r-m0015-02) для сценария «Оператор нажимает «Выдать» для занятой коробки. Запись текущего держателя с номером 804 сохраняется, оператор получает её номер.».

## Готовность и порядок исправлений

ТЗ не готово к разработке. Согласование числа экземпляров блокирует приёмку первой выдачи. Для завершения Т-2 нужно задать ожидаемое представление номера.

1. Согласовать число экземпляров при первой выдаче и привести ожидаемое показание счётчика в Т-1 в соответствие с ним. ([Z-001](#z-001))
2. Задать в Т-2 критерий формата возвращаемого номера 804. ([Z-002](#z-002))

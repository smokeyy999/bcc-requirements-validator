# Управление поливом теплицы

Контроллер одной секции работает по показаниям датчика влажности. У оператора есть кнопка ручной остановки.

## Автоматика
W-1. При ручной остановке все следующие автоматические команды открытия игнорируются до нажатия «Возобновить».
W-2. В режиме ручной остановки команда открытия от расписания не открывает клапан.
W-3. Для полива включается одна зона, выбранная оператором по номеру на панели.
W-4. При получении некорректного значения датчика контроллер обязан перевести клапан в указанное здесь аварийное положение. Аварийное положение — закрыто.
W-5. У контроллера есть обязательная проверка кнопки «Возобновить». Результат приёмки: после нажатия очередная команда открытия исполняется.

## Обмен с панелью
W-6. Контроллер повторяет передачу значения на панель ровно три раза после первого таймаута.
W-7. Число повторных передач значения на панель после первого таймаута равно трём.

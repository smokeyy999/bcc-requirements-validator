# Индикатор выключателя

C-1. Единственный вход индикатора принимает ровно два значения: 0 и 1.
C-2. При входе 0 индикатор не светится.
C-3. При входе 1 индикатор светится.
C-4. Приёмка состоит из двух наблюдений после установления каждого входного значения: отсутствие света при 0 и наличие света при 1.
